# 제작 사양서 02 — UI 화면 명세 (전 화면)

> 좌표계 : 1280×720 기준(좌상단 원점). 색상은 **장별 테마**(§0) 변수를 사용. 전자 래피 수첩 8탭의 항목·데이터는 `docs/design/02_전자수첩_UI_인적사항.md`가 원본이고, 이 문서는 **레이아웃·상태·애니메이션**을 보충한다.

## 1. 타이틀 화면
```
┌──────────────────────────────────────────┐
│    (배경 : 폐쇄된 놀이공원 정문 야경 일러스트 + 오르골 멜로디) │
│                                          │
│            『夢の国 — 유메노쿠니』           │ ← 로고 y=140
│                                          │
│              [ 처음부터 ]                  │ ← 버튼 폭 360, y=360, 간격 72
│              [ 이어하기 ]                  │
│              [ 갤러리 ]                    │ ← 클리어 후 해금
│              [ 옵션 ]                      │
│              [ 종료 ]                      │
│                                          │
│ v0.1.0                    © Yumenokuni   │
└──────────────────────────────────────────┘
```
* 타이틀 배경 : 클리어한 장 수에 따라 **일러스트가 바뀐다**(0장=정문, 1장=회전목마, … 6장=코어).
* 첫 실행 시 15초 후 "토끼 한 마리가 지나가는" 대기 연출.

## 2. 챕터 타이틀 카드 (연출)
* 검정 배경에 로고 + `CHAPTER 0N` + 한국어 제목 + 날짜(`DAY 2`). 1.5초 표시, 0.5초 페이드.
* 예 : `Prologue — 개장 전야` / `Chapter 1 — 개장` / `Chapter 2 — 물놀이 시즌` / `Chapter 3 — 거울의 밤` / `Chapter 4 — 잠든 롤러코스터` / `Chapter 5 — 드림 캐슬` / `Chapter 6 — 드림 코어`.

## 3. 탐색 HUD (파노라마 노드)
```
┌──────────────────────────────────────────────────┐
│ 📍 푸드코트 · 주방               ☆ 17   DAY 2 14:30  │ ← 상단 바 (h=48)
│                                                  │
│  (파노라마 렌더 / 핫스팟 윤곽 표시)                     │
│                                                  │
│   ◀ [이동 화살표 : 주방 입구]      [이동 화살표 : 창고] ▶ │ ← 이동 노드 마커
│                                                  │
│ [Tab 수첩] [M 지도] [Space 조사모드]    [수사 타이머 78:12] │ ← 하단 바 (h=56)
└──────────────────────────────────────────────────┘
```
| 요소 | 사양 |
|---|---|
| 위치 표기 | `📍 구역 · 방` + 층 정보 |
| 코인 | 금빛 코인 아이콘 + 수량. 획득 시 +n 팝업 |
| 시간 | `DAY n HH:MM`. 이벤트 진행 시 자동 갱신 |
| 이동 마커 | 화면 가장자리의 화살표 원(지름 72). 클릭 시 해당 노드로 이동. 마커 위에 방 이름 라벨 |
| 핫스팟 | 평소엔 보이지 않음. `Space`를 누르면 **반짝이는 링**이 0.3s 나타남(옵션 : 항상 표시). 호버 시 이름 툴팁 |
| 시점 | 마우스 드래그로 좌우 360° / 상하 ±40°. 휠로 줌 1.0~1.3 |
| 수사 타이머 | 수사 비트에서만 표시. 10분 이하 빨강 점멸 |
| 단축키 | `Tab` 수첩 / `M` 지도 / `Space` 조사 모드 / `E` 상호작용 / `L` 로그 / `Esc` 일시정지 |

### 3-1. 조사 모드 (확대 화면)
```
┌──────────────────────────────────────────┐
│ ← 뒤로(ESC)       「말 조형물 7번」              │
│     (확대 일러스트 : 3개의 관찰점 ◎)             │
│  ◎1   ◎2   ◎3     [관찰 1/3 완료]             │
└──────────────────────────────────────────┘
```
* 관찰점 최대 3개. 클릭 시 미오 독백 + 필요하면 증거 카드 획득.
* 완료 표시 : 관찰점이 흰색 → 금색.
* 증거 카드 획득 시 : 화면 중앙에 카드가 떠오르며(0.4s) 토스트 + `sfx_card` + 수첩 아이콘 반짝.

## 5. 전자 래피 수첩 (Handbook) 8탭
* 데이터·항목은 `docs/design/02_전자수첩_UI_인적사항.md`. 여기선 **상호작용**만 정의.

| 탭 | 상호작용 |
|---|---|
| 프로필 | `Q/E` 캐릭터 전환(0.2s 슬라이드). 필드 값 호버 시 해금 조건 툴팁. 사망 시 흑백 + 리본 |
| 성적표 | 인연 Lv 막대 / 스킬 카드 클릭 → 장착(SP 초과 시 경고) |
| 증거 | 4색 필터 + 장 필터 + 검색. 카드 클릭 시 상세. **재판 중에는 탄환 장전 모드** |
| 노트 | 장·일차별 페이지. 승격 슬롯 3칸. 변조 불가 카드는 파란 테두리 + 잠금 아이콘 |
| 지도 | 구역 탭(0~6). 방문한 방은 컬러. `Space` 증거 별 표시 토글 |
| 규칙 | 목록. `NEW` 배지. 래피 질의 가능한 규칙에 `?` 아이콘 |
| 선물 | 보유 선물 목록(수량), 코인, 캡슐 이력(최근 10회) |
| 옵션 | 음량·텍스트 속도·자막·색약·번쩍임 감소·스킵·세이브 |

### 5-1. 수첩 열기·닫기 연출
* 열기 : 화면이 0.3s 블러 + 수첩이 아래에서 위로 슬라이드(`ui_open`).
* 닫기 : 역재생. 재판 중에는 "증거" 탭이 **탄환 슬롯**으로 변환되어 하단 중앙에 고정.

## 6. 프리타임 UI

### 6-1. 세션 시작
```
(화면 암전 → 햇살/저녁빛 배경)
┌──────────────────────────────────────────┐
│          ★ 자유시간 ★                       │
│  오늘은 두 사람과 시간을 보낼 수 있어요.        │
│          슬롯 1 / 2                        │
└──────────────────────────────────────────┘
```
### 6-2. 인물 선택 화면
```
┌──────────────────────────────────────────────────┐
│  [얼굴 아이콘 줄 : 생존자 전원]  ← 인연 Lv 별/BP 막대        │
│  ┌──────────────┐   ┌─────────────────────────┐  │
│  │ (선택 인물 입상) │   │ 이름 · 현재 위치 · Lv ★★☆☆☆ (12/18)│  │
│  │               │   │ 이번 이벤트 : ② 「홍차 한 잔」        │  │
│  │               │   │ 선물 사용 가능 : 홍차 틴 1            │  │
│  └──────────────┘   │ [ 만나러 가기 ]   [ 선물 확인 ]       │  │
│                     └─────────────────────────┘  │
└──────────────────────────────────────────────────┘
```
| 규칙 | 설명 |
|---|---|
| 회색 처리 | 이미 본 이벤트·퇴장 인물·위치가 이동 불가한 인물 |
| 이벤트 라벨 | `①` Lv2 / `②` Lv3 / `③` Lv5 / 미해금이면 "일반 대화" |
| 스포일러 방지 | 제목은 이벤트 진입 후 공개 |
| 단축키 | `Q/E` 인물 이동, `Enter` 선택, `G` 선물 확인 |

### 6-3. 이벤트 진행 화면
* 대화 UI + 우측 상단에 **BP 막대**(작게). 선택지 결과 시 `★ +2`·`✕ −1` 팝업.
* 선물 사용 시점 : 이벤트 스크립트가 `@gift_prompt`를 호출하면 선물 선택 창(§6-4) 표시.

### 6-4. 선물 선택 창
```
┌──────────────────────────────────────────┐
│  누구에게 줄까요? : 코토                      │
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐        │
│ │G01 │ │G03 │ │G11 │ │...│ │    │  ← 그리드 5×2 │
│ │ ×2 │ │ ×1 │ │ ×1 │ │   │ │    │        │
│ └────┘ └────┘ └────┘ └────┘ └────┘        │
│  [주기]  [취소]                             │
└──────────────────────────────────────────┘
```
* 선택 시 상대 반응(호/보통/비)이 이벤트 대사로 이어지고 BP 변화 팝업.

### 6-5. 정산 화면
```
┌──────────────────────────────────────────┐
│     「코토」와의 시간 — 완료                   │
│  인연 포인트 +5   (12 → 17)  Lv3 유지         │
│  대표 대사 카드 획득 : 「서로를 믿으면 편해요」       │
│  코인 +2                                   │
│            [ 다음으로 ]                      │
└──────────────────────────────────────────┘
```
* **레벨업 시** : 별이 꽉 차며 `ui_unlock` + 스킬 획득 카드(스킬 이름·효과·SP/MP) 팝업.

## 7. 캡슐 머신 UI
```
┌──────────────────────────────────────────┐
│  래피 캡슐         ☆ 17                     │
│       (3D풍 캡슐 머신 일러스트)               │
│  [ 1회 (3코인) ]  [ 10회 (27코인) ]            │
│  보증 카운터 : 12 / 15                       │
└──────────────────────────────────────────┘
```
* 뽑기 연출(2초) : 캡슐 낙하 → 열림 → 선물 일러스트 확대 → 등급별 이펙트(일반 흰색 / 좋은 것 은색 / 희귀 금색 / 장미 무지개).
* 10회 연속 : 캡슐 10개가 줄지어 나오고 결과 목록.
* 위치별 캡슐 머신 : 광장·각 신규 구역 입구. 같은 풀을 공유.
* 래피 음성 : 누적 5회/10회/20회 시 대사 변화(01 캐릭터 문서 17절).

## 8. 스킬 장착 화면
```
┌──────────────────────────────────────────────┐
│  SP 7 / 10                                      │
│  장착 슬롯 [ 괜찮아, 맡겨!(2) ][ 규칙 정리(2) ][ 집중(2) ][ ] │
│  획득 목록 (카드) : 이름 / 효과 / SP / MP / 획득처          │
│  [ 해제 ] [ 자동 추천 ]                                   │
└──────────────────────────────────────────────┘
```
* 같은 계열(회복형) 2개 이상 장착 시 경고 "효과 80%".
* 사망 인물 스킬은 카드에 **추모 리본**(작은 흑백 리본).

## 9. 재판 공통 HUD
```
┌──────────────────────────────────────────────────┐
│ 집중력 ♥♥♥♥♥ ▓▓▓▓▓▓▓░ 85/100   마음 ▓▓▓▓░ 60/100        │ ← 상단 중앙
│                                                  │
│  (재판장 3D풍 배경 : 원형 연단 + 인물 실루엣)             │
│  증언 문장 영역                                       │
│                                                  │
│ 탄환 슬롯 [E1-02][E1-03][N1-01][...] (최대 10)          │ ← 하단 중앙
│ [Q 질의] [Tab 수첩] [Space 일시정지] [R 재시도]            │
└──────────────────────────────────────────────────┘
```
* HP(집중력) 하트 5개 + 막대 : 하트 1개 = 20.
* 탄환 슬롯 : 증거 카드 아이콘 56×56. 노트 증거는 파란 테두리·금빛.
* 상세는 `04_재판_미니게임_사양.md`.

## 10. 결과·보상 화면 (재판 종료)
```
┌──────────────────────────────────────────┐
│          재판 종료  (정답!)                  │
│  남은 집중력 85  →  코인 +14                  │
│  논파 18 / 오답 2 / 질의 4회                  │
│  등급 : A   [ 다음으로 ]                      │
└──────────────────────────────────────────┘
```
* 등급 : S(오답 0 + 질의 ≤3) / A(오답 ≤2) / B(오답 ≤4) / C. 등급별 코인 보너스(+0~6).

## 11. 게임 오버·재도전
* 집중력 0 : 화면이 붉게 번쩍이고 "재판 중단". 래피 대사 "…다시 해 볼래요?" `[체크포인트에서 재도전]` `[타이틀]`. 체크포인트는 재판 단계 시작점.
