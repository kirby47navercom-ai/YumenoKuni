# 제작 사양서 07 — 데이터 스키마 (게임 JSON)

> `tools/build_data.py`가 생성하는 파일 + 구현 시 직접 작성할 파일의 스키마. 형식은 JSON, 키는 영문 소문자 스네이크, 값은 한국어 가능.

## 1. ID 규칙

| 대상 | 형식 | 예 |
|---|---|---|
| 캐릭터 | `0001`~`0016`, 래피 `0000` | `0003` 소라 |
| 캐릭터 slug | 영문 소문자 | `sora` |
| 장면 UID | `파일접두:장면ID` | `11a:1-S2` |
| 증거 | `E{장}-{번호}[-접미]` | `E1-02`, `E5-02-b` |
| 증언 | `T{장}-{번호}` | `T2-02` |
| 노트 후보 | `N{장}-{번호}` | `N4-01` |
| 마법 카드 | `M{장}-{번호}` | `M3-01` |
| 규칙 | `R-{번호}` | `R-08` |
| 선물 | `G{번호}` | `G03` |
| 스킬 | `S-{slug}-{1|2}` / `S-mio-{1..5}` | `S-rei-1` |
| 프리타임 이벤트 | `FT-{slug}-{1|2|3}` | `FT-taiga-1` |
| 질의 | `Q{장}-{번호}` | `Q1-1` |
| 미니게임 | `MG-{종류}-{장}-{번호}` | `MG-stream-1-2` |

## 2. 캐릭터 (`characters.json` — 이미 생성됨)
```json
{
  "id": "0003",
  "heading": "카미야 소라 (神谷 空 / KAMIYA SORA)",
  "fields": {
    "나이 · 키 · 체중 · 신발": "17세 · 172cm · 63kg · 255mm",
    "생일 · 혈액형": "8월 8일 · O형",
    "지망(꿈)": "소방관",
    "특기": "달리기, 응급 처치",
    "좋아하는 것": "...",
    "싫어하는 것": "...",
    "버릇": "...",
    "마법": "**「빙의」** — ...",
    "수첩 메모": "Lv1 ... / Lv2 ... / Lv3 ... / Lv5 ⚠ ..."
  }
}
```
* 구현 시 정규화 형식(§2-1)으로 변환하는 로더를 작성한다(`fields` 문자열 파싱).

## 3. 장면 (`scenes/*.json` — 이미 생성됨)
```json
{
  "source": "11a_1장_일상_프리타임.md",
  "scenes": [
    {
      "id": "1-S2", "uid": "11a:1-S2", "title": "1-S2 푸드코트 요리 대결 (20분)", "location": "푸드코트 「스위트 팔레트」",
      "events": [
        {"type":"stage","text":"푸드코트. 공용 주방에…"},
        {"type":"say","speaker":"래피","kind":"normal","text":"자, 자, 자!…","emo":"활짝"},
        {"type":"say","speaker":"미오","kind":"monologue","text":"…"},
        {"type":"ui","text":"요리 대결 : …"},
        {"type":"choice","text":"A. \"간장을 더 넣자\" → …"},
        {"type":"break","text":"팀 B 조리대"}
      ]
    }
  ]
}
```

## 5. 재판 표 (`tables/*.json` — 이미 생성됨)
```json
{"section":"D-2 논파 스트림 ① : …","kind":"stream","header":["#","화자","문장","판정","필요"],
 "rows":[["1","유우","\"회전목마가 고장 …\"","**노란**","E1-03 구동 로그"]]}
```
### 5-1. 스트림 정규화(04 §5-4)
```json
{"id":"MG-stream-1-2","type":"stream","rounds":3,
 "statements":[{"no":1,"speaker":"yuu","text":"…","mark":"weak","weak":[{"word":"고장","bullet":"E1-03"}]},
               {"no":3,"speaker":"kaede","text":"…","mark":"agree"}],
 "on_clear":"11b:D-2-clear"}
```
### 5-2. 질의(04 §9-2)
```json
{"id":"Q1-1","options":[
  {"text":"철제 말 조형물을 비틀 수 있는 마법이 있나요? 누구의 것인가요?","kind":"correct","give":["M1-03"],"answer":["래피 : 있어요. …"]},
  {"text":"타이가를 죽인 사람이 누구인가요?","kind":"wrong","answer":["래피 : 그건 질문이 아니에요!"]},
  {"text":"타이가의 마법은 무엇인가요?","kind":"hint","cost":0,"answer":["이름과 규칙은 사건과 관련된 질문일 때만 답해요."]}
]}
```

## 6. 스킬 (`skills.json` — 구현 시 작성)
```json
{"id":"S-koto-1","owner":"koto","name":"규칙 정리","unlock_lv":2,"sp":2,"mp":0,
 "kind":"passive","effect":{"query_plus":1},"desc":"래피 질의 횟수가 +1이 됩니다.","stack_rule":"none"}
```
* 전체 30종 + 미오 5종은 `00_시스템_기획서.md §6-3`과 `02_전자수첩_UI_인적사항.md §5-3` 표가 원본.

## 8. 프리타임 이벤트 (`events.json`)
```json
{"id":"FT-taiga-1","who":"taiga","label":"①","require":{"bp":4},"chapters":[1],"scene":"11a:B-10","max_per_run":1,
 "magic_unlock":["M1-03"],"bp_gain":2,"coin":2,"memory_card":"내가 지킨다!"}
```
* **이벤트 풀 규칙** : `label` ①=Lv2 / ②=Lv3 / ③=Lv5. 요구 레벨 미달이면 낮은 라벨 이벤트가 대신 열린다(09 규칙).
