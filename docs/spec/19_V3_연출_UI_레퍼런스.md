## 0. 한 줄 요약 — V3 다움 7 가지

1. **모든 것이 기울어져 있다.** 이름표·대사 띠·HUD 판·버튼·컷인 띠가 전부 평행사변형(사선 끝)이다. 수평·수직 직사각형 카드, 둥근 모서리는 거의 없다.
2. **배경은 늘 살아 있는 3D 공간이다.** 일상·탐색은 3D 방 안 1인칭, 재판은 3D 원형 재판장. 그 안에 **2D 입상이 종이 인형처럼 서 있다**(발 그림자 있음). 그림 한 장을 깔고 그 위에 인물을 붙이는 화면은 없다.
3. **모드마다 색 테마가 확 바뀐다.** 일상 = 노랑·검정 / 재판 대사 = 보라·분홍 네온 / 논스톱 = 짙은 파랑 / 패닉 = 붉은 주황 / 반론 쇼다운 = 왼쪽 분홍·오른쪽 파랑 + 노란 장식 칸막이 / 클로징 = 자홍(마젠타) 만화책 / 투표 = 은색 기계.
4. **글자가 연출이다.** 논의 발언은 화면 높이의 1/6 넘는 거대한 글자가 3D 로 기울어 날아다니고, 낱말마다 크기·각도가 다르다. 컷인은 붓글씨(「Counter」「GOT IT」)가 화면을 가른다.
5. **카메라는 거의 멈추지 않는다.** 같은 장면에서도 기울기(더치 앵글)·낮은 앵글·원경·클로즈업이 줄마다 바뀌고, 논의 중엔 화자 둘레를 돈다.
6. **HUD 는 네 귀퉁이에 사선 판으로.** 왼쪽 위 화자 이름 / 오른쪽 위 Status(하트·별) / 왼쪽 아래 탄환(언령) / 오른쪽 아래 타이머(디지털 7 세그먼트 글꼴). 가운데는 비워 글자·인물에게 준다.
7. **대사창은 상자가 아니다.** 재판 대사는 화면 아래 어두운 띠 위에 글자만, 일상은 반투명 검은 띠 + 양 끝 노란 사선. 중요 낱말은 노랑/주황 글자.

## 1. 재판 — 대사 화면 (논의가 아닐 때)

**[확인 A 4:00, 7:00, 26:52, 27:12]**
* 배경 : 3D 재판장. 스테인드글라스(분홍·자주 육각 무늬) 창, 검은 철제 난간, 증언대. 화자는 크게(화면 높이 70~90%), **옆자리 사람도 같이 보인다**(작게·흐리게 잘려서). 인물은 어둡게 덮지 않고 그대로 밝다.
* 카메라 : 줄마다 다르다 — 화자 정면 미디엄 / 두 사람 걸친 샷 / 낮게 기운 클로즈업(26:52 고타, 화면이 약 8° 기울어짐) / 위에서 비스듬히.
* **배경 큰 글자** : 「CLASS TRIAL」 을 청록 외곽선만 있는 거대한 이탤릭 글자로, 인물 뒤 공간을 가로질러 흐른다(카메라에 따라 원근이 걸림). 늘 보인다.
* **화면 테두리** : 분홍·보라 네온 사선 여러 줄이 화면 가장자리를 비스듬히 가른다(유리 깨진 듯한 다각형 선).
* **왼쪽 화자 카드** : 왼쪽 위 「CLASS TRIAL」 작은 로고(분홍 J 같은 곡선 + 글자) → 그 아래 기울어진 세로 카드에 **화자 얼굴 크롭**(눈 높이), 카드 아래 이름 두 줄(「Kaito / Momota」), **이름 첫 글자만 크고 색**(청록·분홍), 나머지 흰 글자. 카드는 화면 왼쪽 약 0~20% 폭.
* **대사** : 화면 아래 약 20% 의 어두운 띠 위에 흰 글자 두 줄, 상자 테두리 없음. 글꼴은 깔끔한 고딕. **중요 낱말은 노랑·주황**(27:12 「Gonta」).
* 오른쪽 아래 「AUTO」 원형 버튼(청록 외곽선).
* 여러 명이 동시에 말하는 줄 : 기울어진 분홍 테두리 말풍선 띠가 여러 개 겹쳐 뜬다 **[확인 A 25:00]**.
* 모노쿠마 : 왕좌(붉은 의자) 정면 샷, 스테인드글라스 배경 **[확인 A 13:00]**.

## 2. 논스톱 의논

**[확인 A 16:40~17:20, 1:31:40]** **[위키]**
* **카메라** : 화자 클로즈업이 아니다. **재판장을 넓게 비추는 원경** — 증언대 6~7 명이 한 줄로 보이고 화자는 그 가운데 멀리(16:43). 다른 줄은 낮은 앵글로 화자를 올려다보며 다른 사람들과 함께(16:30·17:10 「No way!」). 줄마다 각도가 바뀌고 계속 움직인다.
* 조명 : 장면 전체가 **짙은 파랑**으로 바뀐다(일반 대사의 분홍·보라 → 파랑).
* **발언 글자** :
  * 아주 크다 — 큰 낱말은 화면 높이의 1/6~1/5.
  * 여러 줄로 쌓이고, **낱말마다 크기가 다르다**(「cuz I」 작게, 「never went」 크게, 「to the」 작게, 「library,」 크게, 「okay!?」 중간).
  * 3D 로 기울어 원근이 걸림(한쪽이 더 멀다), 회전한 채 날아든다. 「N... No way! That's not possible!」 은 낱말 하나하나가 흩어져 각각 다른 각도.
  * 색 : 약점·핵심 구절은 **파랑~청록 그라데이션 굵은 글자**, 나머지는 흰 글자 + 짙은 그림자. (위키 : 약점 = 주황, 동의 = 파랑, 화이트 노이즈 = 자홍) — 이 장면의 파랑이 약점인지 동의인지는 **[추정]**, 역분석으로 확인.
* **HUD [확인 16:43]** :
  * 왼쪽 위 : 기울어진 검은 탭에 화자 이름(「Miu」, 넓은 자간) + 그 아래 **점 여러 개(증언 순서 표시, 지금 줄만 주황)**.
  * 오른쪽 위 : 「Status」 사선 탭 + 분홍 하트 줄(발언력) + 초록 별 줄(집중) — 청록 테두리의 기울어진 판.
  * 왼쪽 아래 : **회전식 탄창(실린더) 그림 + △ 버튼 아이콘 + 흰 사선 판에 탄환 이름(「Moving Bookcase」) + 그 아래 「Truth Bullets」**.
  * 오른쪽 아래 : ▶ 아이콘 + **「04:38:962」 7 세그먼트 디지털 타이머**(주황빛), 기울어진 판.
  * 가운데 작은 조준점(파란 원).
* **명중 「V」 연출 [확인 A 17:20]** : 화면 가득 붉은·노란 거대한 「V」 + 원근 걸린 「ACC(EPT)」 글자, 주황 폭발 배경.
* 규칙 [위키] : 집중(시간 느려짐·조준 흔들림 감소), V 포인트(집중 중 빨간 점 → V-반론/동의/거짓 = 보너스), 사일런서로 화이트 노이즈 제거(시간 +), 거짓말 탄환(버튼을 누르고 있으면 바뀜, 발언력 일부가 표시되며 빠짐, 성공 시 회복), 위증 가능할 때 곡 「V3 Argument -PERJURY-」.

## 3. 패닉 의논 (Mass Panic Debate)

**[확인 A 26:06]** **[위키]**
* 화면이 **세 개의 대각선 쐐기(삼각·사다리꼴) 칸**으로 쪼개진다. 칸 사이는 가는 붉은 선. 직사각형 세 칸이 아니다.
* 각 칸 = 그 화자를 비추는 **실시간 3D 카메라**(재판장 배경 그대로), 전체가 **붉은 주황빛**.
* 발언 글자는 칸 모양에 맞춰 **세로·대각선으로** 쓰인다(「None of us coulda killed him!」 세로, 「There is no God but Atua.」 비스듬히). 낱말 크기 섞임.
* HUD 는 논스톱과 같은 네 귀퉁이.
* [위키] 큰 소리 발언이 다른 대화를 덮어 약점을 못 쏘게 만들고, 그 발언을 사일런서로 쏴야 한다.

## 4. 반론 쇼다운

**[확인 A 50:12]** **[위키]**
* 화면이 **세로로 둘** : 왼쪽 = 상대(료마, 분홍·붉은 빛 재판장), 오른쪽 = 주인공(카에데, 파란 빛, 크게 클로즈업).
* 가운데 칸막이 = **노란 다이아몬드·지그재그 장식 띠**(세로). [위키] 칸막이 위치 = 유리함 — 잘 베면 내 쪽 움직임 범위가 넓어진다.
* 상대 발언이 **대각선으로** 주인공 쪽을 향해 날아든다(「right after killing Rantaro.」).
* 왼쪽 아래 : **칼(카타나) 그림 + 파란 판에 칼 이름(「Monokuma File 1」) + 파란 꽃(수국) 장식**. 칼 커서 = 주인공 쪽 주황 칼 아이콘.
* 오른쪽 아래 타이머, 왼쪽 위 상대 이름 탭, 오른쪽 위 Status.
* 시작 「Advance!」 파란 글자 연출 **[확인 A 50:00]**.

## 5. 의논 스크럼

**[확인 A 1:18:48]** **[위키]**
* 재판장이 **변형**된다 — 증언대가 솟아 두 줄로 마주 보고, 바닥·벽이 체커(흑백 원) 무늬 **[확인 A 1:17:40~1:18:00 변형 장면 : 방사형 터널 그래픽]**.
* 왼쪽 : 상대 편 **빨간 화살표 탭**들(얼굴 작은 사진 + 「???」), 오른쪽을 가리킴.
* 오른쪽 : 우리 편 **파란 화살표 탭**들(얼굴 + 핵심 낱말 「Alibi」「Together」「Receiver」), 왼쪽을 가리킴.
* 가운데 : 지금 말하는 상대의 거대 발언(흰 글자, **핵심 낱말만 주황** 「alibi」) + 뒤에 그 상대가 크게 클로즈업.
* 위 가운데 타이머, 오른쪽 위 Status, 가운데 아래 팔각형 장식.
* [위키] 상대 발언 속 핵심 낱말과 우리 편 낱말을 맞춘다. 다 맞히면 버튼 연타로 마무리.

## 6. 섬광 애너그램 3.0 (Hangman's Gambit Ver3.0)

**[확인 A 1:35:00]** **[위키]**
* 배경 : 어두운 남색 **격자 무늬** + 주인공 실루엣.
* 글자 구슬 = **검은 구**, 평소엔 글자가 안 보이고 **빛이 지나갈 때만** 보인다(위키). 집중하면 가운데서 넓어지는 빛.
* 왼쪽 위 : 답 칸(흰 사각 칸에 각진 글자 「V E N T」). 오른쪽 위 하트·별. 오른쪽 아래 질문 글자 + 「Hide Question」. 왼쪽 아래 타이머.
* 맞히면 **「GOT IT」 컷인** : 화면을 가로지르는 파란 띠 + 검은 붓글씨 「GOT IT」 + 오른쪽에 주인공 얼굴 **[확인 A 1:35:10]**.

## 7. 이론 무장 (Argument Armament)

**[확인 A 1:51:00~1:52:00]** **[위키]**
* **전용 무대** : 붉은 커튼·샹들리에·아치 창이 있는 극장 같은 공간(재판장 아님).
* 상대 = **전신, 자기 재능을 갑옷처럼 두른 과장된 모습**(카에데 = 거대한 피아노 건반·음표 갑옷).
* 상대 발언 = 분홍 글자 + **리듬 버튼 표시(○△□✕)** 가 글자 위에 붙어 박자에 맞춰 날아온다.
* 왼쪽 위 상대 체력 바(분홍, 이름), 오른쪽 아래 주인공 작은 얼굴 + 노란 번개, 왼쪽 아래 타이머.
* [위키] 박자 따라 버튼, 템포 변화, 상대가 버튼 표시를 가림, 피버 타임(집중 가득일 때), 마지막에 낱말 조각을 순서대로 맞춰 「Final Strike」.

## 8. 클로징 아규먼트 (V3)

**[확인 A 1:56:00~1:58:00]** **[위키]**
* 화면 전체 **자홍(마젠타)·보라 만화책** 디자인 : 기울어진 책 페이지, 왼쪽 위 「Closing Argument」 로고(자홍 + 노란 외곽).
* 오른쪽 위 페이지 수(「03/10」) + 노란 화살표.
* 가운데 : 만화 칸들, 비어 있는 칸 = **분홍 「?」 칸**. 위에 자홍 사선 상자로 질문(「Who was asked to modify the cameras?」).
* 왼쪽 : 기울어진 그림 카드 더미(고를 칸 후보), 아래 노란 사선 판에 후보 설명.
* 틀리면 **빨간 고리**, 맞으면 체크. 오른쪽 아래 타이머(분홍 판).
* 다 맞히면 **검은 화면에 만화 칸이 하나씩 들어오는 재연**, 아래 자막(핵심 낱말 노랑) **[확인 A 1:57:40~]**.

## 9. 투표·결과

**[확인 A 2:08:00~2:09:00]**
* 모노쿠마 「VOTING TIME」.
* **은색 금속 슬롯머신** 화면 : 얼굴이 그려진 릴 3 개가 돌고 멈춘다.
* 「Results」 : 금속 테두리 모니터 안 붉은 화면.
* 얼굴들이 둘레에 박힌 **룰렛 원판**(모노쿠마 색 띠).

## 10. 컷인·전환 연출

* **「Counter」 [확인 A 26:35]** : 붉은 주황 속도선 배경 + 화면 반을 덮는 **검은 붓글씨 「Counter」** + 주인공 얼굴이 대각선으로 크게 들어옴(소리 지르는 표정).
* **「GOT IT」 [확인 A 34:10, 1:35:10]** : 가로 파란 띠 + 검은 붓글씨 + 얼굴.
* **모노쿠마 끼어들기 [확인 A 1:15:50]** : 분홍 역삼각형 판에 모노쿠마.
* **두 얼굴 대비 [확인 A 2:05:00]** : 화면을 반으로 나눠 파랑·노랑 배경에 두 사람 얼굴.

## 13. 유메노쿠니 지금 상태와 크게 다른 곳 (이 문서 기준)

* 탐색·일상 : 2D 배경 위 그림 → V3 는 3D 방 1인칭 + 입상(§11). **가장 큼.**
* 일상 HUD·대사창 색 : 노랑·검정 사선 테마가 아님.
* 재판 대사 : 화자 카드(왼쪽 얼굴 + 첫 글자 큰 이름)·배경 「CLASS TRIAL」 흐름 글자·네온 테두리 선이 약하거나 없음. 대사창이 상자형.
* 논스톱 : 카메라가 화자 클로즈업 위주 → V3 는 원경·낮은 앵글로 여러 사람 함께. 조명 파랑 전환 없음. 글자 크기·여러 줄 쌓기·낱말별 크기 부족. HUD 의 증언 순서 점·탄창+△ 판 모양 다름.
* 패닉 : 직사각 기운 칸 + 컷인 그림 → V3 는 대각선 쐐기 + 실시간 카메라 + 칸 모양 따라 세로·대각 글자.
* 쇼다운 : 세로 분할·노란 장식 칸막이·칸막이 이동 없음.
* 스크럼 : 재판장 변형·빨강/파랑 화살표 탭 구성 확인 필요.
* 이론 무장 : 전용 무대·갑옷 모습 없음(재판장 위 UI).
* 애너그램 : 검은 구슬 + 빛 지나갈 때만 보이는 방식, 격자 배경 확인 필요.
* 클로징 : 자홍 만화책 화면·「?」 칸·페이지 수 구성과 다름.
* 투표 : 은색 슬롯머신·룰렛 없음.
* 컷인 : 붓글씨 「Counter」「GOT IT」 류, 「V」 폭발 없음.

> 이 목록은 「무엇을 볼지」의 기준이다. 실제 수치·타이밍·배치 좌표는 역분석 결과(사양서 18)로 확정한다.
