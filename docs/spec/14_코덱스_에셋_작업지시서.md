# 제작 사양서 14 — 코덱스 에셋 작업지시서 (⚠ 전체 스포일러)

> 대상 : 코덱스. 이 문서 하나로 **업스케일 → 스프라이트(포즈·캐붕) → CG(사망·처형·클라이맥스·서비스) → UI·언령 → 맵·배경 → 래피**를 순서대로 만든다.
> 사용자는 스포일러를 보지 않는다. 결과 보고에 범인·트릭·사망자를 적지 말고 **파일 경로와 개수만** 적는다.
> 세부 기준 문서 : 12(포즈·CG 목록) · 13(포즈 지시) · 05(연출·처형 스토리보드) · 06(에셋 목록) · 04(재판 UI) · 11(교칙) · `docs/design/*`(각본) · `docs/design/17_막간_서비스씬.md`(막간).

## 0. 공통 규칙 (모든 산출물)
1. **그림체** : `art/standing/{slug}.png`가 정답이다. 선·셀 채색·광택 피부·눈 표현을 그대로 맞춘다. 화풍 프롬프트 원문은 각 `{slug}.txt`.
2. **설정** : 머리색·머리 모양·눈 색·교복 색과 형태·소품·키·체형을 바꾸지 않는다. 안경 금지(전원).
3. **표현 수위** : 전원 미성년 포함. 노출·신체 부위 강조·성적 구도 금지. **피는 보라색**, 상처·절단·고통 묘사 금지. 시체는 쓰러진 실루엣·옷자락·손끝·소품 위주.
3-1. **체형 고정** : 포즈 컷에서 가슴·엉덩이·허벅지를 기준 입상보다 크게 그리거나 강조하지 않는다. 치마는 기준 입상 길이 그대로, 웅크림·앉기·무릎 꿇기는 무릎을 모으고 치마로 덮는다. 아래에서 올려다보는 구도 금지. (2차 검수에서 하루카 전 컷·아카리 X3 재작업)
3-3. **증언대·책상·소품 분리** : 스프라이트에는 증언대·책상·탁자를 그리지 않는다. 증언대는 3D 재판장에 따로 있다. T02(증언대 짚기)는 손을 가슴~허리 높이 앞으로 내밀어 짚는 동작만 그리고, 아래는 비워 둔다.
3-2. **12세 회상(K·R)** : 지금보다 **확실히 어린 아이**로 그린다 — 키 약 145cm, 머리가 몸에 비해 크고 둥근 얼굴, 큰 눈, 가는 팔다리, 아이 체형, 아이 사복. 17세 얼굴을 그대로 쓰지 않는다. 머리색·눈 색·대표 소품만 같게.
4. **형식** : 작업은 PNG, 저장소·게임은 WebP(`tools/pack_webp.py`가 같은 이름 .webp 생성, 큰 PNG는 git 제외). UI·아이콘은 PNG 그대로. 스프라이트·래피는 투명 배경. CG는 1920×1080. UI는 1280×720 기준 2배(2560×1440 캔버스 기준 좌표)로 그린다.
5. **진행 기록** : `art/MANIFEST.md`에 분류별 [완료/진행/남음] 개수와 경로를 갱신한다. 한 번에 다 못 하면 여기서 이어 한다.
6. **커밋** : 묶음마다 한국어 커밋 메시지. 대용량 원본(작업용 PSD 등)은 커밋하지 않는다.

### 2-1. 캐붕(반전) 연출 원칙
* 반전 컷은 **그 인물의 기본 인상과 정반대의 몸 쓰기**로 그린다. 기본 입상과 나란히 놓았을 때 "같은 사람인데 다른 사람 같다"가 목표.
* 단계 : **균열(미세)** → **붕괴(폭발)** → **잔해(체념·고요)**. 인물마다 최소 1컷씩.
* 쇼 : 침착 → 손을 숨기는 균열 → 이를 악문 붕괴 → 사진을 쥔 잔해.
* 아카리 : 단정 → 머리핀을 뜯는 균열 → 과호흡 붕괴 → 경례하는 잔해.
* 레이 : 무표정 귀족 → 커프스를 쥐어뜯는 균열 → 두 눈이 드러나며 소리치는 붕괴 → 무릎 꿇은 잔해.
* 사츠키 : 팔짱 → 떨리는 손 → 스카프를 내리고 절규, 그림자가 제멋대로 → 이름을 부르며 무너짐.
* 코토 : 다정한 미소 → **미소가 그대로 굳은 채 눈만 차가워짐**(가장 중요) → 붉은 실을 당기는 위압 → 아이처럼 우는 잔해 → 끊어진 실을 보는 고요.

### 2-2. 빙의 세트 (3장) — **남의 몸, 자기 몸짓**
* 3장 중반부터 재판까지 「켄」의 몸에는 **소라의 의식**이 들어 있다. 얼굴·머리·의상·키는 100% 켄, **표정·자세·손버릇은 100% 소라**.
* 소라의 몸짓 사전 : **왼손으로 인사**(소라 고유 버릇, 켄에게는 없음 — 가장 중요한 단서) / 엄지척 / 허리에 손 / 뒤통수 긁으며 헤헤 웃음 / 두 손 번쩍 놀람 / 간식을 내미는 손 / 다리를 벌리고 선 자세 / 이를 드러낸 큰 웃음 / 혼자일 때 텅 빈 무표정.
* 켄의 몸짓(빙의 중에는 **절대 나오지 않음**) : 한쪽 입꼬리 올린 미소 / 연극 인사 / 망토 펄럭 / 손가락 튕기기 / 반쯤 감은 눈.
* 세트 `ken_P01`~`ken_P12` (출력 `art/sprites/ken/`):

| ID | 장면 | 지시 |
|---|---|---|
| P01 | 빙의 직후 일상(미세) | 켄 얼굴, 입꼬리 미소 없이 **양쪽 입꼬리가 다 올라간** 헤헤 웃음 |
| P02 | 〃 | 블레이저를 망토처럼 걸치지 못하고 어깨에서 흘러내림, 어색하게 붙잡음 |
| P03 | 〃 | 무의식적 엄지척을 하다가 손을 내림(반쯤 접힌 엄지) |
| P03b | 〃 | **왼손을 들어 인사**(소라 버릇) |
| P04 | 수사 | 뒤통수 긁기 |
| P05 | 재판 초반 | 다리를 벌리고 허리에 손 — 켄답지 않은 운동부 자세 |
| P06 | 재판 : 몰림 | 두 손 번쩍 놀람(소라식) |
| P07 | 재판 : 변명 | 간식을 내밀 듯 손바닥을 내미는 제스처 |
| P08 | 재판 : 정체 직전 | 켄 얼굴에 **소라의 텅 빈 무표정** |
| P09 | 정체 발각 | 눈동자 아주 옅은 주황 기운, 소라의 큰 웃음이 울음으로 |
| P10 | 자백 | 켄의 몸으로 소라처럼 무릎을 끌어안고 웅크림 |
| P11 | 자백 끝 | 켄 얼굴로 소라의 "괜찮아, 맡겨!" 엄지척 + 눈물 |
| P12 | 처형 직전 | 마지막 한 장 : 켄의 미소가 한순간 돌아옴(눈빛 켄) |

* P01~P05는 **플레이어가 눈치챌락 말락**해야 한다. 과장 금지. P08~P11부터 확실하게.
* 실제 켄(빙의 전)의 몸짓과 비교 검수 : `ken_C01~C14`와 나란히 놓고 "켄이 하지 않을 행동"이 하나씩 들어 있는지 확인.

## 5. 맵 · 탐색 배경
