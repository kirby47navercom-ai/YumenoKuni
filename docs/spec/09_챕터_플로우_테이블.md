## 비트 JSON 예시
```json
{
  "chapter": 1,
  "beats": [
    {"type": "story", "scenes": ["11a:1-S1"]},
    {"type": "story", "scenes": ["11a:1-S2"], "require_cards": ["M1-01"]},
    {"type": "freetime", "session": 1, "slots": 2, "pool": ["B-1","B-2","B-3","B-4","B-5","B-6","B-7","B-8","B-9","B-10","B-11","B-12","B-13","B-14","B-15"]},
    {"type": "investigation", "minutes": 80, "areas": ["A1"], "required": ["E1-01","E1-02","E1-03"]},
    {"type": "trial", "steps": ["D-0","D-1:timeline","D-2:stream","D-3:stream"]}
  ]
}
```

## 규칙
* `story`는 장면 목록을 순서대로 재생. **필수 효과 목격(M카드)** 이 있는 장면은 `require_cards`로 보장(스킵 불가 마킹).
* `freetime` 풀 : 이벤트 라벨(①②③)과 인연 Lv 요구는 `data/events.json`(구현 시 생성)에서 판정.
* `investigation`은 장소 목록·필수 증거를 지정. 수사 종료 시 03 §6-3 규칙 적용.
* `trial` 단계 유형 : `timeline` `stream` `grid` `special:*` `query` `reconstruction` `showdown` `finale` `vote` `story`.
