## 1. 재판 전체 흐름
1. **집합 방송** → 재판장 입구(V3 : 「심판의 사당」 앞)로 모임.
2. **엘리베이터 하강** : 인물들이 대화하며 내려간다(시스템 화면 없음).
3. **재판장 입장** : 진행자 「증언대 앞, 자기 이름이 적힌 곳에 서세요」. 사망자 자리에는 **영정(초상)** 이 세워진다.
4. **개정** : 진행자가 규칙 설명(범인을 맞히면 범인만 처형, 틀리면 범인 외 전원 처형). 첫 재판에서만 튜토리얼이 이어진다.
5. **전반(Former)** : 20단계 안팎.
6. **휴정(Intermission)** : 전반·후반 사이 저장 지점. 휴정 후 영상 「Post-Intermission」. [미확인 : 휴정 화면 디자인]
7. **후반(Latter)** : 15~25단계. 「범인 지목(Identify the Person)」으로 범인이 특정된다.
8. **이론 무장(Argument Armament)** : 범인이 마지막으로 버틴다 → 「마지막 일격」.
9. **클라이맥스 추리(Closing Argument)** : 만화 컷으로 사건 전체 재구성 → 주인공이 끝까지 읽어 내리고 범인 이름을 부른다.
10. **투표** : 「앞에 있는 버튼을 눌러 투표하세요」. 투표 거부는 처벌 대상. V3에서는 플레이어가 직접 투표 버튼을 누른다.
11. **판결·자백** → **처형(Punishment Time)** : 「처형은 신성한 시간」, 방해 금지.
12. **챕터 클리어** : 장 클리어 기념품 획득. [미확인 : 재판 결과 점수 화면 세부]

## 2. 재판장 (3D)
| 항목 | 원작 사실 |
|---|---|
| 구조 | **원형으로 늘어선 증언대 16개**. 바닥은 동심원 고리 무늬(V3 1장 : 청록·파랑). 진행자 왕좌는 높은 단 위(붉은 의자·붉은 깃발), 뒤로 스테인드글라스 창(분홍·보라), 계단·난간 |
| 증언대 | V3 : 반투명 청록 유리 기둥형, 위에 이름판. 사망자는 증언대에 **초상 액자**가 선다 |
| 자리 순서 | 장 내내 고정. 진행자 정면 약간 오른쪽부터 시계 방향 |
| 장별 변화 | 재판장 장식이 **장마다 바뀐다**(예 : 극장풍 붉은 커튼·금색 기둥) |
| 인물 | **2D 입상(빌보드)이 3D 증언대 뒤에 서 있다**. 화면에 화자 외 다른 인물들도 함께 보인다 |
| 카메라 | 3D 카메라가 증언대 높이 근처에서 화자를 비추고, 화자가 바뀔 때 원을 따라 **휙 돌아간다**. 저각·사선 구도가 많다 |
| 변형 | 논의 스크럼 때 증언대들이 **움직여 두 줄로 마주 보는 통로**가 되고, 끝에 진행자가 보인다. 끝나면 원래 자리로 돌아간다 |

## 4. 단계 종류와 규칙
### 4-1. 논스톱 논의 (Nonstop Debate)
* 튜토리얼 원문(요지) : 인물들이 **쉬지 않고 연달아 말한다**. 거짓·모순을 찾아 **언령**으로 논파. 관련 언령이 **언령 탄창(Truth Cylinder)** 에 장전된다. **금색 글자 = 약점**을 노려라. 전부 논파할 수 있는 건 아니고 **맞는 언령**을 써야 한다. **시간이 다 되면 자동 실패**.
* **동의점(파랑)** : 그 발언이 옳음을 증명하는 언령을 쏘면 「동의」. V동의도 있다.
* **화이트 노이즈** : 화면을 떠다니는 잡음 문장(V3에서는 분홍·보라 계열 색). **언령은 노이즈에 닿으면 사라진다(막힌다)**. 사일런서로 쏘면 지워지고 **시간이 늘어난다**. V3에서는 일반 문장에 사일런서를 쏴도 벌점 없음. 노이즈 일부는 여러 번 쏴야 한다.
* **V포인트** : 집중 중 약점·동의점 안에 빨간 점 → 맞히면 V논파/V동의/V거짓. 점수·코인 보너스.
* **거짓 탄환** : 발사 버튼을 **누르고 있으면** 반대 의미의 거짓 언령으로 바뀌고, **떼면 발사**. 준비하는 동안 발언력 일부가 **표시(걸림)** 되고, 빗나가면 그만큼 잃고, 성공하면 회복. **각 재판에 거짓말이 필수인 논의가 1개**, 선택적 거짓말은 **뒷길(Back route)** 로 이어진다. 거짓말 가능 논의는 전용 BGM.
* 화면 : 3D 재판장 위로 큰 흰 글자가 원근으로 날아다니고 약점은 주황·금색. 왼쪽 위 화자 이름표(사선), 왼쪽 아래 언령 탄창 + 언령 이름, 오른쪽 아래 남은 시간.
### 4-2. 패닉 논의 (Mass Panic Debate)
* 세 명이 동시에 떠든다(「세 배의 의견」). 「정말 듣고 싶은 대화를 조준하고, 집중해서 더 잘 들어라」. 목소리가 엇갈려(대개 오른쪽→왼쪽) 나온다. 큰 소리가 다른 대화를 덮어 약점을 막을 수 있다 → 사일런서로 해제. V포인트 있음.
### 4-3. 선택형 3종
* **객관식(Multiple Choice)** : 질문 + 보기 3~4개. 가장 자주 나오는 단계(장당 5~10회).
* **언령 고르기(Choose Truth Bullet)** : 질문에 맞는 언령 1장을 고른다(장당 3~6회).
* **지점 고르기(Spot Selection)** : 그림의 한 곳을 고른다. 커서가 처음부터 정답 후보 위에서 시작한다.
* **인물 지목(Identify the Person)** : 인물 초상 중 한 명을 고른다(장당 1~3회, 범인 특정 포함).
* 정답이면 발언력 회복, 오답이면 감소.
### 4-4. 인터럽트 → 반론 쇼다운 (Rebuttal Showdown)
* 누군가 「잠깐!」 하고 끼어들면(인터럽트) **1대1 반론 쇼다운**. 언령은 **언령의 칼(Truth Blade)** 이 된다.
* 칼을 왼스틱으로 움직여 상대 발언에 각도를 맞추고 × 일반 베기, △ 언령의 칼 베기. 횟수 제한 없음. 대신 **조준 가능 범위(타원 궤도)** 가 우세할수록 넓어지고 밀리면 좁아진다.
* 베면 분위기가 내 쪽으로 기울며 **논의가 진행(발전)**, 놓치면 상대 쪽으로 기울며 진행이 되돌아간다. 팽팽해지면 **칼 맞대기(Blade Lock)** → × 연타.
* 한 번에 여러 문장을 베면 시간 보너스(두 개 2초, 세 개 3초…). 큰 글자는 여러 번 베어야 한다. 마지막에 약점이 나오면 맞는 언령의 칼로 벤다.
### 4-5. 논의 스크럼 (Debate Scrum)
* 의견이 두 편으로 갈리면 증언대가 움직여 **두 줄로 마주 선다**. 「논의 스크럼 START!」.
* 상대 편이 먼저 말한다. 우리 편 발언의 **키워드**는 보이고 상대 키워드는 숨겨져 있다. 상대가 말을 끝내기 전에 십자키로 맞는 우리 키워드를 골라 △로 받아친다 → 상대 키워드가 드러난다.
* 5~6합. 마지막에 화면 지시대로 **버튼 연타** → 「완전 논파」.
### 4-6. 섬광 애너그램 Ver.3.0 (Hangman's Gambit)
* 「**글자 구슬**을 올바른 순서로 골라 키워드를 만든다」. 글자는 어두워서 안 보인다. × = **섬광(flash spot)** : 화면 가운데에서 서서히 넓어지는 빛으로 구슬을 비춘다(집중력 소모). **비추는 동안에는 고를 수 없으니** 위치를 기억했다가 △로 집는다. 약 5초마다 **빛의 물결**이 화면을 가로질러 잠깐 보여 준다. 틀린 순서면 감점.
### 4-7. 발굴 이매지네이션 (Mind Mine)
* 「답을 파낸다」. 답 그림이 블록으로 덮여 있다. 왼스틱 커서, × 지우기. **같은 색 2개 이상이 이어져 있으면** 함께 지워지고, 이웃 블록 색이 **흰색→분홍→노랑→흰색** 순으로 바뀐다. 물체 위 블록을 다 지우면 그 물체를 고를 수 있다(△). 틀린 물체 = 발언력 감소. 마지막 외톨이 블록을 여러 번 눌러 부수면 시간 벌점. 제한 시간 있음.
### 4-8. 브레인 드라이브 (Psyche Taxi)
* 「흩어진 **글자 큐브**를 모아 질문을 완성한다」. × 가속, 왼스틱 좌우, R1 집중(장애물 회피). 다른 차와 부딪히면 집중력 감소(위키 : 길 가장자리·차 충돌 시 발언력 피해).
* 질문이 완성되면 **정답을 든 손님(길가에 선 여성)** 쪽으로 몰아 태운다. 오답 손님 = 나쁜 일. 장당 질문 3개 정도.
### 4-9. 이론 무장 (Argument Armament)
* 분노한 상대가 자기 주장으로 만든 **갑옷**을 두른다. 문장 위의 **리듬 표시**가 한 바퀴 돌 때 맞는 버튼으로 쏜다. 갑옷이 충분히 부서지면 **음악이 바뀌고 템포가 빨라진다**. 상대 입상의 장신구가 하나씩 떨어진다. 깜박이는 아이콘 = 모든 버튼 연타.
* **피버 타임** : 집중력이 가득일 때 R1 → 무적, 아무 버튼이나 OK.
* **마지막 일격** : 단어 4개가 ×△□○에 배정 → **올바른 순서**로 눌러 결정타.
### 4-10. 클라이맥스 추리 (Closing Argument)
* 사건 전체를 **만화**로 재구성. 빈 칸에 **아래 패널 목록**에서 그림 조각을 끼운다(맞는 조각만 들어감). 빈칸 힌트와 조각 힌트를 비교. 처음엔 고를 수 없는 패널이 있고, 앞 칸을 맞히면 열린다. L1/R1 페이지, □ 확대.
* 완성 후 애니메이션 만화로 재생되며 주인공 내레이션 → 범인 이름으로 끝.
