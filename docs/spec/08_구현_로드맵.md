## 4. 테스트 계획

### 4-1. 자동 검사(빌드 시)
| 검사 | 설명 |
|---|---|
| 장면 UID 유일성 | 중복 UID 없음 |
| 카드 참조 무결성 | 각 장 재판 표의 증거 ID가 모두 정의됨(`build_data.py` 리포트) |
| 필수 카드 획득 경로 | 03 §6-4 목록의 모든 카드가 수사 핫스팟·장면에서 `@give`로 연결됨 |
| 표정 맵 커버리지 | `emotion_map.json`의 모든 태그가 표정 ID에 매핑 |
| 코드블록 균형 | md 코드 펜스 짝 검사(이 저장소에서 이미 1회 발생) |

### 4-2. 수동 QA 체크리스트
- [ ] 각 장 정답 루트로 클리어 가능
- [ ] 각 장에서 **노트 승격 없이도** 클리어 가능(난이도 보정 포함)
- [ ] 마법 힌트 카드를 놓쳐도(이벤트 미시청) 질의로 클리어 가능
- [ ] 프리타임을 전혀 하지 않아도 클리어 가능
- [ ] 선택지 분기(A/B)별 후속 대사 일관
- [ ] 세이브/로드 후 재판 단계 복원
- [ ] 접근성(색약·번쩍임·텍스트 크기)
