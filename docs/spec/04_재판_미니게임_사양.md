# 제작 사양서 04 — 학급 재판 (V3 방식) 상세 사양

> **원칙 : 단간론파 V3 재판을 90% 그대로 따른다.** 아래 10종 외의 독자 미니게임(시간표 맞추기·알리바이 그리드·재구성 컷·피날레 컷 빈칸·병 추적·거울 길 찾기·평면도 간섭·시계 맞추기·서약선 해체·래피 질의 UI)은 **폐지**한다. 그 내용은 §13 변환표대로 V3 미니게임 안으로 옮긴다.
> 수치는 1차 값. 08 로드맵 M5 플레이 테스트로 보정한다.

## 1. 재판장

| 항목 | 사양 |
|---|---|
| 무대 | 장 공통 **원형 증언대 법정**(V3처럼 지하 엘리베이터로 내려가는 전용 재판장). 장마다 장식·조명 색만 바뀐다 |
| 배치 | 16개 증언대 원형 고정. 사망자 자리는 **영정 패널**(얼굴 사진 + 분홍 X). 3장은 영정 2개 |
| 카메라 | 화자에게 스윙(0.35s, 원형 궤도) → 바스트 샷. 발언이 이어지면 좌우 흔들림. V3식 사선 구도 |
| 래피 | 중앙 높은 왕좌. 재판 진행·규칙 설명·투표 진행 |
| 진행 | 의견 정리는 **대본 속 인물들**이 한다. 고정 사회자 없음(V3와 동일) |

## 3. 재판 흐름 (V3 표준)

```
개정(래피 규칙 설명) → 논스톱 논의 ① → 선택지·증거 제시 → 섬광 애너그램 / 발굴 이매지네이션
 → 논스톱 논의 ② (또는 패닉 논의) → 논의 스크럼(의견 분열) → 브레인 드라이브
 → 반론 쇼다운 진타 → 논스톱 논의 ③ → 이론 무장 → 클라이맥스 추리 → 범인 투표 → 자백 → 처형
```
* 순서는 장마다 바뀐다(§13). 단계마다 오토세이브.
* **선택지 / 증거 제시 / 인물 지목** : 미니게임 사이에 V3처럼 짧게 낀다. 「누가 할 수 있었지?」 → 인물 지목, 「그걸 증명할 건?」 → 증거 1장 제시. 오답 −1칸.

## 4. 논스톱 논의 (Nonstop Debate) + 거짓 탄환

| 항목 | 사양 |
|---|---|
| 화면 | 인물들이 차례로 발언. 발언 텍스트가 화면을 가로질러 **떠다니며**(직선·곡선·회전) 지나간다. 화자 바스트가 배경에 겹친다 |
| 약점 | **주황색 글자**(V3). 「논파」 대상. 정답 **언령(코토다마)** 탄환으로 쏜다 |
| 동의점 | **파란 글자**. 찬성 논의에서만. 찬성 탄으로 쏜다 |
| 소음 | 흰 글자 잡담(「배고파…」 등)이 약점을 가린다. 침묵 탄으로 제거, 집중력 +5 |
| 탄환 | 언령 최대 5발 장전. 수사에서 얻은 증거·증언·**교칙**·마법 카드가 언령이 된다 |
| **거짓 탄환** | 탄환을 길게 눌러 회전시키면 **반대 의미의 거짓 언령**으로 바뀐다(예 : 「문은 잠겨 있었다」 → 「문은 열려 있었다」). 정해진 장면에서만 정답. 쏘면 「위증」 연출 |
| 라운드 | 발언 한 바퀴가 1라운드. 시간 제한 내 반복 |
| 판정 | 정답 = 「그건 틀렸어!」 컷인 + 논파. 오답 = 화자 반박 + −1칸. 소음 맞춤 = 감점 없음 |
| 데이터 | §12-1 |

### 4-1. 다이내믹 연출 (V3 고유)
| 항목 | 사양 |
|---|---|
| **3D 글자** | 발언 글자가 3D 공간에 뜬다. 인물 **앞·뒤·옆**으로 지나가고, 비틀리거나(회전 ±35°) 원근으로 다가온다. 같은 문장 안에서도 단어마다 깊이가 다를 수 있다 |
| **감정별 글꼴·크기·등장** | 화자의 감정·상황에 따라 글꼴(§4-3)·크기(48~160px)·등장 방식이 전부 달라진다. 예 : 분노 = 굵은 붓글씨체가 화면 밖에서 **쾅** 떨어짐 / 겁 = 가는 손글씨가 **덜덜** 떨며 번짐 / 냉정 = 명조체가 **스르륵** 미끄러짐 / 장난 = 둥근체가 **통통** 튐 / 속삭임 = 작은 글씨가 화자 뒤에서 **흐릿하게** |
| 인물별 기본 글꼴 | 인물마다 기본 글꼴 1종(§4-3 표). 감정이 크게 흔들리면 감정 글꼴로 바뀐다 |
| **집중 추궁** | 재판 전개에 따라 의심받는 인물의 증언대가 **재판장 한가운데로 이동**하고, 나머지 전원이 원형으로 둘러싸 추궁한다(카메라가 중앙 인물 주위를 회전) |
| 스캔 없음 | 상대 발언을 미리 훑어보는 기능은 없다. 그 버튼에는 **거짓 탄환 모드**가 배정된다 |
| 침묵 탄 | 엉뚱한 곳에 써도 감점 없음 |
| **V포인트** | 집중력을 쓰면 약점 글자 안에 **빨간 점**이 보인다. 그 점을 정답 언령으로 맞히면 **V논파**(연출 강화 + 재판 평가 상승 + 래피 코인 보너스). 패닉 논의·거짓 탄환에도 적용 |

## 5. 패닉 논의 (Mass Panic Debate)
* **3명이 동시에** 떠든다. 화면이 세 칸으로 나뉘고 발언이 겹쳐 흐른다. 약점은 한 사람에게만.
* 나머지는 논스톱 논의와 같다. 집중력을 쓰면 한 칸의 소리가 크게 들린다.

## 6. 반론 쇼다운 진타 (Rebuttal Showdown)
| 항목 | 사양 |
|---|---|
| 1단계 | 상대 발언이 큰 글씨로 날아온다. 마우스로 **베어 낸다**. 다 베면 상대가 몰려 2단계 |
| 2단계(진타) | 상대가 더 빠르게 몰아친다. **진행(발전)** : V3처럼 상대의 공격 중 특정 문장을 베면 「발전」해 논의가 전환된다 |
| 마무리 | 약점 문장이 나오면 **언령의 칼(코토노하)** 로 벤다. 정답 칼을 고른 뒤 약점을 벤다 |
| 실패 | 베지 못한 문장에 맞으면 −1칸 |
| 연출 | 칼날 이펙트, 상대 발언 산산조각, 「베어 버린다!」 류 컷인 |

## 7. 발굴 이매지네이션 (Mind Mine)
* 화면을 색 블록이 덮고 있다. 블록을 클릭하면 **이어진 같은 색 블록이 함께 깨지고, 주변 블록의 색이 한 단계 바뀐다**(V3 동일).
* 깨진 자리 아래 **그림(단서 이미지)** 이 드러난다. 다 드러나면 그림 속 정답 부분을 클릭.
* 실패 = 블록이 다시 쌓여 화면을 덮을 때. 제한 시간 120s.

## 8. 브레인 드라이브 (Psyche Taxi)
* 미오가 래피 장식 차를 몰고 **네온 도로**를 달린다. 좌우 차선 이동, 가속, 점프.
* 1단계 : 길 위의 **글자를 모아 질문**을 완성(예 : 「범인은 왜 시계를 늦췄을까?」).
* 2단계 : 질문마다 **세 갈래 차선** 중 정답 차선으로 달린다. 오답 차선 −1칸, 장애물 충돌 시 감속.
* 질문 3~4개를 풀면 결론 대사.

## 9. 섬광 애너그램 Ver.3.0 (Hangman's Gambit)
* 어두운 화면에서 **글자 블록**이 떠다닌다. 손전등으로 비추면 보인다.
* 같은 글자를 **두 개 부딪혀** 하나로 만들고, 그 글자를 단어의 다음 칸에 넣는다(V3 규칙).
* 단어는 한국어 2~5음절(예 : 「되감기」「빙의」). 틀린 글자 −1칸.

## 10. 논의 스크럼 (Scrum Debate)
* 의견이 둘로 갈리면 증언대가 **좌우로 회전해 두 팀**으로 갈린다(V3 동일).
* 상대 팀 발언의 **키워드(주황)** 에 대응하는 우리 팀 인물의 키워드를 골라 받아친다.
* 6~8합. 전부 받아치면 「이게 우리의 답이야!」 연출. 시간 초과 −1칸.
* 갈등 연출의 중심. 어느 팀에 누가 서느냐가 그 장의 인간관계를 보여 준다(03 캐릭터 문서 파벌표 참조).

## 11. 이론 무장 (Argument Armament)
* 상대가 몰아붙이는 동안 **리듬 게임**(V3 동일) : 박자에 맞춰 버튼. 상대 게이지를 깎는다.
* 마지막에 **4개의 조각**이 사방에 뜬다. 정답 문장(증거 이름)이 되도록 순서대로 쏜다.
* 놓친 박자 −발언력.

## 11-1. 클라이맥스 추리 (Closing Argument)
* V3 그대로 **만화 패널**로 사건 전체를 되짚는다. 비어 있는 패널에 **아래 조각 그림**을 끌어 넣어 완성한다.
* 패널 8~12칸. 틀린 조각 −1칸. 완성되면 미오가 처음부터 끝까지 읽어 내린다(「이게 사건의 전말이야!」).
* ※ 「글자로 빈칸 채우기」가 아니라 **그림 조각 배치**만 한다.

## 11-2. 범인 투표
* V3식 **슬롯머신** : 생존자 얼굴이 도는 릴. 투표 후 래피가 결과를 발표.
* 다수결이 범인이 아니면 범인 외 전원 처형(규칙). 게임상 오답은 즉시 게임 오버.
