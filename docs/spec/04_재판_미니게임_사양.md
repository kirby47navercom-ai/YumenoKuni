# 제작 사양서 04 — 재판(학급 재판) 미니게임 상세 수치 · 상태머신 · 데이터

> 레퍼런스 : 단간론파 논스톱 토론 · 반론 쇼다운 · 논파 연출. 이름·판정은 본작 독자 설정. 모든 수치는 **1차 값**이며 08 로드맵 M5에서 플레이 테스트로 보정한다.

---

## 1. 재판장 구성

| 항목 | 사양 |
|---|---|
| 배경 | 장별 임시 법정(1장 연회장 / 2장 푸드코트 / 3장 극장 무대 / 4장 갤러리 / 5장 대연회장 / 6장 코어 홀) 3D풍 일러스트 + 원형 연단 |
| 인물 배치 | 생존자 수(6~16)를 **원형**으로 배치. 화자 지정 시 카메라가 해당 인물로 슬라이드(0.3s) + 상반신 컷인 |
| 영정 | 피해자 사진(장별). 3장은 2개 |
| 카메라 | `trial` 스타일. 논파 때 카메라 쉐이크 + 줌 1.2 + 배경 블러 |
| 사회 | 코토가 진행. 래피는 중앙 상단 |

## 2. 공통 수치

### 2-1. 집중력(HP)·마음(MP)
| 항목 | 값 |
|---|---|
| 집중력 | 100(스킬 보너스 가능). 하트 5개(20/개) |
| 오답 감소 | 논파 오답 −15 / 반론 쇼다운 실패 −20 / 시간 초과(스트림) −10 / 시간표·그리드·재구성 오배치 −10(3회째부터) |
| 회복 | 정답 연속 3회마다 +3 / 스킬 회복 / 단계 클리어 +5(최대 100) |
| 마음(MP) | 100. 스킬 사용 시 소모. 정답 +10, 반론 쇼다운 일격 +20 |
| 0이 되면 | 게임 오버 연출 → 체크포인트 재도전(02 §11) |

### 2-2. 난이도
| 항목 | Easy | Normal | Hard |
|---|---|---|---|
| 스트림 속도 | 100 px/s | 140 px/s | 180 px/s |
| 약점 표시 | 항상 노란 밑줄 | 노란 밑줄(깜박임 0.8s) | 표시 없음 |
| 오답 감소 | ×0.7 | ×1.0 | ×1.3 |
| 시간 제한 | ×1.5 | ×1.0 | ×0.8 |
| 힌트 | 2회 오답 시 자동 | 3회 오답 시 | 없음 |
| 코인 보상 | ×0.8 | ×1.0 | ×1.3 |

## 3. 재판 파이프라인(장 공통)

```
Opening → TimelinePuzzle(시간표 맞추기) → NonstopStream ×N → [Alibi Grid] → [Special Mini]
 → [Query(래피 질의)] → [Reconstruction] → RebuttalShowdown(반론 쇼다운) ×1~2 → FinaleCut(피날레 컷) → Vote → Confession → Execution
```
* 각 장의 순서·분량은 `docs/design/NNb_*수사_재판.md`의 D 섹션과 09 챕터 플로우를 따른다.
* 단계마다 오토세이브(체크포인트).

## 4. 시간표 맞추기 (TimelinePuzzle)
| 항목 | 사양 |
|---|---|
| 화면 | 가로 시간 축(눈금 5~10분 단위, 줌 가능) × 세로 장소/인물 행 |
| 카드 | 증거·증언 카드 6~12장. 하단 트레이에서 드래그 |
| 판정 | 정답 칸(허용 오차 ±2분) 근처에 놓으면 스냅. 오배치는 튕겨 나가며 −0(처음 2회) / −10(3회째부터) |
| 함정 칸 | 일부 장에서 "그럴듯한 오답 칸"을 둔다(예 : 2장 20:14 사망) |
| 완료 | 모든 카드 배치 → 하이라이트 연출 + 대사 3줄 |
| 시간 제한 | 없음. 평균 3~4분 |
| 데이터 | `{"cards":[{"id":"E1-04","slot":"22:50"}...],"trap":[...]}` |

## 5. 논파 스트림 (Nonstop Stream)

### 5-1. 화면
```
┌─────────────────────────────────────────────────────┐
│ HP / MP                                              │
│                                                      │
│  [화자 컷인(좌)]      ┌── 증언 문장 박스 흐름 ──┐         │
│                      │ ─▶ "회전목마가 고장 나서…" ─▶   │  레인 1 (y=240)
│                      │ ─▶ "타이가는 순찰대장이니…" ─▶   │  레인 2 (y=330)
│                      │ ─▶ "수동 모드는 카드가…" ─▶     │  레인 3 (y=420)
│                      └─────────────────────────┘         │
│  조준선 +                                                │
│ 탄환 슬롯 [E1-03][E1-02][...]                            │
└─────────────────────────────────────────────────────┘
```
### 5-2. 문장 박스
| 항목 | 값 |
|---|---|
| 크기 | 폭 520~640(글자 수에 따라) × 높이 84 |
| 이동 | 우→좌 직선(레인 3개 중 무작위, 같은 레인 연속 금지). 박스 간 최소 간격 180px |
| 속도 | §2-2 난이도 표 |
| 스폰 간격 | 평균 1.6s(문장 수와 속도로 조정) |
| 색 | 흰(일반) / **노란 마크(약점)** / **파란 마크(동의)** |
| 한 문장 안 약점 | 박스 안 특정 단어 1~2개에 노란 밑줄(클릭 판정 영역 단어 폭 +12px) |
| 루프 | 전체 문장 1바퀴를 1라운드, 최대 3라운드. 3라운드 후 놓친 약점이 있으면 −10 + 힌트 연출 |
| 일시정지 | 박스 클릭 시 해당 박스 **정지**(조준 상태). 정지 중 탄환 선택·발사 |

### 5-3. 판정
| 상황 | 결과 |
|---|---|
| 노란 약점에 **정답 탄환** | 논파 성공(§10 연출) → 해당 문장 폭발 → 다음 단계 대사 |
| 노란 약점에 **오답 탄환** | 오답 −15, 화자 반박 대사 1줄, 박스 재개 |
| 일반 문장에 탄환 | "…?" 코토 대사 + −5 |
| 파란 문장에 **동의** | 정답 +MP 5 |
| 파란 문장에 탄환 | −15 |
| 파란 문장 놓침 | 영향 없음 |
| 노란 약점 놓침(1라운드) | 영향 없음. 3라운드 후 −10 |

### 5-4. 데이터
```json
{
  "id": "1-D-2",
  "type": "stream",
  "rounds": 3,
  "statements": [
    {"speaker":"yuu","text":"회전목마가 고장 나서 사고난 거 아냐?",
     "weak":[{"word":"고장","bullet":"E1-03"}]},
    {"speaker":"haruka","text":"타이가는 순찰대장이니까 기계를 만지다 사고…",
     "weak":[{"word":"사고","bullet":"E1-02"}]},
    {"speaker":"kaede","text":"수동 모드는 카드가 필요해. 누군가 꽂았다는 뜻이지.","agree":true}
  ],
  "on_clear": "scene:1-D-2-clear"
}
```
* 각 장 문서의 표(`| # | 화자 | 문장 | 판정 | 필요 |`)가 위 `statements`로 1:1 변환된다(자동화 대상 : 08 M4).

### 5-5. 스킬 영향
| 스킬 | 효과 |
|---|---|
| 관찰(미오) | 약점 1개를 약하게 하이라이트(MP 15) |
| 되짚기 | 직전 문장 재생(MP 10) |
| 집중 | 제한 시간 +10초 |
| 연기 간파(켄) | 거짓 문장에 노란 마크 즉시(MP 15) |
| 앙코르(유우) | 스트림 1회 재생(MP 25) |
| 시간 관리(카에데) | 시간 +5% |
* 상세 목록은 `00_시스템_기획서.md` §6-3.

## 6. 반론 쇼다운 (Rebuttal Showdown)

### 6-1. 화면
* 상대(범인/반론자) 대사가 **위아래로 겹쳐 흐르는 거대 텍스트**(폰트 64px, 4~5줄). 중앙에 **칼날 게이지**.
* 플레이어가 마우스로 **텍스트를 가로로 베기**(드래그 방향 일치) 또는 `Space`로 타이밍 클릭.

### 6-2. 규칙
| 항목 | 값 |
|---|---|
| 줄 수 | 4~5줄 |
| 판정 윈도우 | 각 줄의 "절단 지점" 마커가 중앙 마커에 겹칠 때 ±0.35s |
| 성공 | 줄이 베여 흩어짐. 게이지 +20% |
| 실패 | 줄이 되돌아옴. 게이지 −10%, 반론 대사 |
| 일격 | 게이지 100% → 증거 선택 UI(최대 3개 중 택1, 정답은 "필요" 열의 증거) |
| 제한 시간 | 줄당 4s. 총 25~40s |
| 실패 처리 | 일격에서 오답이면 −20, 1회 재도전. 두 번 실패 시 코토 힌트 대사(스킬 「최후의 중재」로 면제) |
| 연출 | 베기마다 `sfx_slash` + 화면 번쩍. 일격은 시간이 느려지며 흰 배경 컷인 |

### 6-3. 데이터
```json
{
  "id": "1-D-9",
  "type": "showdown",
  "lines": [
    {"text":"저는 부상이 없습니다. 팔을 보세요.","hint":"E1-12"},
    {"text":"…혈흔은 제가 도운 환자의 것입니다.","hint":"T1-01"},
    {"text":"의학 지식이 있다고 범인은 아닙니다.","hint":"Q3,Q4"},
    {"text":"하지만 그 이유로 저를 의심하는 건…","hint":"E1-13"},
    {"text":"…이건 삐었을 뿐입니다.","final":true,"answers":["E1-08","E1-13"]}
  ]
}
```

## 7. 알리바이 그리드
| 항목 | 사양 |
|---|---|
| 화면 | 행 = 용의자, 열 = 시간대 3~5구간. 셀 크기 160×72 |
| 카드 | 증언 카드를 셀로 드래그 |
| 판정 | 정답 셀에 놓으면 초록 체크 + 증언 요약. 오답이면 튕김 −0/−10 |
| 모순 감지 | 완성 후 모순 셀이 **붉게 깜박**(예 : "쇼 22:50~23:20 TV 소리 = 증거 아님") |
| 완료 | 비어 있는 칸(= 범행 가능 시간)이 강조되며 대사 |
| 데이터 | `{"rows":["sora","rin","satsuki","sho"],"cols":["22:40~22:50","22:50~23:20","23:20~23:30"],"cells":[["T1-02","T1-03","-"],...]}` |

## 8. 재구성 컷 (Reconstruction)
| 항목 | 사양 |
|---|---|
| 화면 | 상단 컷 카드 8장(1장은 가짜), 하단 7칸 슬롯. 컷 카드 크기 240×150 |
| 규칙 | 드래그로 순서 배치. 가짜 컷을 슬롯에 놓으면 `sfx_wrong` + 컷이 흔들림 |
| 판정 | 모두 올바른 순서면 완료. 1장 오배치당 −0(2회) / −10(3회째부터) |
| 힌트 | 3회 오답 시 가장 이른 컷에 금 테두리 |
| 완료 연출 | 7컷이 순서대로 만화처럼 재생(컷당 2s) + 코토 요약 대사 |
| 스킬 | 설계도 읽기(오배치 1회 취소) / 매듭의 기억(1칸 고정) |

## 9. 래피 질의 (Query)

### 9-1. UI
```
┌──────────────────────────────────────────┐
│ 래피에게 질문할 수 있어요. 남은 횟수 ●●●○○   │
│                                          │
│ ▶ "철제 말 조형물을 비틀 수 있는 마법이 있나요? 누구의 것인가요?"  │
│ ▶ "타이가를 죽인 사람이 누구인가요?"                          │
│ ▶ "타이가의 마법은 무엇인가요?"                              │
│ [직접 입력 없음 / 최대 8개 선택지]                           │
└──────────────────────────────────────────┘
```
### 9-2. 규칙
| 항목 | 값 |
|---|---|
| 총 횟수 | 5회(스킬 「규칙 정리」 +1) |
| 소모 | 정답 질문 −1 / 오답 질문 −1(래피 "그건 질문이 아니에요!") / 힌트 질문 0(표시 "소모 0") |
| 선택지 | 8~10개. 정답 1~2개, 오답 4~5개, 힌트 1~2개 |
| 답변 | 마법 이름·소유자·규칙·시스템 기록. **사실(누가 했는지)은 불가** |
| 완료 | 답변이 **마법 카드/규칙 카드**로 수첩에 저장 |
| 데이터 | `{"id":"1-Q1","options":[{"text":"…","kind":"correct","answer":"scene:1-Q1-a","give":["M1-03"]},{"text":"…","kind":"wrong"},{"text":"…","kind":"hint","cost":0}]}` |

## 10. 논파 연출 (성공 시)
| 순서 | 연출 | 시간 |
|---|---|---|
| 1 | 탄환 발사음 + 슬로 모션 0.2s | 0.2 |
| 2 | 대상 문장 박스 파괴(유리 깨짐) + 흰 플래시 | 0.3 |
| 3 | 화면 가운데 "논파!" 텍스트가 **쾅** 하고 뜸(폰트 128, 테마색, 쉐이크) | 0.6 |
| 4 | 플레이어(미오) 컷인 : 증거 이름과 한 줄 대사 | 1.2 |
| 5 | 대상 인물 반응 컷인(놀람/침묵) | 1.0 |
| 6 | BGM 피치 업(+0.2) 1바 | 2 |
* **실패 연출** : 탄환이 튕김 + 화면 붉은 가장자리 + 화자 반박 컷인 + HP 하트 깨짐.

## 11. 피날레 컷 (Finale Cut)
| 항목 | 사양 |
|---|---|
| 구성 | 8컷 만화 패널(각 960×540). 컷 사이 슬라이드 |
| 입력 | **빈칸 채우기 2~3컷** : 각 컷에 3지선다(예 : 쇼가 도움을 요청한 장소) |
| 판정 | 정답이면 컷이 완성되며 컬러로 채색. 오답은 −10 |
| 연출 | 컷마다 흑백 → 컬러 전환, 효과음, 래피 나레이션 |
| 마지막 컷 | 범인 표정 클로즈업 → 투표 연출로 연결 |
| 데이터 | `{"panels":[{"id":1,"img":"fin_1_1","blank":false},{"id":4,"blank":true,"choices":["회전목마","푸드코트","호텔"],"answer":0}]}` |

## 13. 특수 미니게임 6종

### 13-1. 1장 「회전목마 로그 맞추기」 (입문)
* 시간표 맞추기의 단순화 버전. 로그 3줄(23:12 가동 / 23:19 정지 / 22:50 일지)을 제어반 인쇄물 위 칸에 배치. 오답 허용 3회.

### 13-2. 2장 「병 추적」
* 지도 4지점(의무실 / 매점 / 호텔 라운지 / 쓰레기통)을 선으로 연결해 **병·앰플 이동 경로**를 그린다.
* 선 시작·끝 지점 카드(E2-04/05/06/T2-05)를 연결. 경로 일치 시 완료. 오배치 −0/−10.

### 13-3. 3장 「거울 길 찾기」
* 극장 평면도 위에 인물별 경로(소라 본체 / 켄 / 리쿠)를 **색 선으로 연결**. 켄의 선이 **21:30 이후 주황색으로 변하는** 연출(소라 의식 이동).
* 정답 경로를 모두 그리면 완료. 선 시작/끝 오류 −0/−10.

### 13-4. 4장 「평면도 간섭」
* 4종 도면(수첩 지도 / 포스터 / 린 측정 / 노트 N4-01)을 **레이어 슬라이더**로 겹쳐 불일치 영역을 찾는다.
* 불일치 영역(리넨 창고 → 505호)을 클릭하면 붉게 표시. 레이어 4개 모두 겹칠 때 완료.

### 13-5. 5장 「시계 맞추기」
* 시계 3개(서고 / 카에데 손목 / 시계탑)의 바늘을 돌려 **같은 시각**에 맞추고 차이(40분)를 확인.
* 완료 시 "서고 시계는 40분 느림" 카드가 자동 생성.

### 13-6. 6장 「서약선 해체」
* 미오의 손목·코토의 완장에 표시된 선 5개를 **인물 카드(나나·레이·아카리·사츠키·미오)** 와 연결.
* 연결 시 선이 이름으로 변하며 화면 중앙으로 수렴.
