# 제작 사양서 25 — 재판 줄마다 연출표 (2026-11-04, Claude)

주인님 지시 : 돌아가는 연출만이 아니라 재판 속 대화까지, 인물·상황에 맞게 한 줄씩 연출한다. 문장부호(!·?)로 기계적으로 고르지 않는다.

## 파일
* 원본 `data/v4_story/trial_direction.json`, 게임 사본 `Game/Assets/Data/v4_story/trial_direction.json`.
* 장별 작성 스크립트 `tools/trial_direction_ch<N>.py` — 대사를 읽고 줄마다 직접 정한 값. 돌리면 원본·사본을 갱신하고, 실제 줄 id 가 아닌 항목은 버린다.
* `debate[<논스톱 줄 id>]` : `pose`(C01~C14·T01~T04·U1~U6, 사양서 12), `motion`(Debate.hpp 이름), `yaw`(원근 판 각도), `shot`(Courtroom SHOTS), `fx`(shake·swirl·punch), `size`, `font`, `se`.
* `queue[<eventId>]` : 재판 중 대화 줄의 `pose`·`fx`·`se`.

## 게임 쪽
* `Game/Source/TrialDirectionV4.hpp` 가 읽는다. `Yumeno.cpp` 논스톱 줄 만들 때·`styleLine`, `V4Tasks.hpp` 대화 줄.
* 연출표가 없는 줄만 예전 추측(문장부호) 연출을 쓴다.
* 글자 : 낱말마다 무작위 크기 없앰(약점·동의 낱말만 1.3배), 외침(burst)은 화자 위 둥근 띠로 좌→우 읽힘, 통통 튀기는 낱말 단위로 작게, 두 줄 발언은 위로 올림.
* GPU 글자 : 통째 묶음(rig) 경로를 껐다(`GpuTrialHudV4.hpp motion()`). 줄이 바뀔 때 앞줄 글자 그림이 남아 한글이 깨졌다(「그럼」→「피일」).
* `font` 를 바꾸면 GPU 글자판 굽기(`v4-gpu-trial-assets.mjs`·`v4-gpu-trial-batches.mjs`)도 같은 표를 읽는다. 깨짐 원인은 글꼴이 아니라 통째 묶음 경로였다 — 글꼴 지정은 다시 켰다(29줄).

## 함정 약점·동의점(노랑·파랑) — `tools/trial_decoys.py`
* 근거 : V3 STX 색 태그(`chap*_text_US/c0?_2??_00?.stx`). 노랑 `cltWEAK` 364곳·파랑 `cltAGREE` 108곳. 논스톱 86개 중 노랑 자리 1곳 26·2곳 22·3곳 6·4곳 8…(평균 2.7). 파랑은 57개 논의에 없음, 있으면 1~5곳.
* 노랑이 붙는 말 : 상대 주장 속 짧은 핵심 명사구·짧은 주장. 파랑 : 본 사실·증언.
* `debate[<줄 id>].decoy = {kind, word}` 로 논의마다 직접 고름(노랑 101·파랑 22). 게임은 정답 없는 약점으로 만든다(`answer="decoy:none"`) — 맞히면 오답(RE 04_재판), `cleared()` 는 함정을 세지 않는다.

## 잡음(분홍) — `tools/trial_noise.py`
* 근거 : V3 논스톱 DAT(`trial_data/.../nonstop_0?_US/nonstop_*.json`) 행의 `u16[6]==1` 이 잡음 행(묶음 `u16[1]=65535`, 글 500번대, 시간 `u16[10]=0`, 자리 `u16[3]` 0/1/2).
  58개 중 48개 논의에 있고 평균 9.5행. 1장 앞 5개·6장 끝 3개는 0. 글은 곁 인물의 짧은 반응·되묻기·화제 낱말(새 사실·정답 없음).
* `noise[<과제>] = [{id, actor, speaker, text}]` 474줄·63개 논의(1장 A06부터 5줄, 2장 7, 3장 8, 4~6장 9 — Codex `v4_trial_noise.json` 줄과 합쳐). 6장 끝 T6-NS-01·T6-LIE-01 은 비움. 미오는 잡음을 내지 않는다.
* 게임 : `Yumeno.cpp startDebate` 가 논의 줄 뒤에 잡음 줄을 붙인다(`noiseGroup`=자기 id, 화자 자리와 무관하게 돈다).
* 잡음 통째 그림(`gpunoisehudv4` rig)은 껐다. rig 는 예전 크기(.9·Z1250)로 구워져 지금 `Debate.hpp`(1.25·Z860)와 어긋난다. `v4-gpu-noise-assets.mjs` 의 확인 값도 지금 값으로 맞췄다.
* 순서 : `trial_direction_ch*.py`(save) → `trial_decoys.py` → `trial_noise.py`.
