## 2. 추정이 들어간 것

* 374 를 쇼다운 「전진(Advance)」 피드백에 썼다 — 3f69c0 의 case 9 에서 부르지만 그 상태가 전진인지는 확인하지 못했다.
* 342(15초)·378(2초)은 원작에서 반복 재생(루프)이지만 엔진 `Audio::Play` 는 한 번만 튼다. 장전이 15초, 힘겨루기가 2초를 넘으면 소리가 먼저 끝난다.

## 3. 아직 연결하지 못한 것

* 논스톱 시작(「논스톱 논의」 붓글씨·탄환 장전)의 소리 — 역분석에 V3_SE 호출이 없다(연출 클립 안에 들어 있을 수 있음). 지금은 1편 효과음 그대로.
* 재판 결과 화면 320·321·322·052(3da1c0), 클라이맥스 시작 447·완성 448, 스크럼 마지막 단계 시작 366 — 가져오기는 했으나 해당 화면의 시점 연결이 남았다.
* 일상 장면(e01~e06, 600~887번)의 장면 효과음 — 대본(WRD) 의 `SE_` 명령과 우리 원고의 장면이 1:1 이 아니라 아직 손대지 않았다.
