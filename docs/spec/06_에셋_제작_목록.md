## 2. 스프라이트 (입상)

| 항목 | 수량 | 비고 |
|---|---|---|
| 교복 × 표정 10종 | 16명 × 10 = **160** | 기준 입상에서 상반신 크롭+표정 변형 |
| 수영복 × 표정 4종(neutral·smile·surprise·sad) | 14 × 4 = **56** | 2장 |
| 여름 사복 × 표정 4종 | 14 × 4 = **56** | 2장 |
| 연극 의상 × 표정 3종 | 5 × 3 = **15** | 3장 |
| 래피 | 표정 8종 + 노이즈/반투명 변형 4종 = **12** | 장별 눈 하이라이트 변화 |
| 시체 일러스트(실루엣) | 장당 1~2 = **7** | 유혈 없음 |
| 컷인(표정 강조 상반신 확대) | 인물당 3종 = **48** | 05 §2 |
| 합계 | **약 350장** | |
* **제작 방식** : `tools/generate_tpose_nai.py`의 `CHARACTERS` 프롬프트를 기반으로 **표정 태그만 교체**하여 NovelAI로 생성(또는 인페인팅). 코덱스에게 "표정·의상 변형 지시문"을 맡긴다(별도 문서 필요 시 `docs/spec/11_스프라이트_변형_지시문.md`).
* **표정 프롬프트 모듈** : `smile` = `smile, closed mouth` / `serious` = `serious, slight frown` / `surprise` = `surprised, open mouth, wide eyes` / `sad` = `sad, teary eyes` / `worry` = `worried, looking away` / `anger` = `angry, clenched teeth` / `closed` = `closed eyes` / `whisper` = `whispering, hand beside mouth`.

## 9. 제작 파이프라인

```
[1] 스타일 바이블 확정(이 문서 §1)
[2] 입상 생성 : generate_tpose_nai.py (기준 17장) → 표정/의상 변형(코덱스·NovelAI)
[3] 배경 : Blender 모델링 → 파노라마 렌더 → 핫스팟 좌표 지정(03)
[4] UI : 피그마(또는 이미지 편집) → 엔진 테마 리소스
[5] 사운드 : 외주/AI 작곡 → 루프 편집 → 큐 시트(05 §7)
[6] 통합 : data/ + assets/ 를 엔진에서 로드, 누락 에셋은 플레이스홀더로 자동 대체
```
* **플레이스홀더 규칙** : 누락 파일은 `placeholder_*.png`(색 블록 + 파일명)로 대체해 개발을 막지 않는다.
