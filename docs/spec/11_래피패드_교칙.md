# 제작 사양서 11 — 래피 패드 · 교칙

> V3 모노패드에 해당. 프롤로그에서 래피가 나눠 준다. 화면 구성은 02 UI 사양(8탭)을 따르고, 이 문서는 **교칙 탭의 본문**을 확정한다.
> 교칙은 재판에서 **언령(탄환)** 으로 쓸 수 있다. 문구 하나하나가 사건 논리에 쓰이므로 바꿀 때는 해당 장 각본을 함께 검수한다.

## 1. 패드 기본
| 항목 | 내용 |
|---|---|
| 이름 | 전자 래피 수첩 (줄여서 「래피 패드」) |
| 외형 | 분홍 토끼 귀 모양 상단, 화면 좌상단에 장 표기, 우상단에 래피 마크 |
| 켜기 | 탐색·일상 중 `Tab`. 재판 중에는 언령 확인만 가능 |
| 본인 인증 | 켜면 소유자 이름이 뜬다. 다른 사람 패드는 켜지지 않는다 |

## 4. 주의 (각본 검수용)
* **교칙 3 「낮잠」** 은 2장 이후 「객실 밖에서 쓰러져 있던 사람」 논의에서 반론 근거로 쓸 수 있다. 사건 논리를 바꾸지 않도록 대사로만 언급한다.
* **교칙 9** 는 6장 회수용이다(떡밥 장부 F-17 참조). 패드를 「부수면 안 되는」 진짜 이유가 최종장에서 밝혀진다.
* **교칙 10** 은 4장 핵심 언령이다. 기억은 바뀌어도 기록은 바뀌지 않는다.
* R-06은 결번이었으므로 교칙 번호 체계로 대체한다. 데이터 ID는 `R-01`~`R-14`를 유지하고, 신규는 `R-15`~`R-19`로 붙인다(교칙 2·3·4·9·11·12 중 R-08 선행분 제외 순서대로 : 교칙 3=R-15, 4=R-16, 9=R-17, 11=R-18, 12=R-19, 교칙 2=R-20).
