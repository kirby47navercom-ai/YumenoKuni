# 제작 사양서 24 — 재판 연출·글자 간격 수정 (2026-11-04, Claude)

Codex 변경과 같은 파일에 섞인 수정은 따로 커밋할 수 없어, 무엇을 바꿨는지 여기 적는다. 확인은 `Game/tools/record-trial-directions.mjs` 로 실제 게임 화면·소리를 녹화해서 했다(`연출 영상/claude/`).

## 글자 간격 (실제 글꼴 폭)
* `tools/glyph_metrics.py` → `Game/Source/GlyphMetricsV4.hpp` : 게임 글꼴 21개의 글자 폭(em) 표. 글꼴을 바꾸면 다시 돌린다.
* `Debate.hpp` : `em(g,font)`·`lineCount()`. 논스톱 줄 배치와 패닉 글자(`36*1.3f` 실측 간격)를 글꼴 폭으로.
* `V4Showdown.hpp` : 쇼다운 발언 글자 간격 = 글꼴 폭 × 36px × 1.45.
* `Yumeno.cpp` : 발언 줄에 글꼴(`x.font`)을 넣고 `spacing=1`.
* `Pad.hpp`(증거)·`PadReportV4.hpp`·`PadRulesV4.hpp`·`PadSystemV4.hpp`(`padsystem::wrap`)·`TrialPickerV4.hpp`·`TrialRunner.hpp`(추리 질문·선택지) : 줄 나누기·칸 높이를 실측 폭으로.
* `Game/tools/v4-gpu-panic-assets.mjs` : 패닉 GPU 글자 굽기가 같은 폭표를 읽는다(전에는 46px 고정).
* 패닉만 다시 구우면 GPU 재판 자원 순서가 어긋나 쇼다운이 `map::at` 으로 꺼진다 → `Game/tools/claude-regen-gpu-after-panic.mjs` 로 `--gpu-trial-finalize` 순서 전체(최적화 제외)를 다시 돈다.
