# 제작 사양서 13 — 코덱스 포즈 제작 지시서 (⚠ 스포일러 포함)

> 대상 : 코덱스(Codex). 기준 입상 1장(NovelAI 생성·4배 업스케일)을 **원본 그대로의 그림체**로 유지하면서 여러 동작 스프라이트를 만든다.
> 포즈 목록·의미 : `docs/spec/12_스프라이트_포즈_CG_목록.md`. 태그 원본 : `art/poses.json`.

## 1. 입력
| 항목 | 경로 |
|---|---|
| 기준 입상(얼굴·복장·색의 정답) | `art/standing/{slug}.png` (4배 업스케일본, 약 3328×4864) |
| 포즈 ID와 동작 설명 | 12 문서 §1~§3, `art/poses.json` |
| 인물 성격·버릇 | `docs/design/01_캐릭터_스토리_자유시간.md`, 12 문서 §2 「몸짓 버릇」 |

## 2. 반드시 지킬 것
1. **그림체 보존** : 선 굵기, 채색(단간론파 / 코마츠자키 루이풍 셀 채색), 눈 그리는 법, 하이라이트 색을 기준 입상과 똑같이.
2. **설정 보존** : 머리색·머리 모양·눈 색·교복 색과 형태·소품(미오 손목 수첩, 레이 커프스, 나나 손목 리본 등)을 바꾸지 않는다. 키와 체형 비율 유지.
3. **구도** : 스프라이트는 허벅지 위(cowboy shot), 정면, 흰 배경, 투명 PNG로 배경 제거. 캔버스 2048×2048, 머리 꼭대기 y≈120, 몸 중심 x=1024 정렬(대화창에서 인물이 튀지 않게).
4. **성격이 보이는 동작** : 같은 감정이라도 인물의 버릇으로 표현(예 : 레이의 놀람 = 커프스를 쥐며 한 걸음 물러섬, 소라의 놀람 = 두 손을 번쩍).
5. **표현 기준** : 노출·신체 부위 강조 금지(미성년 포함). 피는 보라색만.
6. **안경 금지**(전원).

## 3. 산출물
```
art/sprites/{slug}/{slug}_{포즈ID}.png     예) art/sprites/rei/rei_T01.png
art/sprites/{slug}/sheet.png               전 포즈 한 장 미리보기(6열)
```
* 우선순위 : 12 문서 §4 순서(프롤로그·1장 등장 전원 C01~C14·T01 → 1장 반전 세트 → 장 순서).
* 반전 세트(X)는 해당 인물의 **기본 인상이 무너지는 대비**가 핵심. 기준 입상의 차분한 표정과 나란히 놓았을 때 확 달라 보여야 한다.

## 4. 검수 체크
- [ ] 기준 입상과 나란히 놓았을 때 같은 사람으로 보인다
- [ ] 소품·색 누락 없음
- [ ] 정렬 기준(머리 y, 중심 x) 일치
- [ ] 같은 인물의 포즈끼리 손 모양·몸짓이 겹치지 않는다
