## 1. 화면 문법 (스크린샷 관찰)

### 1-1. 탐색(1인칭)
| 위치 | 요소 | 본작 구현 |
|---|---|---|
| 화면 중앙 | 노란 작은 원 조준점. 조사 가능 물체 위에 오면 커지며 이름표 | `Cross` + `CrossName` |
| 화면 가장자리 | 반투명 시점 화살표 ‹ › ˄ ˅ (돌아보기) | 좌우 팬(배경 1920폭을 1280 화면에서 좌우로 돌림) |
| 좌상단 | 구역 아이콘(노란 건물+햇살) + 노란 평행사변형 띠에 **현재 장소 이름** | `AreaIcon` `AreaName` |
| 우상단 | 노란 모노쿠마 머리 아이콘 + 「Chapter N」 + 「Level n」 + 노란 경험치 막대 | 래피 머리 + 「N장」 + 「Lv」 + 막대 |
| 우하단 | 마름모(45° 회전 사각) 미니맵 : 방 배치, 내 위치 화살표, 출입구 | `MiniMap` |
| 방 안 | 인물은 **작은 전신**으로 바닥에 서 있다(3D 공간 속 2D). 다가가 말을 건다 | 전신 입상 축소 배치 |
| 물체 | 조사 시 짧은 독백, 단서면 언령 획득 연출. 물체를 「때리면」 모노코인이 튄다 | 우클릭 = 두드리기(코인) |

### 1-2. 대화
| 요소 | 관찰 | 본작 |
|---|---|---|
| 대화창 | 화면 하단 폭 ≈ 80%, 반투명 검정, 왼쪽 끝이 사선. 흰 글씨 2줄, 왼쪽 정렬 | 기존 frame.png 유지, 글씨 영역 여백 고정 |
| 이름표 | 대화창 왼쪽 위에 겹쳐 **기울어진** 이름. 첫 글자만 인물 색 | `Name` 첫 글자 색 |
| 넘김 표시 | 대화창 오른쪽 아래 노란 「≫」 깜빡임 | `Next` |
| 우상단 | 대화 중에도 「Chapter / Level」 표시 유지 | `FHud` |
| 인물 | 화면 가운데 상반신. 말하는 사람만. 주인공은 그리지 않음(1인칭) | 기존 |
| 컷인 칸 | 여러 명이 반응할 때 화면을 **사선 칸**으로 나눠 동시 표시(네온 글씨 배경) | `Panel` 사선 2~3칸 |
| 독백 | 이름표 없음, 글씨색 하늘색 | 기존 |

### 1-3. 재판(15번 보강)
* 렌즈형 비네트(동심원), 좌상단 화자 이름(이탤릭 + 점선), 우상단 STATUS 기울어진 패널(하트·별), 좌하단 탄창 + 기울어진 언령 이름표(「Monokuma File 1 / Truth Bullets」 두 줄), 우하단 주황 디지털 타이머 `04:43:450`.
* 발언은 큰 세리프 흰 글씨, 약점은 주황. 화면에 흰·빨강 사각 조각이 떠다닌다.
* **선택지·언령 고르기 화면에 단색 박스 목록을 쓰지 않는다.** V3는 질문 띠 + 화면 오른쪽에 기울어진 카드 목록(언령은 카드 그림), 고른 카드가 커지며 「이거야!」.

## 2. 일상 파트 흐름 (V3)

1. **아침 방송** : 모니터 화면(래피) 「딩동댕동」 차임 → 아침 인사 → 기상. 방(개인실)에서 시작.
2. **스토리 이벤트** : 정해진 장소로 이동하면 진행(목적지 표시). 여럿이 모인 장면은 컷인 칸·카메라 흔들림.
3. **자유행동(자유 시간)** : 「자유행동」 띠가 화면을 가로지른다. 하루 보통 2번.
   * 패드 지도에 **인물 얼굴 아이콘**이 있는 장소가 표시된다 → 그 장소로 가서 인물에게 말을 건다.
   * 「○○와 함께 시간을 보낼까?」 [예/아니오] → 짧은 암전 + 「자유행동」 표지 → 이벤트(선택지 포함).
   * 이벤트 끝 : 「선물을 줄까?」 → 선물 화면(왼쪽 인물 상반신, 오른쪽 아이콘 격자, 아래 설명). 반응 대사(좋아함/보통/싫어함).
   * 「○○의 통신부가 갱신되었다」 + 스킬 획득 띠.
   * 이벤트를 다 본 인물에게는 짧은 대화만(시간 안 씀).
4. **모노모노 머신(캡슐)** : 매점 기계. 코인 넣기 → 레버 → 캡슐 낙하·열림 → 선물 획득.
5. **동기 발표** : 체육관/집합 → 래피 등장 연출.
6. **밤 방송** : 「야간 시간」 안내 → 방으로.

## 3. 수사 파트 흐름 (V3)

1. **시체 발견** : 문을 열거나 돌아보는 순간 정지 → 날카로운 효과음(쾅) + 화면 붉은빛 번쩍 → **시체 CG**(사인·상처 부위가 보이게) → 주인공 충격 컷 → 3명 이상 목격 시 **시체 발견 방송** 「시체가 발견되었습니다! 일정 시간 수사 후 학급 재판을 엽니다!」(전용 차임).
2. **모노쿠마 파일(래피 파일)** 지급 : 화면 중앙에 파일 카드 + 「언령 획득」.
3. **수사 개시** 띠 → 자유 탐색. 현장은 시체 주변을 조준해 조사(머리·손·주변 물건 각각 따로).
4. **언령 획득 연출** : 카드가 회전하며 중앙으로 → 「언령 ○○를 손에 넣었다」 → 패드 언령 목록에 「NEW」.
5. 증언 : 인물에게 말을 걸면 증언 → 증언 카드.
6. **수사 종료 방송** → 빨간 문 앞 집합 → **엘리베이터 하강** 연출(철창 사이로 빛이 지나감, 독백) → 재판장 도착.
7. 재판 → 투표 → 「처형」 표지 → 처형 영상 → 재판 후 대화(슬픈 피아노) → 막간.

## 4. 패드(모노패드) 메뉴

지도 / 언령 / 교칙 / 통신부(인물별 인연 페이지·프로필) / 스킬 / 소지품(선물) / 설정·저장.
화면 : 패드 테두리 그림 안에 왼쪽 세로 탭 아이콘, 오른쪽 내용. 탭 전환 효과음.

## 5-2. 화면별 실측 (위키 스크린샷 300여 장 관찰, 1280×720 기준 비율)

### 패드(모노패드)
* 아래쪽에 **둥근 아이콘 6개 가로 줄**(지도·언령·선물·통신부·교칙·설정). 고른 아이콘만 크게 + 빛 번짐, 새 내용은 위에 「!」.
* 위쪽 머리 띠 : 왼쪽에 주인공 만화풍 얼굴, 가운데 **큰 제목(MAP / PRESENT / SCHOOL RULES)** + 말풍선 설명, 오른쪽 큰 원 안에 고른 아이콘.
* 오른쪽 세로 띠 : 「COINS 500」 · 「MONO PAD」 · 학원 이름. 아이콘마다 **테마색**(지도 빨강, 선물·교칙 파랑…)으로 화면 전체가 물든다.
* 오른쪽 아래 「확인 / 돌아가기」.

### 통신부(인연)
* 위 : 인물 실루엣 16칸 가로 줄(Q/E로 넘김, 고른 사람만 색).
* 이름 큰 장식 글씨 + 꽃 아이콘, 왼쪽 세로 단계 0~5(와 ✿), 가운데 정보 칸, 오른쪽 큰 입상.

### 지도
* 파란 도시 배경 위 **아이소메트릭 층 평면도**(흰 회색 블록, 방마다 그림 아이콘, 출입구 분홍 줄무늬).

### 탐색
* 조준점을 물체에 대면 화면 아래 가운데 **노란 평행사변형 이름표**(「모노모노 머신」), 위아래 작은 화살표.
* 좌상단 장소 아이콘 + 노란 띠 이름, 우상단 Chapter·Level 막대, 인물은 공간 속 작은 전신.

### 재판
* **객관식** : 화면을 어둡게, 좌상단 「1 CLASS TRIAL」 문장(紋章), 형광 초록 이탤릭 「Answer」, 보기는 오른쪽으로 길게 뻗는 **번호 띠**(「1/ 보기」), 고른 띠만 파랗게. 왼쪽 분홍 모래시계 + 주황 타이머, 기울어진 화자 이름표, 아래에 질문 대사(하늘색 글씨). 「확인」 표시.
* **언령 고르기** : 왼쪽 세로 목록(세로 선 + 점, 고른 것 강조), 뒤에 큰 탄창 그림, 오른쪽 위 카드 사진, 오른쪽 아래 제목 + 설명. 화자 입상 가운데, 배경에 네온 「CLASS TRIAL」.
* **지점 선택(Spot Selection)** : 현장 사진을 화면 가운데 큰 액자로, 녹색 십자선 커서, 좌상단 기울어진 제목.
* **인물 지목(Accuse)** : 좌상단 「Accuse」, 지목 대상 입상 + 「11 Kaede Akamatsu」 번호·이름 장식, 발밑 분홍 고리.
* **애너그램 완성** : 「GOT IT」 붓글씨 컷인(청색 띠 + 주인공 얼굴), 완성 글자 칸 「V E N T」 좌상단.
* **반론** : 왼쪽 큰 상대 얼굴, 왼쪽 아래 「???」 위증 칼날 목록, 오른쪽 아래 언령 칼 목록(세로로 겹친 띠).
* **이론 무장** : 상대 전신 + 화면 아래 「KILL THE MASTERMIND」 색 글자, 우하단 주인공 얼굴 + 무지개 칼, 좌상단 상대 이름표, 좌하단 타이머.
* **논스톱** : 렌즈 비네트, 사각 조각, 큰 세리프 발언(외곽선 + 그림자), 약점 주황.
* 공통 : 우상단 STATUS(하트 줄 + 별 줄, 기울어짐), 화면 밖으로 잘린 사선 띠들. **장면은 어둡고 대비가 강함**(배경 법정은 붉은·보라 조명).

## 6. 본작 적용 순서
1. 대화창·이름표·넘김 표시·우상단 HUD 정리(글씨 위치·여백 고정).
2. 탐색 화면(1인칭 팬·조준점·장소 띠·미니맵·방 안 인물) — 수사 현장과 자유행동이 같은 화면을 쓴다.
3. 자유행동 : 지도 얼굴 아이콘 → 장소 → 인물 → 확인 → 이벤트 → 선물 화면.
4. 시체 발견·방송·파일·수사 개시/종료·엘리베이터 연출.
5. 패드 V3 배치.
6. 재판 선택지·언령 고르기·미니게임 화면을 1-3 기준으로 교체.
7. 소리 큐 연결(§5).
