# 제작 사양서 03 — 탐색 · 수사 · 증거 시스템

## 1. 탐색 시스템 규칙

| 항목 | 값 |
|---|---|
| 구조 | 구역(Area) ▸ 방/장소(Room) ▸ **노드(Node)**. 노드 1개 = 정지 파노라마 1장 |
| 노드 이동 | 마커 클릭. 노드 간 최소 거리 1홉 = 0.5초. 같은 방 안 3~6노드 |
| 시점 | 수평 360°, 수직 ±40°. 노드마다 **초기 시점**(yaw,pitch)을 지정 |
| 핫스팟 | 다각형(0~1 정규화 좌표). 타입 : `inspect`(확대 조사) `talk`(인물) `item`(코인/아이템) `door`(노드 이동 연결) `device`(제어반 등 UI 호출) `lock`(열쇠/조건 필요) |
| 해금 | 핫스팟/노드는 `require` 조건(플래그·카드·인연 Lv·시간) 충족 시 활성 |
| 시간대 | 일상 파트는 **시간 슬롯**(아침/오전/점심/오후/저녁/밤)에 따라 NPC 배치·조명이 바뀜(§5) |
| 수사 타이머 | 수사 비트(분 단위) : 1장 80 / 2장 80 / 3장 80 / 4장 95 / 5장 80 / 6장 60. 이동·조사로 소모되지 않고 **실시간 감소**(대화·확대 중에도). 0이 되면 자동 종료 |
| 타이머 보조 | 옵션 `수사 타이머 정지`(접근성) — 정지하면 등급 보너스 제외 |

## 5. NPC 배치 (일상)
| 시간 슬롯 | 규칙 |

| 오전/오후 | 인물별 **선호 장소** 우선(02 문서의 `위치` 목록) + 이벤트 스케줄이 우선 |

## 6. 수사 파트 진행

### 6-1. 단계
1. **발견** 스토리(시체 발견) → 래피 파일 지급(증거 카드).
2. **수사 시작** 안내 + 현장 목록 UI(수첩 지도 탭).
3. 탐색·조사·대화(자유). **증거 카드 획득 조건**은 각 핫스팟에 정의.
4. **노트 슬롯 1회**(수사 중) 선택.
5. 타이머 종료 또는 플레이어가 "수사 종료" → 필수 증거 확인 팝업(§6-3).

### 6-2. 증언 수집
* 인물에게 말 걸기 → 메뉴 `증언 듣기 / 사건 질문 / 소지품 요청`. 각 선택은 `data/evidence.json`의 `T` 카드를 획득시키는 스크립트 연결.
* 증언 중 **거짓/착각** 여부는 UI에 표시하지 않는다(재판에서 판별).

### 6-3. 수사 종료 점검
| 상태 | 처리 |
|---|---|
| 필수 증거 모두 획득 | "충분히 조사한 것 같아." → 종료 |
| 필수 증거 누락 | 미오 독백 힌트 : "아직 [현장명]을 안 봤어." (장소명만 알려 줌) + 종료 확인 |
| 강제 종료(타이머) | 누락 증거가 있으면 재판에서 해당 정답 선택지가 **힌트 모드**로 쉬워짐(난이도 보정) |
* **필수 증거 목록**은 각 장 `...수사_재판.md`의 "공정성 체크표"와 **일치**한다.

## 7. 증거 카드 획득 UX
| 단계 | 연출 |
|---|---|
| 1 | 핫스팟 클릭 → 미오 독백(대사) |
| 2 | 대사 끝 시 카드가 중앙에서 떠오름(0.4s) + `sfx_card` |
| 3 | 상단 토스트 "증거 카드 획득 : (이름)" |
| 4 | 수첩 아이콘 반짝 + 증거 탭 `NEW` |
| 5 | 이미 가진 카드 재획득 시 "이미 가지고 있어." 한 줄(대사 생략) |

## 8. 노트 시스템
| 항목 | 값 |
|---|---|
| 슬롯 | 장당 **3개**(일상 2일 + 수사 1). `@note_prompt`가 발생하는 지점에서만 승격 가능 |
| UI | "노트에 적을까요? [적는다] [적지 않는다]" + 후보 목록(2~4개) |
| 효과 | 적은 카드는 노트 증거(파란 테두리). 재판에서 **거짓 증언·기억 조작 반박 시 무조건 유효** |
| 미승격 | 정황 증거. 반론 쇼다운에서 상대 반박(난도 ↑) |
| 자동 보정 | 4장 N4-01은 승격 안 해도 수사 종료 직전에 자동 승격 |
| 저장 | `notes_promoted[]` |
