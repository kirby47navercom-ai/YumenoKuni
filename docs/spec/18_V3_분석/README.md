# V3 게임 전체 역분석 — 진행·근거 색인

**최신 작업 목표:** 유메노쿠니의 스토리와 세계관은 유지한다. 게임 방식·게임 틀·맵과 이동·조작·일상·자유행동·수사·재판·미니게임·보너스 모드·메뉴·저장·UI·연출 등 게임 시스템 전체는 V3를 기준으로 전면 재구성한다. 기존 구현에 있다는 이유로 보존하거나, 없다는 이유로 분석·재현 범위에서 제외하지 않는다. 먼저 V3 전체의 규칙과 연결을 분석하고 미확정 부분을 구분한 뒤 그 근거로 게임을 고친다. 현재는 분석 단계이며 게임 코드를 변경하지 않는다. 원작 파일의 게임 내 사용·배포 제한은 유지한다.

대상은 주인님이 제공한 Steam PC 설치본이에요. 분석 범위는 **게임 전체**예요. 타이틀·본편 탐색·일상·자유행동·수사·재판·처형·장 끝, 저장·설정·갤러리, 카지노·탈출·RPG 등 설치본의 별도 게임도 포함해요. 2026-10-26 현재 고정24분야의 주요 정상 동작·규칙·연결·표현을 재구성하기 위한 분석 명세를 완료했어요. 실제 적용의 중심 문서는 [전체 재구성 연결 명세](23_전체재구성_연결명세.md)예요.

주인님의 최신 범위 정정 이후 직접 플레이·UI 입력·원본 프로세스 읽기는 중단했어요. REA 정적 코드와 기존 해독 데이터로 입력·허용 조건·상태 변경·결과·실제 표현 소비·다음 모드/저장 연결을 명세했어요. 이전 실행 관찰은 과거 근거로만 보존하며 이후 정적 결론을 실행 검증이라고 부르지 않아요.
