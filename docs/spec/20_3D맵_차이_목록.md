## 1. 가장 근본적인 차이 — 공간을 「무엇으로」 만들었나

| | V3 | 유메노쿠니 |
|---|---|---|
| 가구·소품 | **그림을 그린 평면 판**을 3D 에 배치. 교실 책상 16·의자 16 본체가 전부 평면이고, 여러 방향에서 그린 그림(atlas)을 서로 다른 평면에 붙여 깊이를 다르게 둔다 **[역분석 01 「평면 가구가 입체처럼 보이는 구체적인 이유」]** | 단색 재질의 **저폴리 상자 모델**(침대·책상·의자·선반이 다 같은 방식) |
| 벽·바닥 | 손으로 그린 질감 텍스처(얼룩·덩굴·낙서·네온·무늬) **[원작 렌더]** | 거의 단색 + 약한 대리석 무늬. 모든 방이 같은 베이지 벽·보라 걸레받이·같은 천장 |
| 빛 | 그림에 빛과 그늘이 그려져 있고(lightmap 곱), 색 조명이 강함 **[역분석 + 영상]** | PBR 조명의 회색빛 실내, 밤은 전체를 어둡게만 |

→ 그래서 우리 공간은 「3D 게임 회사 사무실」처럼 보이고 V3 의 **「그림책을 세워 만든 무대」** 느낌이 없다. 모델 수를 늘리는 것보다 **표현 방식(그린 평면 + 그린 텍스처)** 을 먼저 정해야 한다.

## 2. 조작 구조

**[역분석 01 「공간을 어떻게 플레이하는가」]**
* V3 맵은 두 종류 : `2.5D`(99) / `3D`(65), 실제 조작 필드 「操作」 0 = **고정 중심에서 둘러보기**(교실 등 실내 — 걸어 다니지 않음, 주시점·반경·각도 제한), 1 = **걷기**(복도·야외 — 이동·충돌).
* 수치 예 : 복도 FOV 60·pitch −20~20·속도 0.1·달리기 ×2.25 / 교실 FOV 70·pitch −9.74~6.09·이동 없음 / 야외 FOV 75·속도 0.2·달리기 ×2.5.
* 유메노쿠니 : `art/space_v4/README.md` 의 배정(광장·로비·복도 = 걷기, 객실·식당 등 = 고정 둘러보기)은 **방향이 맞다**. 다만 수치(FOV·pitch 범위·속도·보간)를 원작 값에 맞췄는지, 방 안 고정 시점이 실제 게임에서 그렇게 도는지 **확인 필요**.

## 4. 테마·색

* 유메노쿠니는 「꿈의 놀이공원」이다. 그런데 공간이 전부 **호텔·사무실·병원** 톤(베이지·보라·짙은 갈색)이고 놀이공원의 색(분홍·민트·네온·전구·깃발)이 없다.
* V3 는 장소마다 색 테마가 확 다르다(교실 = 청록·노랑 네온, 카지노 = 붉은 금색, 수영장 = 주황 + 유리 천장, 격납고 = 초록 기계) **[원작 렌더]**. 우리는 공간 사이 색 차이가 거의 없다.

## 5. 걷기 화면(HUD) — 게임 캡처 기준

* 조준점 : 노란 **원 하나** → V3 는 노란 **겹친 마름모 + 가운데 아이콘**(문은 돋보기), 아래 노란 사선 판에 이름 **[영상 B 25:03]**.
* 조작 안내 : 화면 아래 흰 글자 한 줄(「WASD 이동 · Shift 달리기 …」) — V3 는 이런 상시 안내 없음(GPT 식 판별 §12).
* 미니맵 : 안 보임 → V3 는 오른쪽 아래 기울어진 마름모 미니맵 **[영상]**.
* 왼쪽 위 시간대 띠·오른쪽 위 장 판은 V3 와 비슷하게 맞춰져 있음(좋음). 단 시간대 엠블럼 그림은 단순 도형.
* 그림자 없음 → 바닥 위 물체가 떠 보인다.

## 6. 인물·조사 대상 (확인 필요)

* V3 : 장소마다 인물 자리 목록(복도 19·교실 8·야외 91 행), 물체마다 개별 조사 대상(교실 39 개, 책상·의자 하나하나) **[역분석]**.
* 유메노쿠니 : 3D 공간 안에서 인물이 어떻게 서 있는지, 조사 대상이 물체 단위인지 화면으로 못 봤다. 예전 2D 좌표(`data/hotspots.json`)를 3D 에 그대로 쓰면 안 된다는 점은 역분석 01 「바꿀 것」 4 와 같다.

## 7. 고칠 순서 (제안)

1. **표현 방식 결정** — V3 처럼 「그린 평면 소품 + 그린 텍스처」로 갈지(우리 NAI 그림을 소품 판·벽 텍스처로 쓰는 방법 포함), 지금의 3D 상자 모델을 다듬을지. **주인님 결정이 필요하다.**
2. 공간별 개성 — 인물·시설마다 소품·색을 다르게, 밀도를 원작 수준으로.
3. 공원 바깥 — 지평선까지 채우기(건물·놀이기구·조명), 경로 모양.
4. 재판장 — 원형 객석·철창·기둥벽, 장별 변형.
5. 걷기 HUD — 마름모 조준·이름 판·미니맵, 안내 글자 제거, 그림자.
6. 조작 수치 — FOV·pitch·속도를 역분석 값에 맞추고, 방 안 고정 둘러보기 확인.
7. 인물 자리·물체 단위 조사 대상 연결 후, 게임 화면으로 V3 영상과 나란히 비교.
