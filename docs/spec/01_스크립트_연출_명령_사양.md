# 제작 사양서 01 — 스크립트 재생 · 연출 명령 · 대화 UI 규칙

> `data/scenes/*.json`을 **어떻게 재생하는지** 정의한다. 각본 md는 그대로 두고, 재생기가 **기본 연출 규칙**으로 자동 연출을 만들고, 필요한 장면만 `@명령`으로 덮어쓴다.

---

## 1. 이벤트 타입과 재생 규칙

| type | 필드 | 재생 |
|---|---|---|
| `say` | speaker, kind, text, emo?, note? | 대화창에 출력. 화자 스프라이트 강조 |
| `stage` | text | 지문. 키워드 규칙(§3)으로 연출 실행 + 필요 시 나레이션창 출력 |
| `ui` | text | 시스템 안내창(§5)으로 출력. 튜토리얼이면 포커스 하이라이트 |
| `choice` | text | 선택지 묶음의 일부. 직전·직후 `choice`들을 한 묶음으로 처리 |
| `break` | text | 화면 전환(§3-3). `── 전환 : 장소 ──` |
| `note` | text | 제작 메모. **게임에서는 재생하지 않음**(디버그 모드에서만 표시) |
| `cmd` | name, args | `@명령`(§4). 명시적 연출 |

### 1-1. say.kind
| kind | 의미 | 표시 |
|---|---|---|
| normal | 일반 대사 | 이름표 + 대사 |
| monologue | `(독백)` | 이름표 없음, 대사창 테두리 점선, 글자색 연한 회색, 화면 가장자리 비네트 |
| broadcast | `(방송)` `(머신 음성)` | 대사창을 **모니터 프레임**으로 교체, 래피 아이콘, 약간의 스캔라인 |
| voice | `(음성)` `(영상)` | 스프라이트 없이 이름표만. 효과음 필터(라디오 느낌) |

## 2. 대화창 사양 (1280×720 기준)

## 3. 지문(`stage`) 자동 연출 규칙

`stage.text`에 아래 **키워드가 포함되면** 대응 연출을 실행한다. 여러 개면 위에서 아래 순서로.

### 3-1. 키워드 → 연출
| 키워드(포함) | 연출 | 기본 길이 |
|---|---|---|
| `암전` | 화면 검정 페이드아웃 후 정지 | 1.0s |
| `번쩍`, `플래시`, `흰색으로` | 흰색 플래시(투명도 0→0.8→0) | 0.3s |
| `노이즈`, `화면이 일그러` | 화면 글리치(색수차+가로 슬라이스) | 0.6s |
| `딩동♪` | 효과음 `sfx_ding` + 화면 상단에 시체 발견 아이콘 | 1.2s |
| `쿵`, `쾅`, `부딪` | 카메라 쉐이크(강) | 0.4s |
| `떨림`(지문 한정), `흔들린다` | 카메라 쉐이크(약) | 0.5s |
| `오르골` | `sfx_musicbox` 한 소절 | 3s |
| `비명` | 화면 약간 붉은 비네트 + 쉐이크(약) | 0.8s |
| `울음`, `눈물`(지문) | 화면 채도 −20% 서서히 | 2s |
| `소등`, `조명이 꺼` | 배경 밝기 −60% | 0.8s |
| `조명이 켜` | 배경 밝기 복구 | 0.8s |
| `불꽃`, `폭죽` | 파티클 `fx_firework` | 2s |
| `거울` | 화면 일부 반사 셰이더(가로 반전 잔상) | 1.0s |
| `종이 울` , `종이 울린` | `sfx_bell` | 2s |
| `카메라(…)시점`, `시점` | 카메라 스타일 전환(시점 컷, §5-1) | - |
| `(컷 ①`~`⑧` | **피날레 컷**(04 §12) 패널 한 장씩 | 3s/컷 |

### 3-2. 나레이션 표시
* `stage` 중 **키워드 연출만 있고 설명이 없으면 화면에 텍스트를 띄우지 않는다.**
* 장면 서술형 지문(길이 > 20자)은 **화면 중앙 하단 반투명 바**에 이탤릭으로 3초 표시하고 자동으로 넘어간다(클릭으로 스킵).

### 3-3. `break` (장면 전환)
| 형태 | 연출 |
|---|---|
| `── 전환 : 장소 ──` | 배경 0.5초 페이드(검정), 새 배경, 인물 모두 퇴장 |
| `── 장소 ──`(시간 경과 포함) | 위 + 자막 카드 "N분 후 / 저녁 7시 / 다음 날 아침" 표시 |

## 4. 명시적 연출 명령 (`@cmd`)

각본 md의 코드블록 안에 **`@명령 인자`** 한 줄로 쓸 수 있다. `build_data.py`가 `{type:"cmd"}`로 변환(구현 항목 M1).

| 명령 | 인자 | 설명 |
|---|---|---|
| `@bg` | `bg_id [fade=0.5]` | 배경 교체 |
| `@bgm` | `bgm_id [fade=1.0 | stop]` | BGM 교체/정지 |
| `@sfx` | `sfx_id` | 효과음 |
| `@show` | `char pos expr [enter=slide_left|fade]` | 인물 등장. pos = `L2 L1 C R1 R2` |
| `@hide` | `char [exit=fade]` | 퇴장 |
| `@expr` | `char expr` | 표정 변경 |
| `@move` | `char pos [time=0.4]` | 위치 이동 |
| `@cam` | `zoom 1.0~1.4 [pan x y] [time]` | 카메라 줌/팬 |
| `@shake` | `strong|weak [time]` | 화면 흔들림 |
| `@flash` | `white|red [time]` | 플래시 |
| `@fade` | `in|out color [time]` | 페이드 |
| `@cutin` | `char expr [side=L|R]` | 컷인(캐릭터 상반신 크게, 04·05) |
| `@wait` | `sec` | 대기 |
| `@give` | `card_id` | 카드(증거/증언/마법/규칙/메모) 획득 + "획득" 토스트 |
| `@note_prompt` | `note_id` | "노트에 적을까요?" 승격 선택 UI |
| `@bp` | `char +n` | 인연 포인트 가감 |
| `@coin` | `+n` | 코인 가감 |
| `@flag` | `key=value` | 플래그 설정 |
| `@if` / `@endif` | `flag==value` | 조건 분기 |
| `@goto` | `scene_id` | 장면 이동 |
| `@call` | `minigame:name` | 미니게임 호출(04) |
| `@save` | | 오토세이브 |
| `@tutorial` | `tut_id` | 튜토리얼 팝업 |

## 5. 연출 기본 규칙 (자동)

### 5-1. 카메라 스타일
| 스타일 | 용도 | 기본값 |
|---|---|---|
| `stage` | 일반 대화 | 인물 3명까지 가로 배치, 줌 1.0 |
| `closeup` | 감정 고조(`{울음}` `{떨림}` `{결의}`) | 화자 중심 줌 1.15 + 배경 블러 |
| `pov` | `(…시점)` 지문 | 화자 스프라이트 숨기고 배경 전면 |
| `trial` | 재판 | 둥근 법정 원형 배치 (04 §1) |

### 5-2. 인물 배치
* 스프라이트 위치 슬롯 5개 : `L2(x=180) L1(x=400) C(x=640) R1(x=880) R2(x=1100)`. 하단 y=720 기준, 상체 크기 640px.
* 자동 배치 규칙 : 첫 화자는 `C`. 두 번째 화자는 `L1` 또는 `R1`(미오는 항상 `L1`쪽 고정이 아님, **대화 대상이 반대쪽**에 선다). 4명 이상 동시 등장 시 `L2 L1 R1 R2`.
* 화자가 바뀌면 이전 화자는 밝기 −35% + 살짝 뒤로.

### 5-3. 표정 ID (스프라이트 변형)
기준 입상(`art/standing`)의 상반신 크롭 + 표정 **10종**.

| ID | 설명 | emo 매핑 키워드 예 |
|---|---|---|
| `neutral` | 기본 | (그 외 전부) |
| `smile` | 웃음 | 웃음·미소·활짝·환호·장난·윙크 |
| `serious` | 진지·단호 | 단호·결의·차분·정리·담백·무표정·낮게 |
| `surprise` | 놀람·당황 | 놀람·당황·숨을 삼킴·움찔 |
| `sad` | 슬픔·울음 | 눈물·울음·눈가·주저앉 |
| `worry` | 걱정·불안·소극 | 걱정·불안·소극·작게·조심 |
| `anger` | 분노 | 분노·적의·외침 |
| `closed` | 눈 감음 | 눈을 감음 |
| `whisper` | 속삭임 | 속삭임 |
| `special` | 인물 고유(레이 한쪽 눈, 켄 연기 표정 등) | 캐릭터별 정의(06) |
* `data/emotion_map.json`에 **592개 태그 → 표정 ID**가 자동 매핑되어 있다(대부분 `neutral`로 떨어지는 손동작 태그는 **연기 힌트**로만 사용). 필요 시 JSON에서 직접 수정.
* **동작 태그**(`소매를 정돈`, `머리핀을 만짐` 등)는 표정이 아니라 **미세 애니메이션 슬롯**(손·소매)이며 에셋이 없으면 무시.

### 5-4. 전환·템포
| 상황 | 템포 |
|---|---|
| 동일 인물 연속 대사 | 표정만 교체, 입상 이동 없음 |
| 감정 폭발(`{울음}` `{비명}`) | 컷인 또는 closeup + 0.2s 정지 |
| 침묵 표시(`(침묵)`) | 1.2초 정지 후 자동 진행 |
| 장면 시작 | 배경 페이드 0.5s → 인물 입장 0.3s → 첫 대사 |

## 6. 선택지 처리

| 항목 | 규칙 |
|---|---|
| 표시 | 화면 중앙 하단에 세로 목록, 최대 4개, 폭 640, 높이 56, 간격 12 |
| 분기 규칙 | `▶ 선택지` 직후의 문단 `- A. ...` 혹은 `★` / `✕` 라벨 : **★ = 인연 +2, ✕ = −1** |
| 타임아웃 | 없음(재판 중 "집중 선택"만 제한 시간) |
| 이탈 | 선택지에서 로그 열람 가능 |
| 결과 | 선택 후 응답 대사를 재생, `@bp`/`@flag` 적용 |

## 7. 튜토리얼 UI 문구(`ui` 이벤트)

* `[UI] 문구` 줄은 **하단 중앙 안내창**(폭 720, 높이 72, 배경 검정 70%)에 표시, 일정 시간 후 자동 소멸(8초) 또는 클릭 시 소멸.
* 튜토리얼 필수 안내는 `@tutorial`로 지정해 해당 UI 요소를 **스포트라이트 하이라이트**(주변 어둡게).
