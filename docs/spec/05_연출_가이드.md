# 제작 사양서 05 — 연출 가이드 (카메라 · 컷인 · 색 · 사운드 · 처형 스토리보드)

> 원칙 : **밝게 시작해 점점 어두워진다.** **모든 피는 보라색**(각본의 「혈흔」「피」도 화면에서는 보라색으로 그린다). UI 색·BGM·래피의 말투와 얼굴이 장과 함께 변한다. 처형은 **빛과 소리**로만 표현하며 신체 손상·유혈·고통 표현은 금지.

## 2. 카메라 · 컷인 문법

| 연출 | 사용 | 파라미터 |
|---|---|---|
| **클로즈업 컷인** | 감정 폭발, 증거 제시 | 상반신 확대 1.5배, 배경 블러, 0.2s 슬라이드 인, 가장자리에 감정색 비네트(분노=적, 슬픔=청) |
| **시점 컷** | 발견 장면 | 인물 스프라이트 숨기고 파노라마 전면 + 약한 핸드헬드 흔들림 |
| **슬로우** | 논파 일격, 결정적 대사 | 시간 스케일 0.3, 0.4s |
| **스플릿 컷** | 두 인물 대립 | 화면 대각선 분할, 각 인물 컷인 |
| **회상 컷** | 과거 장면 | 세피아 + 가장자리 필름 번짐 |
| **노이즈 컷** | 래피의 감정 균열 | 화면 글리치 0.4s + 음성 피치 변화 |
| **오르골 컷** | 하루카·래피 | 오르골 소절 + 화면 가장자리 별 파티클 |

## 3. 시체 발견 연출 (공통 템플릿)

| 순서 | 연출 | 시간 |
|---|---|---|
| 1 | 시점 컷(플레이어 시점) : 발견 직전 침묵(BGM 정지) | 2s |
| 2 | 시체/현장을 일러스트로 한 번 보여 줌(유혈 없음, 쓰러진 실루엣 위주) | 1.5s |
| 3 | `딩동♪` SFX + 화면 상단에 **시체 발견 마크**(래피 얼굴 + 십자) 슬라이드 인 | 1.2s |
| 4 | 래피 방송 컷(모니터 프레임) | 4s |
| 5 | 수사 시작 UI(타이머 등장) + BGM "수사" | - |
* 3장 같은 **2연속 발견**은 1·2차 간 BGM을 이어 붙이고, 2차에서 BGM이 한 단계 낮은 키로.

## 4. 재판 연출

### 4-1. 개정
* 암전 → 원형 연단 위로 줌 아웃 → 인물 입장(각자 의자에 앉는 컷 0.2s씩 8명, 최대 3초) → 래피 중앙 하강 → "재판을 시작할게요" 대사.
* 영정 사진 컷 : 화면 하단 중앙에 1.5초.

### 4-2. 범인 지목 연출 (투표 후)
| 순서 | 연출 |
|---|---|
| 1 | 투표 결과 화면 : 각 인물이 지목한 대상의 얼굴이 중앙으로 모임 |
| 2 | 래피 컷인 "…정답이에요(또는 오답)" |
| 3 | 범인 컷인 : 표정이 서서히 무너짐(웃음→침묵→눈 감음) |
| 4 | BGM : 재판 BGM이 서서히 페이드, 범인 테마 BGM 시작 |

### 4-3. 자백
* 범인이 말하는 동안 **화면 분할**: 좌 범인 컷인 / 우 청중 반응(미오, 코토 등) 번갈아.
* 마지막 대사 후 **암전 1.0s** → 처형.

## 5. 처형 스토리보드 (잔혹 묘사 금지)

## 9. 음성 정책
* **풀 보이스 없음**. 텍스트 블립 + 감정 효과음(웃음 `sfx_laugh_*`, 숨 `sfx_gasp`, 울음 `sfx_sob`).
* 확장 단계에서 보이스 도입 시 `speaker.voice_id`를 스키마에 이미 포함(07 참조).

## 10. 래피 연출 변화 체크리스트
- [ ] 1~2장 : 모니터 프레임 밝은 분홍, 래피 눈동자 하이라이트 2개
- [ ] 3장 : 하이라이트 1개 감소, 프레임 어두운 보라
- [ ] 4장 : 프레임 회색, 모자 정돈
- [ ] 5장 : 래피만 컬러(화면은 흑백), 가끔 노이즈
- [ ] 6장 : 눈동자 색이 분홍 → 갈색(하루카 본래 눈 색)으로 서서히 변화
