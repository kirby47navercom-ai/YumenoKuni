# 제작 사양서 12 — 스프라이트 포즈 · 이벤트 CG 목록 (⚠ 스포일러 포함)

> 레퍼런스 : 단간론파 위키 Sprite Gallery(인물당 30~50컷). 본작은 **인물당 26~34컷**을 1차 목표로 한다.
> 구도 : 스프라이트는 **허벅지 위(cowboy shot)·정면·흰 배경**. 기준 전신 입상(`art/standing`)과 같은 얼굴·복장으로 그린다.
> 생성 : `tools/generate_tpose_nai.py --pose <ID>`. 포즈 태그 원본은 `art/poses.json`.
> 규칙 : 노출·신체 부위 강조 금지(전원 미성년 포함). 피는 **보라색**. 시체 CG는 실루엣 또는 옷·소품 위주로 그린다.
