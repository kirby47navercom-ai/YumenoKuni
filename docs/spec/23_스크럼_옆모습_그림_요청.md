## 1. 왜 필요한가 (V3 근거)
* V3 영상 A(youtube.com/watch?v=4Gu0GGxs4rw) 1:18:28~1:18:45 : 의논 스크럼에서 두 팀이 통로를 사이에 두고 마주 선다. 말하는 사람은 **건너편 팀 쪽을 옆으로(3/4) 바라보는 모습**으로 크게 잡힌다(진구지·이루마·키보 등). 왼쪽(빨강) 팀은 화면 오른쪽을, 오른쪽(파랑) 팀은 화면 왼쪽을 본다.
* 우리 입상은 모두 정면 그림이라 카메라 각도로만 흉내 내고 있다(사양서 22).

## 2. 만들 것 — 16명 × 2장 = 32장
대상 : mio rin ken nana taiga ai rei sora haruka sho koto akari riku satsuki yuu kaede (래피 제외)

| 포즈 코드 | 내용 |
|---|---|
| `SR` | 몸을 약 45° 돌려 **화면 오른쪽**을 바라보는 3/4 전신. 얼굴·시선도 오른쪽. 논쟁 중(진지·반박) 표정, 손짓은 자연스럽게(가슴 앞·팔짱·가리킴 중 인물 성격에 맞게) |
| `SL` | 같은 조건으로 **화면 왼쪽**을 바라보는 3/4 전신. `SR` 을 좌우 반전한 그림으로 대신하지 않는다(가르마·액세서리·완장 위치가 뒤집히면 다른 사람이 된다) |

공통 조건
* 승인된 신규 캐릭터 원본(`art/character_delivery_v4` 의 각 인물 master)과 같은 얼굴·머리·의상·체형·색. 옛 그림체·NAI 후보 272 포즈를 정본으로 쓰지 않는다.
* 전신 서 있는 자세, 투명 배경(알파), 기존 master_hd 와 같은 캔버스 크기·발 기준선·인물 키 비율(정면 입상과 나란히 세워도 키가 맞아야 한다).
* HANDOFF 금지 사항 그대로 : 미성년 성적 표현·노출 금지, 혈액은 보라색.
* 얼굴·손·의상 깨짐 검수 후 등록(`art/v4_production/README.md` 의 원본/고해상도/알파·얼굴·손·의상 검수 구분).
