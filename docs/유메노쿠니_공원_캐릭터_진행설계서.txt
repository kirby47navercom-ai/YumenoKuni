■ 1. 단간론파 구조 분석과 이 작품에의 적용
----------------------------------------------------------------
[분석 요약]
- 한 챕터는 3단 구조 : 일상(Daily Life) → 수사(Deadly Life) → 재판(Class Trial).
- 일상 : 탐색, 프리타임(캐릭터 호감 이벤트), 동기 제시. 긴장을 쌓는 구간.
- 동기 : 살인을 '이해할 수 있는 선택'으로 만드는 압박. 매 장 종류가 달라져야 함.
- 수사 : 시체 발견 후 현장·증언 수집. 모든 단서는 이 구간에서 확보 가능해야 함.
- 재판 : 수집한 단서로 논파·반론·재구성을 거쳐 범인 지목. 마지막에 범인의 자백과 처형.
- 프리타임은 재판용 '스킬'과 연결되어 호감도 보상이 플레이에 직결됨.
- 챕터 후반에 반드시 한 번의 대반전(범인의 정체 또는 방법)이 있음.
- 6장 구성에서 마지막 장은 일상이 짧고 흑막 대결에 집중.

[이 작품 적용]
- 마법은 '증거 생성 규칙'. 싸움이 아니라 추리의 재료.
- 래피 수첩 / 래피 파일 / 규칙 질의로 공정성 보장.
- 맹세·기록 등 마법이 인간관계와 심리전을 만듦.
- 놀이공원은 챕터마다 새 트릭 무대가 열리는 확장형 맵.
- 분위기 : 밝게 시작해 점점 어두워짐. 래피의 말투와 BGM·UI 색이 함께 변화.

■ 2. 챕터별 진행 시간 설계 (목표 6.5~7시간/장)
----------------------------------------------------------------
[기본 템플릿 — 분 단위]
 일상 파트        110  (이벤트 3~4개 + 탐색 + 신규 구역 소개)
 프리타임         40   (슬롯 3~4개)
 동기 발표·긴장    15
 에필로그         15   → 스토리 합계 약 3시간
 ─────────────────────────────
 사건 발생·발견    5
 수사             80   (현장 3~4곳 + 증언 + 물증)
 재판             150  (6단계)
 처형·연출         10   → 추리 합계 약 4시간

[장별 가중치]
 1장 : 일상 +20분 (세계관·캐릭터 소개), 재판 -10분 (입문)
 2장 : 표준
 3장 : 재판 +20분 (복잡 구성)
 4장 : 수사 +15분, 재판 +25분 (최고 난도)
 5장 : 일상 +10분(관계 정리), 재판 +15분
 6장 : 일상 0분, 프리타임 0분. 수사 60분 + 재판 180분 + 엔딩 40분

[장 내부 흐름 예시]
 일상 파트 1 (아침 모임, 새 구역 개방) → 프리타임 슬롯 → 일상 파트 2 (이벤트) → 프리타임 슬롯 → 일상 파트 3 → 동기 발표 → 밤 → 사건 발생 → 수사 → 재판 → 처형 → 에필로그

■ 3. 재판 시스템 (미니게임 구성)
----------------------------------------------------------------
 1단계 사건 정리     : 래피 파일 + 현장 단서를 시간표에 배치하는 요약 퍼즐
 2단계 논파          : 증언의 모순을 단서로 쏴서 반박 (논스톱 토론)
 3단계 알리바이 표    : 용의자별 시간대를 채워 압축
 4단계 재구성        : 평면도에 이동 경로를 배치 / 순서 맞추기
 5단계 규칙 질의     : 래피에게 규칙을 질의(최대 5회). 질의 자원은 프리타임 스킬로 확장
 6단계 최종 추궁     : 반론 쇼다운 + 마지막 요약 연출 → 투표 → 자백 → 처형
[추가 시스템]
- 미오의 노트 : 하루 1페이지 기록. 수사 파트에서 쓴 기록이 재판의 증거로 사용 가능.
  (플레이어가 중요하다고 판단한 순간에 노트에 적도록 유도하는 시스템)
- 거짓 증언 시스템 : 증언 일부는 거짓. 단서로 판별.
- 동의/반론 : 옳은 증언엔 '동의'를 눌러야 함.
- 페널티 : 오답 시 집중력(체력) 감소.

■ 5. 캐릭터 프로필 (스포 없음)
----------------------------------------------------------------
공통 : 사쿠라가오카 학원 교복 + 개성 커스터마이즈. 말투는 한국어 기준 설정.

01 아오이 미오 (17 / 158cm) — 주인공
 - 성격 : 조용하고 관찰력이 좋음. 눈에 띄지 않으려 하지만 사람을 잘 챙김.
 - 입체 포인트 : 평범하다는 말을 들을 때 가장 불편해함.
 - 말투 : 부드러운 반말 + 가끔 존댓말. "적어 둘게."가 입버릇.
 - 버릇 : 대화 중 노트 모서리를 만지작거림. 좋아하는 음료는 달달한 라테. 싫은 것은 갑작스러운 큰 소리.
 - 프리타임 : 모든 캐릭터의 접점. 각 캐릭터 이벤트에서 '노트에 한 줄' 기록이 쌓임.

02 미사키 레이 (18 / 176cm)
 - 성격 : 냉정하고 말수가 적음. 부유한 가문 출신이라 사람과 거리를 둠.
 - 입체 포인트 : 정중하지만 선물을 받으면 어쩔 줄 몰라 함.
 - 말투 : 존댓말에 가까운 정중한 말투. 반말은 거의 하지 않음.
 - 버릇 : 소매를 자주 정리. 좋아하는 것은 조용한 장소와 홍차. 싫은 것은 큰 모임.
 - 프리타임 : 공원의 설계와 역사에 박식. 구조 설명을 해 줌.

03 카미야 소라 (17 / 172cm)
 - 성격 : 밝고 정의로우며 모두의 중심. 소방관 지망.
 - 입체 포인트 : 분위기 메이커이지만 혼자 있는 시간엔 표정이 사라진다.
 - 말투 : 활기찬 반말. "괜찮아, 맡겨!"가 입버릇.
 - 버릇 : 사람들에게 간식을 나눠 줌. 좋아하는 것은 달리기와 군고구마. 싫은 것은 불 이야기.
 - 프리타임 : 구급 응급 처치 연습, 야간 순찰 동행.

04 시라누이 켄 (18 / 178cm)
 - 성격 : 연기 천재. 말이 많고 사람을 시험하는 걸 즐김.
 - 입체 포인트 : 웃고 있지만 진짜 표정을 보인 적이 없음.
 - 말투 : 극적인 말투와 장난. 대사 중 연극 대사를 섞음.
 - 버릇 : 말하기 전 오른쪽 입꼬리를 올림. 좋아하는 것은 무대와 커피. 싫은 것은 침묵.
 - 프리타임 : 연기 레슨, 즉흥 연극.

05 유키무라 나나 (17 / 155cm)
 - 성격 : 온화하고 섬세함. 간호사 지망.
 - 입체 포인트 : 남을 돌보면서 자신은 돌보지 않음.
 - 말투 : 부드러운 존댓말. 말끝을 흐림.
 - 버릇 : 소매 끝을 만지작거림. 좋아하는 것은 허브티, 싫은 것은 피 이야기.
 - 프리타임 : 약초 차 만들기, 상처 치료 연습.

06 타치바나 리쿠 (17 / 170cm)

 - 입체 포인트 : 웃음 뒤에 사람을 꿰뚫어 보는 눈.
 - 말투 : 가벼운 반말. 농담 섞인 말.
 - 버릇 : 동전 돌리기, 카드 셔플. 좋아하는 것은 마술 소품과 젤리, 싫은 것은 진지한 분위기.
 - 프리타임 : 마술 레슨, 트릭 풀이.

07 모리 아카리 (17 / 162cm)
 - 성격 : 성실하고 책임감이 강한 약사 지망.
 - 입체 포인트 : 냉철해 보이지만 칭찬에 약함.
 - 말투 : 단정한 존댓말.
 - 버릇 : 안경을 올림, 소지품 정리. 좋아하는 것은 정리 정돈과 홍차, 싫은 것은 지각.
 - 프리타임 : 약초 공부, 정리 정돈 도움.

08 쿠로세 유우 (17 / 175cm)

 - 입체 포인트 : 사람들의 감정 변화에 가장 민감함.
 - 말투 : 친근한 반말. 감탄사가 많음.
 - 버릇 : 흥얼거림. 좋아하는 것은 음악과 탄산음료, 싫은 것은 조용한 분위기.

09 하나이 코토 (18 / 160cm)

 - 입체 포인트 : 누구에게나 친절하지만 자기 이야기는 거의 하지 않음.
 - 말투 : 부드러운 존댓말과 반말의 중간.

10 이노우에 사츠키 (17 / 165cm)
 - 성격 : 말수가 적고 의리가 있음. 사냥 집안 출신.
 - 입체 포인트 : 동물에게는 다정하지만 사람에게는 서툼.

 - 버릇 : 소매를 걷음. 좋아하는 것은 새로운 레시피, 싫은 것은 음식 낭비.
 - 프리타임 : 요리 대결, 레시피 교환.

15 아사노 하루카 (17 / 160cm)
 - 성격 : 밝고 사교적인 미오의 소꿉친구.
 - 입체 포인트 : 누구와도 금방 친해지지만 과거 이야기는 가볍게 넘김.

 - 버릇 : 팔찌를 만지작거림. 좋아하는 것은 고양이와 단 음식, 싫은 것은 혼자 있는 시간.
 - 프리타임 : 사진 찍기, 고양이 간식 주기.

16 시노미야 카에데 (17 / 168cm)

■ 6. 프리타임 시스템
----------------------------------------------------------------
- 챕터당 프리타임 슬롯 3~4개 (호텔 외 구역은 개방 시 추가).
- 캐릭터당 총 3개의 이벤트 : (1) 초반 만남 (2) 중반 심화 (3) 후반 전환.
- 이벤트를 완료하면 '스킬 조각'이 주어지고, 재판용 스킬로 교환 가능.
- 선물 시스템 : 래피 코인으로 캡슐 머신에서 선물 획득, 취향에 맞는 선물을 주면 호감도 상승.

[스킬 예시]
 - 집중 연장 : 논파 시간 +15%
 - 반론 지원 : 반론 쇼다운에서 힌트 1회
 - 기억 보조 : 잘못된 증언 하이라이트
 - 노트 정리 : 노트 페이지 열람 시 핵심 줄 강조
 - 규칙 질의 +1 : 질의 횟수 1회 추가
 - 침착함 : 오답 페널티 -20%
