■ 0. v1 대비 변경점
----------------------------------------------------------------
- 자살 사건 삭제. 나나는 5장 피해자로 이동.
- 3장 범인 = 소라 (빙의로 켄의 몸을 빼앗고 자기 몸을 죽여 '피해자'로 위장).
- 4장 범인 = 레이 (원래부터로 '존재하지 않던 방'을 만들어 살인, 피해자는 가짜 하루카).
- 가짜 하루카 생성 시점을 '5년 전'에서 '게임 시작 직전(0일차 밤)'으로 변경.
  → "처음부터 15명이었다"는 구조가 성립하고, 4장 재판의 핵심 반전이 됨.
- 마법 싸움 배제. 모든 사건은 '공개된 규칙의 조합'으로 풀리는 순수 추리.
- 공정성 장치 3종 신설 (래피 수첩 / 래피 파일 / 규칙 질의).
- 사망 11명, 생존 5명(미오, 린, 아이, 카에데 + 체포되는 코토)

■ 1. 공정성 규칙 (플레이어가 풀 수 있도록 보장하는 장치)
----------------------------------------------------------------
1) 래피 수첩 : 1장에 전원에게 지급되는 규칙서. 아래가 적혀 있음.
   - 16명의 마법 이름과 발동 조건·약점 (공개). 사용 횟수·실제 사용 여부는 비공개.
   - 구역 지도 (인쇄본). 래피는 "수첩에는 오류가 없다"고 선언 → 물증의 기준점.
   - 챕터마다 규칙이 추가됨 (소등 시간, 극장 입장 규칙 등).
2) 래피 파일 : 시체 발견 직후 지급되는 검안서. 사망 추정 시각(범위), 사인, 특이사항을 기재.
   - 거짓은 쓰지 않으나 일부러 생략하는 항목이 있음 (생략된 것을 추리해야 함).
3) 규칙 질의 : 재판 중 래피에게 마법 규칙을 최대 5회 질의 가능. 래피는 항상 진실로 답함.
   - 100% 확장 규칙은 평소 비공개이며, 질의로만 확인 가능.
4) 증거 제시 원칙 : 재판의 결론은 반드시 '플레이어가 확보한 물증 + 규칙 질의'만으로 도출되어야 함.

■ 2. 마법표 (공개 조건 / 100% 확장)
----------------------------------------------------------------
공통 : 억제 = 평소에도 사용, 위력 약함. 100% = 살의 있을 때만 발동, 제한 일부 해제.

 미오     기록     손글씨는 마법으로도 지울 수 없음. 하루 1페이지, 본인이 사실이라 믿는 내용만. / 100%: 쓴 문장과 모순되는 마법 효과 무효화
 레이     원래부터 물체 생성 + 모두(본인 포함)가 '원래부터 있었다'고 믿음. 100%에서만 가능, 하루 1회. 생성물이 소멸하면 모순된 기억이 돌아옴 / 100%에서만 존재하는 마법
 소라     빙의     상대가 잠들었거나 의식이 없을 때만, 15분. 본체는 무방비. 빙의 중에는 호스트의 마법을 쓸 수 없고, 신체 능력은 호스트의 것 / 100%: 시간제한 해제. 본체가 사망하면 빙의가 고정되고 호스트의 의식은 소멸
 켄       최면     눈 맞춤 + 이름 호명 + 3문장 이내. 상대가 정말 하기 싫은 일은 못 시킴 / 100%: 거부하기 어렵게 만듦
 나나     망각     접촉한 상대의 최근 1시간 기억을 흐림 / 100%: 영구 삭제
 리쿠     대역     두 사람의 신원 인식을 10분간 맞바꿈. 거울·사진에는 안 통함 / 100%: 30분
 아카리   되감기   직전 10초를 되돌림(세계 전체가 되돌아가며 본인만 기억). 하루 1회, 갱신 07:00 / 100%: 30초
 유우     공명     감정을 증폭·전염. 본인도 같은 감정에 물듦 / 100%: 범위 확대
 코토     맹세     상호 합의한 약속의 위반에 대가. 서약선이 손목에 생김 / 100%: 합의 없이도 일방 구속 시도 (단, 상대가 거부 의사를 밝히면 실패)
 사츠키   그림자   그림자를 분신처럼 움직임. 그늘·밤에만, 빛 아래에서는 소멸, 거울에 안 비침 / 100%: 분신이 물건을 쥠
 타이가   괴력     심박수가 올라야 발동, 사용 후 10분간 근육이 풀림 / 100%: 위력 대폭 증가
 린       변신     직접 본 사람만 흉내, 목소리·흉터는 못 따라함 / 100%: 목소리 모방
 쇼       재생     통증을 느껴야 발동, 쿨다운 반나절 / 100%: 쿨다운 단축
 아이     경직     이름을 아는 상대의 몸을 3초간 멈춤 / 100%: 5초
 하루카   각성     한 감각을 극대화하면 다른 한 감각이 꺼짐 / 100%: 두 감각 극대화
 카에데   서리     얼음을 만듦 / 100%: 냉각 범위 확대

※ 하루카의 각성은 레이가 생성할 때 '위험하지 않은 마법'으로 설정한 것. 진짜 하루카의 마법은 '마음 전달'.

■ 3. 진상 (5년 전과 0일차 밤)
----------------------------------------------------------------
[5년 전 — 개장 전야]
- 초대된 아이 16명(전원 직원 자녀). 진짜 아사노 하루카는 청각이 뛰어난 소녀. 왼손잡이, 토끼 인형을 좋아함, 고양이 알레르기.
- 코토의 아버지(수석 기술자)는 드림 코어의 이상 징후를 알고도 점검표를 위조. 아카리의 아버지가 최종 서명.
- 19:30 하루카가 점검표 사본을 근거로 코토에게 따짐. 둘이 코어 홀 점검 통로로 향함 (다수의 아이가 목격).
- 19:40 코토가 하루카를 난간에서 밀침. 순간의 살의를 드림 코어가 증폭 → 폭주 → 어른 수백 명 사망.
- 하루카는 마지막 마법으로 품 속 토끼 인형(미오가 선물, 귀를 빨간 실로 꿰맨 시제품 「래피」)에 마음 일부를 옮김. 인형의 힘으로 대피소 문이 열려 15명 생존.
- 20:50 코토만 늦게 대피소에 합류(입소 단말에 기록).
- 직후 코토가 맹세 2건을 체결. 나나는 아이들(19:00~20:00 사이 1시간)의 기억을 지우고 침묵. 레이는 침묵 약속.
  지워진 기억에는 "하루카가 코토와 함께 점검 통로로 갔다"는 목격이 포함됨.
- 이후 5년간 15명은 "하루카는 사고로 죽었다"고 알고 있었음. 누구도 살인이라 생각하지 않음.

[0일차 밤 — 게임 시작 직전]
- 래피(깨어난 인형)가 코어의 잔류 에너지로 초대 명단 16명을 소환하려 함. 실제 도착은 15명.
- 가장 먼저 눈을 뜬 코토가 상황을 파악. 래피가 '하루카의 부재'를 문제 삼으면 5년 전을 파고들 것이라 판단.
- 코토가 레이와의 5년 전 맹세를 이용해 「원래부터」로 '아사노 하루카'를 생성시킴.
  (래피의 규칙이 발효되기 전이라 레이는 살의 없이 마법을 사용할 수 있었음.)
- 레이의 기억에 의존한 가짜 : 오른손잡이, 인형에 무관심, 고양이를 좋아함, 마법은 안전한 각성.
- 모든 참가자는 "하루카는 사고에서 살아남아 5년간 함께 자랐다"고 믿게 됨.
- 미오는 하루카를 소꿉친구로 믿음. 5년 전 일기장(사고 후 "하루카가 죽었다" 기록)은 개인 물품 상자에 들어 있으나 다시 읽지 않음.

[래피의 정체와 목적]
- 5년간 잠든 인형이 코어 잔류 에너지로 깨어남. 자기 이름과 과거는 기억하지 못하고 "누가 날 죽였는가"라는 감정만 남음.
- 살의에 반응하는 코어의 법칙이 래피의 존재 조건. 규칙을 어기면 소멸.
- 가짜 하루카를 보면 이유 모를 불쾌감을 느낌(피함).
- 코어는 살의를 먹고 기억을 복원하므로, 래피는 재판과 구역 확장을 통해 기억을 되살리려 함.

[납치 이유]
- 사고 당일 코어 홀 가까이에 있던 생존자 15명 중에 하루카를 죽인 사람이 있다는 것만 래피는 알고 있음.
- 래피는 살의의 흔적으로 진범을 찾으려 함. 코토는 이것을 역이용해 목격자를 제거하려 함.

■ 4. 흑막 코토의 행동 원리
----------------------------------------------------------------
- 직접 살인은 하지 않음. 맹세로 사람의 입을 막고 심리를 조작해 대신 움직이게 함.
- 맹세의 형태 : "내가 널 지켜 줄게, 대신 내 이름은 말하지 마."
- 서약선 : 맹세를 맺은 사람 손목에 가는 검은 선. 상대마다 하나씩 쌓임. 코토는 완장과 긴 카디건으로 가림.
- 맹세 체결 상대 : 나나(5년 전), 레이(5년 전), 아카리(2장), 사츠키(5장), 하루카(0일차 후 간접), 미오(6장 직전, 함정).
- 코토의 약점 : 래피가 하루카의 마음이라는 것을 모름 / 가짜 하루카가 사라지면 기억이 돌아와 판이 흔들림.

■ 6. 챕터별 상세
----------------------------------------------------------------

================ 1장 「개장」 ================
구역 : 중앙 광장, 회전목마, 드림 호텔(1~4층), 푸드코트, 기념품샵
동기 : 래피가 "바깥 소식 영상"을 배포. 쇼는 여동생이 위독하다는 영상을 봄. (+ 졸업 규칙 선언)
범인 쇼의 동기 : 졸업해서 여동생에게 가려는 절박함. 순찰대장 타이가가 가장 큰 장애물.

[진상 타임라인]
 22:30 쇼가 메모를 남기지 않고 푸드코트 뒷문 서비스 복도를 통해 회전목마로 이동.
 22:50 쇼가 타이가에게 "환자가 쓰러졌다"며 도움을 요청 (타이가 순찰일지 마지막 줄 : "22:50 S가 회전목마 쪽에서 도움 요청, 확인하러 감").
 23:00 격투. 타이가가 살의를 품고 100% 괴력 발동 → 말 조형물 파손, 쇼의 팔이 부러지고 금속 모서리에 손목이 깊게 베임.
       쇼는 팔 골절만 재생으로 치료(쿨다운 시작), 손목 상처는 치료하지 못함(재생이 한 번만 가능했음).
 23:05 괴력 반동으로 타이가의 근육이 풀린 틈에 쇼가 급소를 노려 사망시킴.
 23:12 회전목마를 가동해 기계 압좌로 위장. 23:19 정지.
 23:30 호텔로 복귀. 방 TV를 켜 둠(타이머 라디오 채널 이용).

[래피 파일] 사망 추정 22:55~23:20 / 사인 흉부 압좌(외상성 쇼크) / 특이사항 : 피해자의 손이 떨림.

[핵심 단서]
 1. 순찰일지의 'S' : 소라, 쇼, 사츠키 세 명이 후보 (레드 헤링).
 2. 말 조형물 파손 = 100% 괴력 흔적 → 피해자가 상대를 죽이려 했다는 뜻 → 정당방위 가능성.
 3. 타이가의 손이 떨림 = 괴력 반동 → 마지막 순간 무력했음.
 4. 회전목마 구동 로그(제어반 인쇄) 23:12 가동 / 23:19 정지.
 5. 쇼의 소매에 피가 묻었으나 팔에 상처 없음 = 재생 사용. 쿨다운으로 아침 시점에는 재사용 불가.
 6. 쇼가 아침에 붙인 파스 아래에 금속 모서리에 베인 상처. 말 조형물의 파손 단면과 일치.
 7. 쇼의 알리바이 : 옆방 아이가 "TV 소리가 23:30까지 들렸다"고 증언 → TV 소리일 뿐 쇼 본인의 소리는 없음.
 8. 호텔 TV 심야 채널의 타이머 설정 흔적(리모컨 예약 기록).
 9. 푸드코트 뒷문의 열림 흔적(쇼의 소매에 묻은 주방 기름). 린의 복제 마스터키는 레드 헤링.
 10. 쇼가 검시를 자청하며 "급소"를 정확히 지적 → 의학 지식 노출.

[재판 논리 체인]
 1. 사건 구도 : 피해자가 100% 괴력을 썼다 → 누군가와 격투 → 상대가 다쳤다.
 2. 부상자 찾기 : 팔 골절은 재생으로 치료 가능 → 재생 사용자는 쇼뿐. 하지만 재생 쿨다운으로 아침에 증명 불가.
 3. 쇼가 제시한 알리바이(TV 소리)의 허점 : TV는 사람이 없어도 소리를 냄.
 4. 'S' 후보 3명 중 '환자가 쓰러졌다'로 타이가를 불러낼 수 있는 사람은 의무실 지식이 있는 쇼.
 5. 파스 아래 상처 확인 → 쇼 자백.

[처형] 회전목마 「엔드리스 라운드」
[재판 후] 코토가 "서로 지켜 주자"고 제안. 래피의 말투는 아직 밝음. 새 구역 : 워터파크, 퍼레이드 거리

================ 2장 「물놀이 시즌」 ================
구역 : 워터파크 「스플래시 쿠니」, 퍼레이드 스트리트
동기 : 비밀 봉투. 각자 타인의 비밀이 든 봉투를 받음. 아카리의 비밀(유우가 받음)은 "아카리의 아버지가 사고 당일 코어 홀 안전 서명을 했다."
범인 아카리의 동기 : 가족의 죄가 알려지는 것에 대한 공포 + 코토의 거짓 정보("유우가 오늘 밤 공개할 거야").
코토 개입 : 의무실 열쇠(반장 보관)를 "약 정리 도와줘"라며 아카리에게 빌려줌. 맹세(내 이름 말하지 않기).

[진상 타임라인]
 19:30 아카리가 의무실에서 심장 박동을 흐트러뜨리는 약제(앰플)를 확보. (구체적 방법 생략)
 19:36 매점 자판기에서 유우가 평소 마시는 음료가 판매됨(판매 로그). 아카리가 병에 약을 주입.
 19:38 카에데가 접근해 아카리가 들킬 뻔함 → 아카리가 되감기 사용(하루 1회) → 카에데 접근 전의 세계로 복귀. 아카리는 사츠키에게 "곧 카에데가 올 거야"라고 말함(실수).
 19:40 아카리가 "화해의 선물"로 음료를 건넴. 유우가 마심.
 19:55 아카리가 호텔 카페에서 사츠키, 코토와 합류 (알리바이).
 20:14 유우가 약의 영향으로 극심한 공포를 느낌 → 공명이 발동해 호텔 사람 전원이 순간적으로 섬뜩함을 느낌. 모두가 이 시각을 사망 시각으로 오해.
 20:30 유우가 웨이브 풀 근처에서 쓰러져 익사. 아카리는 이미 알리바이 확보.

[래피 파일] 사망 추정 20:10~20:40 / 사인 익사 / 특이사항 : 폐의 수분량이 적음, 부정맥 소견.

[핵심 단서]
 1. 공명의 20:14 = 사망이 아니라 공포의 순간. 시간 앵커를 오판하게 만드는 장치.
 2. 폐의 수분량이 적음 → 익사 이전에 이미 의식 상실.
 3. 유우의 음료 병이 매점 쓰레기통에서 발견, 향이 다름.
 4. 쓰레기통 속 의무실 앰플 빈 용기. 의무실 열쇠 소지자는 코토와 나나.
 5. 판매 로그 19:36. 이 시각 유우 근처에 있던 사람 후보 : 아카리, 카에데(19:38 도착), 나나.
 6. 사츠키의 증언 "아카리가 카에데가 올 거라고 미리 말했다" → 되감기 사용 정황.
 7. 카에데 증언 "19:38 매점 근처에 갔지만 아무도 없었다. 그런데 이상하게 방금까지 누가 있었던 느낌."
 8. 아카리의 공개 마법은 되감기이고 하루 1회. 다른 사용 시점이 없음 → 19:38이 유일한 사용점.
 9. 아카리의 긴소매와 손목시계(서약선 은폐).
 10. 재판 중 아카리가 "누가 알려줬어. 그건……하나이……"라고 말하다 손목을 움켜쥐고 쓰러짐 (모두 죄책감으로 오해).

[재판 논리 체인]
 1. 시간 앵커 파괴 : 20:14는 공포의 시각이며 사망 시각이 아님 → 알리바이의 효력 상실.
 2. 투약 시점 추리 : 부정맥 발현 시간과 판매 로그를 합쳐 19:36~19:40으로 좁힘.
 3. 그 시각 후보 : 아카리 / 나나 / 카에데. 나나는 의무실 열쇠 소지자.
 4. 되감기 흔적 : "곧 카에데가 올 거야" 발언 → 19:38의 되감기 확정 → 그 시각 현장에 있던 사람 = 아카리.
 5. 나나는 그 시각 코토와 있었다는 증언(코토 증언).

[레드 헤링] 나나(간호 지식·의무실 열쇠) / 카에데(현장 근접)
[처형] 워터슬라이드 「스플래시 폴」
[재판 후] 사츠키가 아카리를 잃고 크게 무너짐. 코토가 사츠키에게 접근. 새 구역 : 거울 미로, 대관람차, 극장

================ 3장 「거울의 밤」 ================
구역 : 거울 미로 「미러 라비린스」, 대관람차, 드림 시어터(극장)
동기 : 래피가 극장에서 "5년 전 사고 당일 영상"을 상영. 대관람차 정상에 출구(1석)가 있다고 선언. 상영 중 입장·퇴장은 자유.
추가 규칙 : 야간 22:00 이후 외등 소등.

[범인 소라의 입체적 설정]
- 표면 : 밝고 정의로운 소방관 지망 소년. 모두의 중심.
- 내면 : 소방관이던 아버지는 사고 당일 소라를 구하려다 순직. 소라는 늘 "나는 영웅이 되어야 한다"고 스스로를 몰아붙임.
- 동기 : 상영된 사고 영상에서 아버지가 불길 속으로 들어가는 장면을 보고 무너짐. "죽기 싫다"는 본심이 드러남.
- 계획 : 자신을 '피해자'로 만들어 용의선에서 빠지고, 가장 의심받는 켄의 몸에 숨어 졸업한다.
- 왜 켄인가 : 켄이 2일 전 "최면으로 누구든 움직일 수 있다"는 발언으로 모두의 경계 대상이 되어 있었음(일상 파트 이벤트).
- 왜 리쿠인가 : 마술사 아들 리쿠가 빙의에 대해 질문을 계속하는 소라의 의도를 눈치채고 있었음(조용히 확인하려 함).

[진상 타임라인]
 20:00 극장 개막. 21:00 사고 영상 상영 시작(90분). 객석은 어둡고 사람은 흩어져 앉음.
 21:20 소라가 음향실에 "조용히 보겠다"며 들어가 카드키를 지니고 문 사이에 고무 문받침을 끼움.
 21:30 켄이 객석 J열에서 졸고 있음. 소라가 음향실에서 켄에게 빙의(100%: 리쿠에 대한 살의가 활성화 조건).
        소라 본체는 음향실에서 의식을 잃음.
 21:35 미오가 켄이 객석에서 자고 있는 것을 목격 (몸은 켄이지만 이미 소라).
 21:45 켄의 몸(소라)이 객석을 나와 무대 장치실로 이동. 리쿠와는 "장치 점검 도와줘"라는 약속(리쿠 주머니 쪽지 "21:40 소라와 장치 점검").
 21:50 샌드백 낙하 장치로 리쿠를 압사. 사고처럼 위장.
 22:00 켄의 몸이 음향실로 이동. 열려 있던 문으로 들어가 소방 도끼(극장 비상 박스)로 소라 본체를 살해.
        본체 사망 순간 빙의가 고정 → 켄의 의식은 소멸.
 22:05 문받침을 제거하고 퇴장 → 문이 자동 잠김. 카드키는 소라 본체의 주머니 안.
 22:25 켄의 몸이 객석에 돌아와 자는 척.
 22:40 아이가 켄을 깨움. "켄"은 눈을 뜨자마자 "소라는? 소라 어디 갔어?"라고 물음(자신의 몸을 확인하려는 반사).

[래피 파일]
 - 소라 : 사망 추정 21:55~22:10 / 사인 두부 및 상체 타격(도끼류) / 특이사항 : 방어흔 없음.
 - 리쿠 : 사망 추정 21:45~21:55 / 사인 압좌 / 특이사항 : 낙하물 아래에 서 있는 자세.
 ※ 켄의 의식 소멸은 파일에 기재되지 않음.

[핵심 단서]
 1. 소라 시체 : 음향실에서 자동 잠김. 카드키는 시체 주머니. 린이 피킹으로 개방.
 2. 방어흔 없음 = 의식 없는 상태에서 살해 → 소라 본체는 무방비 상태(빙의 사용 중)였다는 가설.
 3. 리쿠 주머니의 약속 쪽지 "21:40 소라와 장치 점검" → 소라가 리쿠를 불러냈다.
 4. 켄이 객석에서 자는 모습을 미오(21:35), 아이(22:40)가 목격. 켄의 알리바이로 여겨짐.
 5. 객석 통로 쓰레기통에서 발견된 고무 문받침 (음향실 문받침과 동일).
 6. 소방 도끼 보관함 개봉 기록(래피 파일 부록의 봉인 로그).
 7. 켄 몸의 이상 행동 : 눈 뜨자마자 소라의 행방 확인 / 손잡이 / 버릇.
 8. 미오의 노트(기록) : "켄은 오른손 엄지로 입술을 만진다", "소라는 왼손잡이", "켄은 말하기 전 오른쪽 입꼬리를 올린다".
 9. 켄이 재판에서 소라 이야기가 나올 때마다 왼손으로 머리를 쓸어 올리는 습관.
 10. 켄의 최면 시연 실패(린이 동의해 시연 → 불발).
 11. 규칙 질의 : "빙의 중 호스트의 마법은?" 사용 불가. "100% 빙의에서 본체가 사망하면?" 빙의가 고정되고 호스트의 의식은 소멸.

[재판 논리 체인]
 1. 두 시체의 시간 관계 : 리쿠(21:50) → 소라(22:00). 이동 거리상 한 사람이 가능.
 2. 소라 본체는 방어흔이 없다 → 무방비 상태에서 살해됨. 가설 A : 소라가 잠들었었다 / 가설 B : 소라가 빙의 사용 중이었다.
 3. 빙의 사용 중이었다면 호스트는 '잠든 사람' → 알리바이상 잠든 것이 확인된 사람은 켄뿐.
 4. 그러나 켄이 범인이라면 소라를 죽일 동기가 약함. 소라가 켄에게 빙의 중이었다면 '소라가 범인'일 가능성이 열림.
 5. 규칙 질의로 100% 빙의의 고정 규칙 확인 → 소라 본체가 죽어도 소라의 의식은 켄의 몸에서 살아있다.
 6. 증명 : (a) 눈 뜬 직후 소라의 행방 확인, (b) 왼손 습관, (c) 미오의 노트와 불일치, (d) 최면 시연 불발(빙의 중 호스트 마법 불가).
 7. 결론 : 범인은 '이미 죽은 소라'. 소라를 지목해야 정답.
 8. 오답 시나리오 : 켄을 지목하면 래피는 "오답"을 선언하고 켄의 몸을 가진 소라가 졸업.

[레드 헤링] 린의 복제 마스터키 / 코토·나나(호텔 알리바이) / 사츠키(단독 순찰)

[재판 클라이맥스]
- 켄(소라)이 "나는 켄이야"라고 연기하지만 연기 천재인 켄의 눈빛이 아니라는 지적.
- 소라의 고백 : "죽기 싫었어. 아버지처럼 되고 싶지 않았어."
- 래피 : "정답. 범인은 소라(의식)입니다." 켄의 몸을 처형.

[처형] 거울 미로 「미러 파라독스」 : 켄의 몸이 거울의 방에서 끝없이 갈라져 사라지는 연출(잔혹 묘사 없음).
[재판 후] 생존자들은 소라가 범인이었다는 사실과 켄이 이미 소멸해 있었다는 사실에 충격. 래피의 말투가 크게 가라앉음.
새 구역 : 롤러코스터, 호텔 VIP 플로어(5층)

================ 4장 「잠든 롤러코스터」 ================
구역 : 롤러코스터 「드림 라이너」(승강장, 제어실, 정비동), 호텔 5층 VIP 플로어
동기 : 래피가 "VIP 플로어에서는 자유롭게 지낼 수 있어요. 대신 한 사람이 돌아오지 않을 수 있어요."라고 말함. 5층에는 사고 당일 사진이 걸려 있는 갤러리가 있음.
추가 규칙 : VIP 플로어는 객실 배정이 없고 자유 이용.

[범인 레이의 입체적 설정]
- 표면 : 냉정하고 거리를 두는 도련님.
- 내면 : 5년간 코토와의 맹세에 묶여 침묵. 0일차 밤 가짜 하루카를 만든 죄책감이 가장 큼.
- 동기 : 가짜 하루카를 '파괴'하면 모순된 기억이 돌아와 거짓이 끝난다. 하지만 그는 말을 할 수 없음. 그래서 '재판을 통해 진실이 드러나도록' 사건을 설계함.
- 그는 이기려는 것이 아니라 미오의 노트(변조 불가)에 승부를 걸었음. 풀리면 처형, 안 풀리면 졸업.

[진상 타임라인]
 17:50 미오가 VIP 플로어를 둘러보며 노트에 스케치. "5F: 501, 502, 503, 504 / 리넨 창고 / 비상계단".
 18:20 레이가 리넨 창고 자리에 방을 생성(100%, 하루 1회). "505호"는 원래부터 있던 방으로 모두가 믿게 됨.
 19:30 하루카에게 "미오가 505호에서 기다린다"는 쪽지를 전달(미오 필체 모방).
 19:35 하루카가 505호로 들어감. 레이가 문 외부 걸쇠를 걸고 퇴장.
 20:10 레이가 롤러코스터 정비동에서 린과 합류(발전기 점검 구경). 21:40까지 동행(알리바이).
 21:30 505호는 환기구가 없어 하루카가 질식사.
 22:30 미오가 하루카를 찾다가 발견. 문 외부 걸쇠가 걸려 있고 열쇠는 방 안.

[505호 이상 징후]
 - 환기구 없음, 스프링클러 없음, 연기 감지기 없음, 문 명패의 서체가 다른 객실과 다름.
 - 복도 길이와 방 배치가 평면도와 불일치. 벽을 두드리면 속이 빈 소리.
 - 평면도(래피 수첩 지도, 엘리베이터 홀 포스터)에는 리넨 창고가 있어야 할 자리.
 - 그러나 모든 참가자는 "원래 505호가 있었다"고 확신하며 이상을 합리화함("인쇄가 오래됐다", "리모델링이다").

[래피 파일] 사망 추정 21:00~22:00 / 사인 질식 / 특이사항 : 외상 없음, 손톱에 문 긁힌 흔적, 체온 하강이 느림.

[핵심 단서]
 1. 하루카의 사인이 질식인데 방 안에 질식 요인이 없음 → 환기구 없는 방.
 2. 외부 걸쇠가 걸려 있음 → 밖에서 건 사람이 있다.
 3. 쪽지 "505호에서 기다릴게 —미오". 미오는 쓴 적 없음. 미오의 그날 일기 페이지에도 없음.
 4. 린의 줄자 측정 : 복도 길이 계산상 505호는 존재할 수 없는 폭.
 5. 평면도(래피 수첩)와 엘리베이터 포스터 : 두 인쇄물 모두 5F에 리넨 창고 표기. 래피 : "수첩은 오류가 없습니다."
 6. 미오의 17:50 노트 : "5F는 4실. 리넨 창고 있음". 미오의 기억은 "505호가 있었다". 기억과 기록의 충돌.
 7. 코토의 반박 : "모두의 기억이 일치해. 기억이 증거야."
 8. 레이의 알리바이 : 20:10~21:40 린과 동행. 사망 시각엔 알리바이 성립.
 9. 규칙 질의 : "원래부터는 언제부터 있었다고 믿게 하나?" 생성 시점부터 과거 전체로 소급. "100%에서만 가능하며 하루 1회". "생성물이 소멸하면?" 모순된 기억이 돌아옴.
 10. 규칙 질의 : "원래부터 사용자는?" 래피 수첩의 공개 정보 = 레이뿐.
 11. 하루카의 소지품 : 손목시계 정지 시각 21:32.
 12. 쪽지의 필체 : 미오의 필체 모방이지만 'ㅁ'의 운필이 다름. 미오의 노트와 대조.

[재판 논리 체인 — 기억 vs 물증]
 1. 질식 사건인데 질식 요인이 없는 방 → 방이 이상하다.
 2. 방이 이상한 이유 : 환기구가 없다. 전체 참가자가 방의 존재를 의심하지 않지만 물증은 반대를 가리킴.
 3. 기억과 물증의 충돌 : 코토의 "다수 기억이 증거" 주장 vs 미오의 노트, 린의 측정, 인쇄 평면도.
 4. 결론 1 : 505호는 존재하지 않았던 방이다 → 원래부터.
 5. 원래부터 사용자는 레이 → 생성 시점은 노트의 17:50 이후, 쪽지가 전달된 19:30 이전 → 18:00~19:30.
 6. 레이의 알리바이는 사망 시각이지 생성 시각이 아님. 그 시간대 레이의 단독 행적 확인 → 확정.
 7. 100% 조건 : 살의가 있었다 → 레이는 이 시각 이미 살해를 결심했다.
 8. 방은 살인의 도구였다 : 환기구가 없는 방에 가둠 → 질식.
 9. 동기 질문 : 왜 하루카였나? 레이는 침묵. 질문 끝에 미오가 5년 전 일기장을 펼침.
 10. 일기장 : 5년 전 사고 이후 "하루카가 죽었다. 장례식이었다." 라는 기록. 현재의 하루카는 '살아남은 소꿉친구'로 기억됨 → 모순.
 11. 하루카의 특징 : 일기장의 진짜 하루카는 왼손잡이·토끼 인형 애호·고양이 알레르기. 현재 하루카는 오른손잡이·인형 무관심·고양이 애호.
 12. 규칙 질의 : "하루카는 생성물인가?" → 래피가 코어 기록을 확인, "소환 명단 16명 중 도착 15명. 하루카는 도착 기록이 없습니다." 생성물임이 확정.
 13. 결론 2 : 하루카는 처음부터 존재하지 않았다. 레이가 0일차 밤에 만들었다. 그리고 4장에서 그를 파괴했다.
 14. 레이의 마지막 한마디 : "일기장의 마지막 장을 읽어." (맹세의 경계선 위에서 가능한 한 가장 먼 거리의 힌트)
 15. 투표 : 레이.

[재판 후 — 중대 전환]
- 래피의 선언 : "정답입니다." 처형은 레이.
- 하루카의 시체가 빛으로 흩어짐. 그 순간 모든 참가자의 기억이 복원됨.
  → 5년 전 하루카는 죽었다. 0일차 밤에 하루카는 없었다. 지금까지의 하루카는 레이가 만든 존재였다.
  → 하루카를 가장 아꼈던 미오의 붕괴.
- 래피도 흔들림. "하루카……내 이름……" 단편적으로 반응.
- 코토의 표정 : 계획이 틀어지기 시작함. 래피가 '하루카'라는 이름에 반응하는 것에 불안을 느낌.
새 구역 : 드림 캐슬

[처형] 롤러코스터 「드림 라이너」 : 마지막 구간 앞에서 레일이 끝나는 연출.

================ 5장 「드림 캐슬」 ================
구역 : 드림 캐슬 (대연회장, 서고, 시계탑, 갑옷의 복도, 왕좌의 방, 수장고/무기 전시실)
분위기 : 기억 복원 직후의 불안과 분노. 모두가 "누가 하루카를 죽였는가"를 궁금해함.
동기 : 래피가 "시계탑의 종이 이틀 뒤 울릴 때 5년 전의 진실 영상이 재생된다. 그 전에 누군가 졸업하면 영상은 사라진다."라고 선언.

[핵심 구도]
- 기억이 돌아왔지만 19:00~20:00의 1시간은 비어 있음 (나나의 망각).
- 래피 : "그 1시간은 '망각'의 흔적입니다. 망각의 사용자는 나나입니다."
- 나나는 맹세로 입을 열 수 없음. 모두가 나나를 몰아붙임. 코토는 나나를 감싸며 존재감을 높임.
- 코토는 나나가 대가를 감수하고 말할지도 모른다는 불안 + 모두의 분노가 나나에게 향하는 구도를 이용.
- 사츠키(아카리의 죽음 이후 코토와 맹세 체결 : "복수를 도와줄게, 대신 내 이름은 말하지 마")에게 "아카리가 죽은 건 나나가 봉투 이야기를 퍼뜨렸기 때문"이라고 거짓 정보 제공.

[사건]
- 피해자 : 유키무라 나나 (서고에서 발견)
- 범인 : 이노우에 사츠키
- 동기 : 아카리의 복수(코토의 거짓 정보)와 졸업 욕구.
- 방법 : 사냥 집안의 지식과 석궁. 수장고의 전시용 무기 중 작동 가능한 석궁을 사용(미리 점검).

[진상 타임라인]
 20:30 사츠키가 나나를 서고로 불러냄. 석궁으로 사망시킴.
 20:35 서고 시계를 40분 느리게 조정(코토가 알려준 방법). 서고 탁상시계는 20:55를 가리키게 됨.
 20:50 사츠키가 대연회장 상영회에 합류. 알리바이 확보(여기서 모두와 함께 있음).
 21:00 시계탑 종이 울림(정상 시각). 모두가 "21:00"을 인지.
 22:10 카에데가 서고에서 나나의 시체를 발견. 서고 시계는 21:30을 가리킴(실제 22:10).

[래피 파일] 사망 추정 20:15~20:45 (범위로 기재) / 사인 석궁 화살에 의한 관통상 / 특이사항 : 책장 사이 통로, 한 발에 사망.

[핵심 단서]
 1. 서고 탁상시계 : 21:30. 시계탑 종소리 : 22:00에 울렸음 → 서고 시계가 30분 느림 → 조작 흔적.
 2. 서고 시계의 태엽 감김 정도(조정 흔적).
 3. 수장고의 석궁 1정이 사라짐. 수장고 열쇠는 코토(반장 보관).
 4. 석궁 시위의 매듭이 사냥꾼식(1장에서 사츠키가 방 문고리를 같은 매듭으로 묶은 장면의 복선).
 5. 사츠키의 알리바이 : 20:50부터 대연회장 상영회. 하지만 이 알리바이는 사망 시각(20:15~20:45) 이후.
 6. 사츠키의 토시와 팔찌 아래 서약선.
 7. 코토의 설명 중 "시계의 시각 조정 방식을 안다"는 실수.
 8. 사츠키의 동기 : 아카리 관련 발언이 많았음(일상 파트 복선).

[재판 논리 체인]
 1. 시체의 발견 시각 22:10 vs 서고 시계 21:30 → 시계가 40분 느림.
 2. 시계 조작 = 계획적 범행. 범인은 시간차를 이용한 알리바이 확보를 노림.
 3. 사망 추정 20:15~20:45 → 그 시각 알리바이가 없는 사람은 사츠키, 카에데, 린, 아이, 코토.
 4. 사츠키의 알리바이는 20:50부터이므로 사망 시각과 겹치지 않음.
 5. 석궁의 매듭이 사냥꾼식 + 서약선 → 사츠키 확정.
 6. 사츠키는 "하나이……"까지 말하다 손목을 움켜쥐고 침묵. 끝내 코토의 이름을 입에 올리지 못함.
 7. 투표 : 사츠키.

[처형] 「피날레 퍼레이드」 : 성의 대문이 닫히며 퍼레이드 플로트에 실려 사라지는 연출.
[재판 후] 래피의 말투는 극도로 가라앉음. 시계탑 종이 울리며 기억 편린이 크게 복원 : 사고 당일의 대피소 입소 단말이 코어 구역에 있다는 사실.
새 구역 : 드림 코어(지하)

================ 6장 「드림 코어」 ================
구역 : 코어 홀, 대피소, 점검 통로 B
생존자 : 미오, 코토, 린, 아이, 카에데 (5명)
분위기 : 정적과 상실. 각자의 '남은 이유'가 드러남.
최종 동기 : 래피의 마지막 소원 "누가 날 죽였는지 알려줘."

[전제]
- 코토는 5장 밤 미오에게 "내일 재판에서 서로의 말을 먼저 믿고 의심은 나중에 하자"는 약속을 청함. 미오는 선의로 수락 → 서약선 형성(함정).
- 코토의 계산 : 미오가 일기 증거를 제시하려 하면 맹세 위반 대가로 쓰러짐.

[최종 재판 증거]
 E1 미오의 5년 전 일기 : "코토가 아빠와 점검 일정으로 말다툼", "하루카가 코토에게만 할 말이 있다고 했다", "하루카와 코토가 점검 통로로 향하는 걸 봤다".
 E2 대피소 입소 단말 기록 : 15명 입소. 코토만 20:50에 늦게 입소 (다른 14명은 19:55~20:05).
 E3 서약선 : 나나(5년 전), 레이(5년 전), 아카리, 사츠키에게 있었음. 공통 접점이 코토.
 E4 래피의 기억 복원 : 추락 직전의 목소리 "미안해……아빠가……".
 E5 코토가 5장 재판에서 시계 조작 방식을 알고 있었던 것, 점검 통로 B의 존재를 언급한 것(공개 지도에 없음).
 E6 서약선이 있는 사람들의 침묵 패턴 : 모두 코토의 이름을 말하려다 쓰러짐.

[최종 재판 흐름]
 1. 래피가 정체를 밝힘. "내 이름은 하루카. 나는 이 인형 안에 있어."
    - 미오의 키링과 래피의 귀 실밥이 대응. 미오가 5년 전 꿰매 준 인형.
 2. 용의자 후보 : 사고 당일 코어 홀 근처에 있던 6명 (실제 생존자 5명 + 생존자 중 이미 죽은 자들).
 3. 코토가 사회자로 침착하게 정리. 모두가 의존하는 구도.
 4. 증거 E1~E2 제시 : 코토가 "기억이 지워졌잖아. 그 1시간은 증명할 수 없어."라고 반박.
 5. 증거 E3 제시 : 코토가 "맹세는 내 마법이니 내가 거는 쪽일 뿐"이라고 주장. 완장을 벗지 않음.
 6. 린과 아이가 완장을 풀어 버림 → 팔목에 여러 줄의 검은 서약선이 드러남.
 7. 코토의 최후 카드 : 미오와의 맹세 발동 → 미오가 고통으로 쓰러짐. "맹세는 맹세야."
 8. 미오의 100% 「기록」 해금
    - 발동 조건 : 살의. 미오는 하루카를 죽인 사람에 대한 실제 살의를 자각하고 인정함.
    - 노트에 "나는 지금 코토를 의심한다"를 적음 → "의심하지 않기" 맹세와 모순 → 맹세 효과 소멸.
 9. 미오의 살의가 코어를 반응시켜 폭주 조짐. 래피(하루카)가 자신의 마음을 모두 써서 코어를 누름. 래피 소멸.
 10. 코토의 붕괴와 자백.
    - 아버지를 지키려던 13세의 공포, 하루카를 밀친 순간의 후회, 5년간 맹세로 사람들의 입을 막은 것.
 11. 투표 : 4명이 코토를 지목.

[엔딩 A (기본) — 체포]
- 래피가 소멸해 처형 장치가 작동하지 않음.
- 미오가 "살의를 버린다"고 선택하고 코토를 법의 심판에 맡김.
- 코어 정지, 공원의 문이 열림. 생존자 4명 + 체포되는 코토.
- 사고의 진상이 공표됨(안전 점검표 위조 + 한 아이의 살의).
- 마지막 장면 : 미오가 새 노트에 쓴다. "아사노 하루카는 거기에 있었다."

[엔딩 B (어두운 분기) — 처형]
- 래피의 마지막 규칙 집행으로 코토가 처형됨. 미오는 살의를 버리지 못한 채 엔딩.

----------------------------------------------------------------
■ 7. 복선 총정리
----------------------------------------------------------------
[코토]
- 1장 : "서로 지켜 주자"는 제안. 완장·긴 카디건·톱니 배지.
- 2장 : 아카리 "하나이……"에서 쓰러짐. 의무실 열쇠 대여.
- 3장 : 재판 후 사츠키에게 접근.
- 4장 : "기억이 증거"라는 반박. 래피가 '하루카'에 반응할 때 표정 변화.
- 5장 : 수장고 열쇠 소지, 시계 조작 방식 언급, 나나를 감싸는 행동.
- 6장 : 점검 통로 B 언급 → 완장 폭로.

[가짜 하루카]
- 1장 : 인형·마스코트에 무관심, 래피가 하루카를 피함, 고양이를 보고 좋아함.
- 2장 : 각성 사용 장면은 있지만 5년 전 이야기가 나오면 화제를 돌림.
- 3장 : 미오의 개인 물품 상자에 5년 전 일기장이 있으나 미오는 읽지 않음.
- 4장 : 일기장 대조 → 정체 폭로.

[래피(하루카)]
- 1장 : 귀 실밥, 미오의 키링과 같은 토끼. 미오는 이유 모를 익숙함.
- 3장 : 말투 가라앉음.
- 4장 : 하루카 시체에 반응.
- 5장 : 시계탑 종소리에 정체 편린이 복원됨.
- 6장 : 정체 공개와 희생.

[미오의 기록]
- 1장 : 평범한 일기 습관으로 취급.
- 3장 : 노트의 켄·소라 습관 기록이 결정타 중 하나.
- 4장 : 변조 불가 노트 vs 모두의 기억. 첫 대활약.
- 6장 : 100% 해금 — 맹세 무효화.

[서약선 보유자와 은폐 소품]
- 나나 : 흰 리본 / 레이 : 검은 가죽 커프스 / 아카리 : 긴소매+손목시계 / 사츠키 : 궁도 가죽 토시 / 코토 : 완장+긴 카디건
- 하루카의 팔찌는 서약선과 무관한 레드 헤링.

■ 8. 집필·제작 지침
----------------------------------------------------------------
- 각 장은 [일상 → 동기 → 사건 → 수사 → 재판 → 처형 → 에필로그] 순. 진행 시간 설계는 별도 문서.
- 모든 단서는 수사 파트에서 100% 획득 가능해야 하며, 재판 중 새 물증이 등장해서는 안 됨(규칙 질의 제외).
- 처형 연출은 잔혹 묘사를 피하고 놀이공원 어트랙션의 변형 연출로 처리.
- 전문 지식을 쓰는 살인은 서사에 필요한 수준으로만 묘사하고 구체적 절차는 생략.
