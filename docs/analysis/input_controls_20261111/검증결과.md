# 커서 좌표와 ESC 조작키 설정

요청 범위: 커서 위치 불일치 교정, ESC 환경설정의 현재 조작키·동작 설명·변경 기능. 스토리 개정은 이번 실행본에 포함하지 않았다.

## 변경

- 중앙 1280×720 UI와 전체 화면 탐색/재판 입력 좌표를 각 UI 소유자가 명시적으로 선택한다. 프레임 시작 모드에 따른 전역 좌표 전환을 제거했다.
- 전자수첩, 일반 선택지, 조사 목록, 뽑기, 갤러리, 장 선택, 난이도, 재판 기록의 고정 UI는 중앙 원점으로 입력을 변환한다. 3D 탐색/재판의 전체 화면 좌표는 유지한다.
- 해상도 변경 확인창도 환경설정과 같은 중앙 부모 아래에 배치했다.
- ESC로 환경설정을 연다. 전자수첩 안의 ESC는 기존 돌아가기를 유지한다.
- 환경설정 아래쪽 **조작키 안내 · 변경**: 38개 입력의 기능·현재 키·기본 키를 표시하고 키보드/마우스 버튼으로 변경한다. 키 설정 화면은 방향키·Enter·마우스로 조작하며 Esc/Backspace는 고정된 돌아가기다.
- 사용 중인 키는 거부하며, 입력 대기 중 Esc로 취소한다. 키 기본값 복원과 환경설정 전체 기본값 복원을 모두 지원한다.
- 변경한 키는 기존 v2 설정 저장에 `keys`로 보존한다. v1/v2의 기존 설정은 기본 키를 사용한다. 잘못된 키 형식·중복은 안전한 기본 키로 되돌리고 기존 음량·진행 저장을 유지한다.
- 입력 공통 계층을 연결해 누르고 있는 이동/리듬 입력과 일회성 결정/클릭을 함께 재지정한다. 설정 화면은 변경한 키에 잠기지 않도록 물리 입력을 받는다.
