> 피해자 유키무라 나나 / 범인 이노우에 사츠키 / 처형 「피날레 퍼레이드」
> 총 455분. 일상 120 + 자유시간 40 + 동기 15 + 에필 20 + 발견 5 + 수사 80 + 재판 165 + 처형 10.
> 개방 구역 : 드림 캐슬(대연회장·서고·시계탑·갑옷의 복도·왕좌의 방·수장고·지하 체험관·플로트 격납고).
> 일정 : 11일차(개방·동기) / 12일차(일상·사건 21:00) / 12일차 22:10 발견.
> 생존자 : 미오·코토·린·아이·카에데·나나·사츠키(7명).
> 분위기 : 흑백에 가까운 색조, 래피 장난기 10%, 감정 균열.
> 규칙 카드 추가 : **R-12 서고 규칙 : 입퇴실 장부에 서고 탁상시계의 시각으로 입·퇴실을 적을 것.** / **R-13 상영회 입장은 입장 기록기에 카드를 찍을 것(출석 체크).** / **R-14 시계탑 종은 정시에 울린다.**
> **v2 대비 보정(중요)** : 사망 추정 시각을 20:15~20:45 → **20:50~21:20**로 변경, 범행 방식을 "직접 사살"에서 **"시계 알람으로 작동하는 석궁 시한 발사 장치"**로 변경. 시계를 40분 느리게 한 이유가 **알람 시각 위장**임을 명확히 함. 상세는 `99_v2_보정사항.md`.

## B. 동기 : 시계탑의 종 (11일차 오후 / 15분)

```
[래피(방송)] "시계탑의 종이 내일 정오에 울려요. 그 순간 5년 전의 진실 영상이 재생돼요."
[래피(방송)] "그 전에 누군가 졸업하면 영상은 사라져요. …진실이 사라지는 거예요."

[래피(방송)] "망각의 사용자는 유키무라 나나 씨예요."
```

* **[장치 : 동기 구조]** 영상 소멸 위협 + 나나에 대한 공격적 시선.
* 나나는 대답하지 못하고 손목의 리본을 쥔다. 코토가 한 걸음 나서서 나나를 감쌈.
```
[코토] "…나나 씨는 말하고 싶지 않은 거예요. 억지로 몰아붙이면 안 돼요." {단호}

```
* **[복선]** "망각이 아카리를 죽였다"는 사츠키의 오해는 코토의 거짓 정보에서 비롯됨(코토가 별도로 사츠키에게 속삭인 사실은 플레이어 시점에 직접 보이지 않음).

### C-2 장치 (마법이 아닌 것)
1. **석궁 시한 발사 장치** : 책장 고정 + 끈 + 시계 알람 레버. 알람 = 방아쇠.
2. **시계 조작(40분 지연)** : 알람 설정을 20:20으로 하여 실제 21:00에 발사되게 함.
3. **입퇴실 장부** : 나나가 시계판 시각(19:45)으로 기재 → 시계가 느리다는 증거.
4. **입장 기록기** : 사츠키 20:50 입장(다른 사람은 20:30~20:40).
5. **수장고 출입 로그** : 19:50 수장고 열림.
6. **마법의 역할** : 사츠키의 마법(그림자)은 **직접 사용되지 않음**. 코토의 맹세와 거짓 정보가 동기를 만들었을 뿐.
