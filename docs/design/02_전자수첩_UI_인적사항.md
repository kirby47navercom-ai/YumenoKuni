## 3. 프로필 화면 (스크린샷 1 · 3 기반)

### 3-1. 레이아웃
```
┌─────────────────────────────────────────────────────────────┐
│ 0003   카미야 소라                       ← 학생 번호 + 이름      │
│ ┌────────┐  ┌ 이름        ──────────────  카미야 소라          │
│ │Q    E │  │ 나이                          17세               │
│ │ 초상화  │  │ 키                            172cm             │
│ │(입상   │  │ 체중                          63kg              │
│ │ 바스트) │  │ 신발 사이즈                    255mm            │
│ │        │  │ 생일                          8월 8일           │
│ └────────┘  │ 혈액형                         O형              │
│              │ 지망(꿈)                       소방관            │
│              │ 특기                           달리기, 응급 처치 │
│              └ ...                                    1 / 2   │
└─────────────────────────────────────────────────────────────┘
```
* 왼쪽 : 초상화 프레임(둥근 사각, 흰 테두리). 좌상단 `Q`, 우상단 `E` — 이전·다음 캐릭터. **초상화 에셋 = `art/standing`의 기준 입상에서 상반신 크롭 + 표정 변형**(코덱스 작업 항목).
* 오른쪽 : 필드 바(라벨은 주황 둥근 바 → 장별 테마색) + 값(우측 정렬, 흰색).
* 스크린샷 1의 `가슴둘레` 칸은 **신발 사이즈**로 대체한다(전원 미성년 설정이라 신체 치수 공개 항목은 키·체중·신발 사이즈로 제한).
* 스크린샷 3의 `좋아하는 것 / 싫어하는 것 / 생일`은 **2페이지**에 배치.

* **하루카** : 생일·혈액형·좋아하는 것·싫어하는 것·왼/오른손 항목이 **4장 재판 후 `???`로 바뀐다**(가짜 하루카 프로필 → 진짜 하루카 프로필 별도 표시 가능). 진짜 하루카 데이터는 6장 클리어 후 엔딩 컬렉션에 공개(§4 마지막).
* **래피** : 프로필 `0000`. 5장까지 대부분 `???`. 6장 재판 개정 시 이름 `아사노 하루카(래피)`로 갱신.
* **켄(소라 빙의 후)** : 3장 사건 이후 프로필이 `DECEASED`. 단, 3장 재판 직전까지는 정상 표시.
