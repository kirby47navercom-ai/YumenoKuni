# 4장 「잠든 롤러코스터」 시나리오 (⚠ 전체 스포일러)

> 피해자 아사노 하루카(가짜) / 범인 미사키 레이 / 처형 「드림 라이너」
> 총 455분. 일상 110 + 자유시간 30 + 동기 15 + 에필 15 + 발견 5 + 수사 95 + 재판 175 + 처형 10.
> 개방 구역 : 롤러코스터 「드림 라이너」(승강장·제어실·정비동·발전기실·안전 점검 통로), 호텔 5층 VIP 플로어(스위트 4실·갤러리·라운지·전용 엘리베이터 홀·비상계단).
> 일정 : 9일차(개방) / 10일차(동기·사건) / 10일차 22:30 발견.
> 분위기 : 채도 낮음, BGM 침착, 래피 장난기 30%.
> 규칙 카드 추가 : **R-10 VIP 플로어 규칙 : 객실 배정 없음, 자유 이용.** / **R-11 수첩 보증 : 래피 "수첩은 오류가 없다."(1장부터 유효)**
> 최고 난도 장. 시간표·질의·노트의 활용이 핵심. 노트 슬롯 3개 중 1개(**N4-01**)는 반드시 필요(자동 진행 보정 있음).

[래피(방송)] "… (잠깐 침묵) …소라와 켄, 리쿠가 없네요. 래피도 식당 자리가 많이 비었다는 걸 알아요."

### 4-D-02 롤러코스터 탑승 체험 (20분 / 승강장)
* 팀 : 미오·하루카·카에데 / 린·레이 / 코토·나나·아이·사츠키.
```
[하루카] "와아아! 무서워! 미오 손 잡아도 돼?!" {비명}
[미오] "…손이 아파." {웃음}
[카에데] "시간 낭비 없이 한 번 더 타자." {담백}
[레이] "…구조가 흥미롭습니다. 레일 이음새, 제동 구간." {무표정한 흥미}
[린] "레이는 롤러코스터도 설계도 보듯이 타는구나지롱."
[레이] "구조는 거짓말을 하지 않으니까요." {작은 미소}
```
* 탑승 후 정비동 : 린이 발전기 점검 일정(내일 20:10)을 레이와 잡는다.
* 안전 점검 통로 : 제한 구역 표지. **[복선]** "점검 통로"라는 단어에 코토가 약간 반응(6장 연결).

### 4-D-03 정비동 구경 (15분 / 정비동·발전기실)
```
[린] "발전기 점검은 내일 20시 10분에 같이 하기로 했지롱~! 레이 도와줘서 고마워!" {활기}
[레이] "구경하는 척하다가 사고라도 나면 곤란하니까요." {정중}
[나나] "저, 저도 보러 가도 되나요…?" {작게}
[레이] "…위험하지 않은 곳이라면."
```
* **[알리바이 장치]** 20:10 약속이 명시적으로 플레이어에게 노출됨.

### 4-D-04 VIP 플로어 첫 방문 (15분 / 5F)
* **5F의 첫 노출** : 501·502·503·504 / 갤러리 / 라운지 / 리넨 창고 / 엘리베이터 홀 / 비상계단. 객실 번호판은 **504까지만 존재**.
```
[코토] "VIP 플로어는 조용하네요. 한 사람씩 들어가 보세요." {온화}
[미오] "…객실이 넷이네. 방은 적은데 크네."
[하루카] "리넨 창고도 있어! 열어 보자!" {호기심}
[린] "에이, 안 열려 있지롱. 잠겼어."
```
* **[장치 : 플레이어 관찰]** 1인칭으로 5F를 둘러볼 때 **방 4개 + 리넨 창고**가 화면에 명확히 보임. 이후 장면에서 "다섯 번째 방"이 등장해도 플레이어는 모순을 알아챌 수 있다.
* **E4-05 선행 정보** : 엘리베이터 홀 포스터 "5F : 501~504 / 리넨 창고" 확인.

### 4-D-05 갤러리 관람 (15분 / 5F 갤러리)
* 사고 당일의 사진들. 레이·코토가 먼저 들어가 있다.
```
[미오(독백)] "(어린 우리들이 줄줄이 서서 웃고 있다. …이 날이 개장 전야였다.)"
[하루카] "와, 이거 나 맞아? 인형 안고 있는 애? …기억 안 나네~." {웃음}
(사진 속 소녀는 왼손으로 토끼 인형을 안고 있다. 얼굴은 흐릿)
[미오] "…하루카, 오른손잡이잖아." {무심결}
[하루카] "어? …아, 사진이 반전된 걸지도!" {당황}
[코토] "사진은 거울 반전인 경우도 있어요." {온화}
```
* **E4-13 갤러리 사진** : 왼손으로 토끼 인형을 안은 소녀. 조사 모드로 확대 가능. 반전 가능성은 있지만 **인형을 좋아하는 점은 하루카의 현재 성향과 모순**. 사진 속 소녀의 이름표는 흐려짐.
* 코토의 "거울 반전" 발언은 **레드 헤링(합리화)**. 미오는 노트에 "사진의 소녀는 왼손으로 인형을 안고 있다"를 적을 수 있다(N4-02 후보).

### 4-D-06 프리타임 (슬롯 ①~③) — 30분
* 후보 : 전원. 하루카·레이 이벤트가 열려 있는 마지막 장.

### C-2 장치 (마법이 아닌 것)
1. **외부 걸쇠** : 문 바깥에서 걸어 안에서 열 수 없게 하는 기구. 방 안에서는 손잡이만 돌아감.
2. **환기 설비 부재** : 505호에는 환기구·스프링클러·연기 감지기가 없음.
3. **쪽지(필체 모방)** : 종이 + 펜. 미오의 필체를 베낌.
4. **알리바이 구조** : 정비동 동행(린).
5. **마법의 역할** : 505호를 "원래부터 있던 방"으로 만드는 것뿐(방의 존재). 살인 수단은 **걸쇠 + 환기 부재**.
