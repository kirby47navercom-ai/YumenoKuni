# 유메노쿠니 시스템 기획서 (구현 기준)

> 범위: 게임 전체 루프, 1인칭 탐색, 코인·뽑기·선물, 인연 레벨, 스킬, 재판 미니게임, 챕터 시간표.
> 스포일러 없음. 사건 내용은 `11_*` ~ `16_*` 문서(⚠ 스포) 참조.
> 모든 수치는 1차 밸런스 값이며 플레이 테스트로 조정한다.

---

## 1. 게임 한 줄 정의

1인칭으로 놀이공원을 걸어 다니며 동료와 친해지고(일상), 시체가 나오면 현장을 뒤져 증거를 모으고(수사), 모인 증거로 범인을 논파하는(재판) 추리 어드벤처. 마법은 싸움 수단이 아니라 **"공개된 규칙표"** 이며, 모든 사건은 규칙표 + 물증 + 장치(기계·시계·열쇠·장소)의 조합으로 풀린다.

### 1-1. 설계 원칙 (사건 설계자가 지킬 것)
1. **마법만으로 사람을 죽이지 않는다.** 모든 사건에는 반드시 물리적 장치(기계, 건물 구조, 도구, 시간표, 열쇠, 약품)가 있고, 마법은 그 장치를 쓸 수 있게 해 주는 조건 하나일 뿐이다.
2. **한 사건당 혼란 장치 최소 4종**: ① 가짜 시간 기준 ② 가짜 용의자(레드 헤링) ③ 그럴듯한 오답 가설 ④ 증언의 거짓/착각. 각 장치마다 **반증 경로**를 반드시 수사 파트에 둔다.
3. **재판에 새 물증이 나오지 않는다.** 규칙 질의(래피 질의)로 얻는 정보는 "마법·장별 규칙"과 "시스템 기록(소환·도착 기록, 파일의 범위 정보)"뿐이고 "사실(누가 무엇을 했는가)"은 절대 알려 주지 않는다.
4. **래피는 거짓을 말하지 않지만 일부러 말하지 않는 것은 있다.** (래피 파일의 생략 항목)
5. **정답 경로는 하나, 오답 경로는 여러 개.** 각 단계에서 플레이어가 틀려도 힌트가 누적되도록 한다.

## 1-2. 마법 비공개 원칙 (v3.1 확정)
* **모두가 마법을 갖고 있지만, 시작 시점에는 본인 마법만 안다.** 래피 수첩의 마법 페이지에는 **본인 마법 한 칸만** 표시되고 나머지는 `???`.
* 마법 정보는 아래 4경로로만 해금된다(해금되면 수첩의 해당 칸이 채워짐).
  1. **본인이 밝힘** : 자유시간 이벤트(인연 Lv2~3), 일상 중 자연스러운 시연, 성격상 자랑(타이가 등).
  2. **일상 중 목격** : 사건 전 일상 장면에서 마법의 *효과*가 플레이어에게 보임(마법 이름은 안 뜸). 목격하면 **마법 힌트 카드(M-xx)** 로 기록.
  3. **수사 중 증언·증거** : 사건 현장의 사용 흔적, 래피 파일 부록 등.
  4. **재판 중 래피 질의** : "~한 효과를 내는 마법이 있나요? 누구의 것인가요?" 형태의 질문에 래피가 **마법 이름·소유자·규칙**을 답함. (질의 1회 소모, 사건에 관련된 마법만 답변.)
* **래피 질의가 답하지 않는 것** : 누가 그 마법을 *썼는가*, 언제·어디서 썼는가(사실 관계).
* **100% 규칙**은 질의로만 확인 가능(기존과 동일).
* 공정성 보강 : 각 장 일상 파트에서 **그 장 사건에 쓰이는 마법의 효과**가 최소 1회 플레이어 눈에 보이도록 배치한다(마법 이름은 비공개).
* 프롤로그에는 마법 공개·재판·질의·연습 사건이 **없다**. 래피가 "마법이 있다"고만 말한다.

### 2-3. 하루 구조 (일상 파트)

```
아침 방송(래피 공지, 구역 개방)  → 일상 파트 A (이벤트·탐색)
→ 점심 / 자유시간 슬롯 1~2
→ 일상 파트 B (이벤트·탐색)
→ 자유시간 슬롯 3~4
→ 일상 파트 C (이벤트)
→ 동기 발표(저녁 7시경, 래피 모니터 방송)
→ 밤(호텔 복귀 안내·소등 규칙) → 사건 발생 → 아침 시체 발견 방송
```

* 장 하나는 인게임 약 3일. (일상 A·B·C = 1일차~2일차, 동기 = 2일차 저녁, 사건 = 2일차 밤, 발견 = 3일차 아침)
* **시체 발견 방송** : 시체를 3명 이상이 발견하면 방송이 울린다("딩동♪ 시체가 발견되었어요!"). 정확히는 *발견자 중 1명 이상이 시체 발견 사실을 인지하고, 서로 3명이 모이는 순간* 울리는 것으로 본다. (이 규칙은 수첩 3쪽에 인쇄되어 있음. 공정성 장치.)

## 3. 1인칭 탐색 시스템

### 3-1. 이동·조작
* 이동 : 노드 방식 + 자유 시점 회전(360°). 구역 안에서는 **노드(정지점)** 사이를 클릭 이동. 이동 시간은 연출상 0.5초 페이드. (제작 부담 감소, 단간론파 3D 이동과 유사한 조작감)
* 시점 : 마우스 상하좌우 카메라. 클릭 가능한 오브젝트는 하이라이트(옵션으로 끌 수 있음).
* **조사 모드** : 오브젝트를 클릭하면 확대 시점으로 전환. 확대 시점에서 다시 클릭 가능한 "관찰점"이 최대 3개. 관찰점마다 텍스트(미오의 독백) 출력.
* **대화 모드** : 캐릭터 노드에서 말 걸기. 수사 중에는 "증언 듣기 / 사건 질문 / 소지품 요청"의 3개 메뉴.
* **미니맵** : 수첩 지도가 그대로 열린다. 미방문 방은 회색. 증거가 남은 방은 별 표시(옵션).

### 3-2. 수집 대상
| 종류 | 설명 | 표시 |
|---|---|---|
| 증거 카드 | 재판에 쓰는 물증. 장·번호로 ID 부여 (예: E1-04) | 노랑 카드 |
| 증언 조각 | 수사 중 인물에게 들은 증언 (예: T1-02) | 파랑 카드 |
| 규칙 카드 | 수첩 규칙(마법 조건·약점·장별 추가 규칙) | 분홍 카드 |
| 래피 코인 | 탐색 수집 아이템. 구역마다 8~12개 | 금빛 코인 |
| 선물 | 캡슐 머신에서 나옴. 자유시간용 | 인벤토리 |
| 메모 | 일기·쪽지·포스터 등. 사건과 무관한 월드 텍스트 | 회색 카드(재판 사용 불가) |

### 3-3. 미오의 노트(핵심 시스템)
* 미오의 마법 「기록」과 직결되는 시스템. **하루에 1회** 수사/일상 중 "노트에 적기"를 할 수 있다.
* 방법 : 중요하다고 판단한 증거 카드 1장 또는 장면 1개를 노트에 적으면 **노트 증거(변조 불가)** 로 승격.
* 노트 증거의 효과
  1. 재판 중 거짓 증언·기억 조작을 반박할 때 "노트" 탄환으로 **무조건 유효**.
  2. 승격하지 않은 카드는 "정황 증거" 로 취급되어 반론 쇼다운에서 상대가 "그건 기억 아니냐"고 피할 수 있음(난이도 상승 요소).
* 승격은 사건 발생 전 일상 파트에서도 가능(일상 중 이벤트를 노트에 적을 수 있음 → 특정 장의 필수 복선이 된다).
* 안전장치 : 수사 종료 시 노트에 승격 슬롯이 남아 있으면 미오가 "오늘 적을 만한 게 있을까…"라며 제안(힌트 UI).
* 한 장에 노트 슬롯은 일상 1일차·2일차·수사 1회 = **최대 3개**. (복선 확인 후 선택하게 함)

### 3-4. 퍼즐성 수사 요소 (장마다 1개 이상)
* 열쇠·자물쇠 → 린이 있으면 열 수 있지만 동행해야 한다(자유시간 호감도 연계).
* 기계 조작 → 제어반 로그를 인쇄해 증거 카드화.
* 지도·평면도 대조 → 수첩 지도와 현장을 비교(4장 핵심).
* 시계·시간 → 시계 3종(방 시계·손목시계·시계탑 종)을 대조하는 UI (5장 핵심).

## 5. 자유시간 · 인연 레벨

### 5-1. 프리타임 구조 (단간론파식)
* 프리타임은 **한 번에 2슬롯**을 쓰는 "프리타임 세션" 단위로 열린다. **스토리 → 프리타임 → 스토리 → 프리타임** 순으로 끼워 넣는다.
* 슬롯 1개 = 약 7분. 세션 1회 = 약 14분(슬롯 2).
* 장별 프리타임 세션 수 :

| 장 | 세션 | 슬롯 | 비고 |
|---|---|---|---|
| 프롤로그 | 0 | 0 | 없음(스토리 전용) |
| 1장 | 3 | 6 | 스토리 ▶ FT ▶ 스토리 ▶ FT ▶ 스토리 ▶ FT ▶ 동기 |
| 2장 | 3 | 6 | 동일 |
| 3장 | 2 | 4 | 수사·재판 분량이 늘어 세션 감소 |
| 4장 | 2 | 4 | 최고 난도 장 |
| 5장 | 1 | 2 | 후반부 압축 |
| 6장 | 0 | 0 | 대피소 마지막 대화(고정 이벤트) |
| **합** | **11** | **22** | |

### 6-1. 구조
* 스킬 획득은 인연 레벨에 따라 (Lv2 / Lv4) 각 인물당 2종. 총 30종 + 미오 기본 5종.
* **장착 코스트(SP)** : 같은 시점에 장착할 수 있는 총 코스트에 한도가 있다.
  * 시작 6 SP, 장마다 +2 SP, 최대 16 SP.

## 7. 재판 시스템

### 7-1. 공통 UI
* 집중력(♥ 게이지), 마음(MP) 게이지, 증거 탄환 슬롯(최대 10), 노트 증거는 파란 테두리.
* **합의 시스템** : 정답 문장에 '동의' 버튼. 옳은 증언에 반박하면 오답.
* **거짓 증언** : 증언의 일부는 거짓. 증거로 판별.
* **래피의 심판 연출** : 오답 시 래피가 장난스럽게 "아깝다~"; 장이 진행될수록 말투가 가라앉음.

### 7-2. 재판 6단계 (공통 골격)
| 단계 | 이름 | 플레이 | 비고 |
|---|---|---|---|
| 1 | 사건 정리 | **시간표 맞추기** : 래피 파일 + 현장 단서를 시간표에 배치 | 이 단계의 시각 기준이 이후 모든 단계에 사용 |
| 2 | 논파 스트림 | 흐르는 증언의 허점을 증거로 격파(노란 문장) / 옳으면 '동의'(파란 문장) | 단계마다 1~3개 스트림 |
| 3 | 알리바이 그리드 | 용의자 × 시간대 표를 채워 모순을 발견 | 2장부터 |
| 4 | 재구성 컷 | 4~8컷 순서 배치 / 평면도 이동선 / 빈칸 채우기 | |
| 5 | 래피 질의 | 래피에게 규칙을 질문 (최대 5회; 질의 슬롯은 스킬로 +1) | |
| 6 | 최종 추궁 | 반론 쇼다운 → 피날레 컷 → 투표 → 자백 → 처형 | |

### 7-3. 미니게임 상세
* **시간표 맞추기** : 가로 시간 축, 세로 장소. 카드를 끌어 놓음. 오배치 시 카드가 튕김(오답 1).
* **논파 스트림** : 증언 문장이 우→좌로 흐름. 문장은 클릭 가능(플레이어는 문장 일시정지 후 증거 탄환 장전). 허점 문장은 노란 마크가 약하게 보이다가 사라졌다 다시 나타남. 노란 마크 3개 이상 놓치면 −10.
* **반론 쇼다운** : 상대의 연속 발언이 위아래로 겹쳐 흐르며 자르고(타이밍), 마지막에 증거를 선택해 일격. 실패 시 −20, 일격 성공 시 MP +20.
* **알리바이 그리드** : 용의자(행) × 시간대(열). 증언 카드를 끌어 놓고, 모순이 생기면 칸이 붉게 깜박임. 완성 후 "비는 칸 = 범행 가능 시간"이 강조.
* **재구성 컷** : 컷 카드를 드래그. 오답 시 컷이 흔들림. 시각적 만화 컷으로 사건의 과정을 요약(최종 컷은 클라이맥스).
* **래피 질의** : 질문 선택 UI. 질문은 사건 단서와 연계된 "가능한 질문" 8~10개 중 선택(최대 5회). **질문을 잘못 선택하면 래피가 "그건 질문이 아니에요"로 답하고 질의 횟수를 1회 소모**(일부 질의는 소모 없음, 힌트용).
* **피날레 컷** : 재구성 컷의 최종 단계. 6~8컷 + 래피 연출.

### 7-4. 장별 특수 미니게임
| 장 | 이름 | 내용 |
|---|---|---|
| 1 | 회전목마 로그 맞추기 | 구동 로그와 시간표를 맞추는 입문 퍼즐 |
| 2 | 병 추적 | 매점·쓰레기통·의무실의 병/앰플의 이동 경로를 배치 |
| 3 | 거울 길 찾기 | 용의자의 이동 경로를 거울 미로 평면에서 그림(본체/켄/소라 분리) |
| 4 | 평면도 간섭 | 수첩 지도와 현장 사진을 겹쳐 틀린 곳을 찾음 |
| 5 | 시계 맞추기 | 서고 시계·손목시계·시계탑 종의 시각을 정렬 |
| 6 | 서약선 해체 | 손목의 서약선을 노트 문장과 대조하며 하나씩 지움 |

### 7-5. 난이도
* 이지 / 노멀 / 하드 (하드는 노란 마크 하이라이트가 없음).
* 오답이 누적되면 래피의 연출이 짧아져 지루함 방지.
* **체크포인트** : 재판 단계마다 저장. 재도전 시 직전 단계부터.

### 7-6. 투표·처형
* 투표는 **이름 지명 방식**. (사망자도 지명 가능 — 규칙 질의로 확인 가능, 3장에서 필수)
* 정답 → 자백 연출 → 처형. 오답 → 래피가 "오답!" 선언, 처형은 나머지 전원(실제 플레이에서는 게임 오버 + 체크포인트).
* 처형 연출은 어트랙션 변주(잔혹 묘사 없음).
