### A-2 장치 (마법이 아닌 것)
1. **외부 걸쇠** : 안에서 열 수 없게 하는 기구.
2. **환기 설비 부재** : 505호에는 환기구·스프링클러·연기 감지기가 없음.
3. **쪽지(필체 모방)** : 종이 + 펜.
4. **알리바이 구조** : 정비동 동행(린).
5. **마법의 역할** : "방의 존재"뿐. 살인 수단은 **걸쇠 + 환기 부재**.
