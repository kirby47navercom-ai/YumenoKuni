## A. 일상 파트 (110분)

### 2-D-01 아침 방송 · 구역 개방 (6분)
```
[래피(방송)] "여름이에요, 여름! 워터파크와 퍼레이드 스트리트 개장♪ 수영복은 기념품샵에서 대여해 가세요!"
[래피(방송)] "…참고로 1장에서 좀 시끄러운 일이 있었죠. 그래도 오늘은 즐겁게! 즐겁게 하자구요!" {억지로 밝게}
[소라] "…그 말 믿고 싶지는 않지만, 우리가 놀지 않으면 안 되는 이유도 없잖아." {표정이 잠깐 가라앉음}

```
[하루카] "미오~! 수영복 사진 찍자~! 여기 서 봐~!" {활짝}

[소라] "수영 대결! 나랑 사츠키랑 린이랑 레이! 이긴 사람이 팥빙수 먼저!" {활기}
[레이] "…저는 구경만 하겠습니다." {무표정}

* **웨이브 풀 기계실** : 린이 열고 들어감(복제 키). 파도 타이머 패널(수동/자동) 확인. **E2-16 파도 타이머 패널**(20:00 / 20:30 / 21:00 자동, 수동 정지 버튼 존재).
