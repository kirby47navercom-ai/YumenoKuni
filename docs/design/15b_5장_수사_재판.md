> 시간 : 발견 5 + 수사 80 + 재판 165 + 처형 10 + 에필 20 = 280분.

## A. 사건 진상 (제작자용)

### A-1 타임라인
| 시각 | 사건 |
|---|---|
| 19:50 | 사츠키가 수장고에서 석궁 1정을 꺼냄(사전 점검 완료). 출입 로그 기록(열쇠 #K-01). 열쇠는 코토의 가방에서 가져감(코토가 가방을 대연회장에 두고 자리를 비운 사이). |
| 20:05 | 사츠키가 서고에서 책장 통로 끝에 석궁을 고정. 시위·방아쇠에 가는 끈을 걸고, 끈을 **탁상시계 알람 레버**에 연결. 매듭은 사냥꾼식. |
| 20:10 | 서고 탁상시계를 **40분 느리게** 조정(코토가 알려 준 방법). 알람을 시계판 기준 **20:20**에 설정(실제 21:00에 울림). |
| 20:25 | 나나가 서고에 도착. 장부에 시계판 기준 "19:45 입실 / 목적 : 약속(21시)"으로 기재. 사츠키는 "21시에 올게. 여기서 기다려."라고 말하고 퇴실. |
| 20:30 | 코토가 대연회장 입장(기록 20:30). |
| 20:35 | 아이·카에데 입장. |
| 20:38 | 린 입장. |
| 20:40 | 미오 입장. 상영회 시작. |
| 20:50 | 사츠키가 대연회장 입장(기록 20:50). 알리바이 확보. |
| 21:00 | 시계탑 종(정상). 서고 탁상시계(시계판 20:20)의 알람이 울리며 레버가 올라가 끈이 당겨짐 → 석궁 발사 → 나나 사망. |
| 21:20 | 상영회 종료. |
| 22:10 | 카에데가 서고에 들러 시체 발견. 서고 시계는 21:30(실제 22:10). |

### A-2 장치 (마법이 아닌 것)
1. **석궁 시한 발사 장치**(책장 고정 + 끈 + 시계 알람 레버).
2. **시계 40분 지연 + 알람 20:20** → 실제 21:00 발사.
3. **서고 입퇴실 장부**(시계판 시각 기재) → 시계가 틀렸다는 증거.
4. **입장 기록기** : 사츠키 20:50 입장(다른 사람은 20:30~20:40).
5. **수장고 출입 로그** : 19:50 열림, 열쇠 #K-01.
6. **마법의 역할** : 그림자·망각은 사용되지 않음. 코토의 맹세와 거짓 정보가 동기를 만들었을 뿐.

### A-3 혼란 장치
| # | 종류 | 내용 | 반증 |
|---|---|---|---|
| 1 | 가짜 시간 기준 | 서고 시계 21:30 → "발견 시각 21:30" | 카에데 손목시계 22:10 / 시계탑 22:00 종 → 40분 느림 |
| 2 | 가짜 시간 기준 | 21:00 전원이 연회장 → "불가능 범죄" | 시한 장치 |
| 3 | 가짜 용의자 | 코토(수장고 열쇠 + 시계 지식) | 코토는 20:30부터 연회장 / 로그와 열쇠 보관 상태 |
| 4 | 가짜 용의자 | 사츠키의 그림자(100%) | Q1 : 5m / 서고~연회장 200m 이상 |
| 5 | 가짜 용의자 | 린의 피킹(수장고) | 자물쇠 파손 없음 → 열쇠 사용 |
| 6 | 오답 가설 | 자살 | 석궁 고정 + 방아쇠 끈 |
| 7 | 오답 가설 | 나나가 스스로 설치 | 나나는 장치 지식 없음 + 약속(21시)은 타인의 부름 |
| 8 | 증언 착각 | 아이 : "나나는 20:20에 주방에서 차를 마셨다" | 주방 시각은 정확, 서고 시계가 틀림 |
