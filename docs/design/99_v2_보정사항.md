## 10. v3.1 개정 (마법 비공개 · 프리타임 구조 · 프롤로그 재작성)

### 10-1 확정 규칙
| # | 항목 | 내용 |
|---|---|---|
| 1 | 마법 비공개 | 시작 시점에는 **본인 마법만** 안다. 수첩 마법 페이지는 본인 칸만 표시. 다른 사람의 마법은 본인이 밝힘 / 일상 중 효과 목격 / 수사 증언 / 재판 질의로만 해금. |
| 2 | 프롤로그 | **재판·마법 공개·연습 사건 없음**. 자기소개 → 래피 규칙 → 탐색 → 저녁 → 밤. |
| 3 | 프리타임 구조 | 스토리 → 프리타임(2슬롯) → 스토리 … 한 장에 **3세션**(1·2장), 후반으로 갈수록 감소(3·4장 2세션, 5장 1세션, 6장 0). 총 22슬롯. |
| 4 | 래피 질의 | "~한 효과를 내는 마법이 있나요? 누구의 것인가요?" 형태로 **마법 이름·소유자·규칙**을 확인. 누가 썼는지(사실)는 불가. |

### 10-2 3~6장 재작성 (완료)
3~6장도 마법 비공개 규칙·프리타임 구조(3장 2세션, 4장 2세션, 5장 1세션, 6장 0)로 전부 재작성했다. 3장은 빙의(소라 시인)·최면(켄 조건 공개)을 일상 효과로, 4장은 "기억 vs 기록" 규칙(Q5)을, 5장은 시한 발사 장치와 코토의 말실수를, 6장은 맹세·기록 100%를 질의로 확정한다.
