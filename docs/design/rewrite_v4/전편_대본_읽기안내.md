# 전편 대본 읽기 안내

**2026-10-29 동일 회차 정정:** [재판 입력·회차 재편집](재판_입력_회차_재편집_검수.md)을 최신 배치로 우선해요.모든 장에12/3을 할당하던 표를 폐기하고 중복 입력8곳은 실제 대면으로,다른 반론2곳은 새 논스톱으로 고쳤어요.현재 횟수는 원고에서 센 결과이며 품질 합격 기준이 아니에요.현재 스크럼/무장/클라이맥스/투표는 각1회로 쓰여 있지만 횟수 상한은 없어요.별개의 논점과 결과가 있으면 여러 번 배치해요.게임 미적용이에요.

**2026-10-29 독자 경로 재검수:** [재검수 결과](전편_독자경로_재검수_2026-10-29.md)는 이전 검수의 품질·분량 이력으로 남겨요.반복되는 반박 문형과1장 중복 재구성을 발견해 실제 고쳤어요.핵심 떡밥/인물 간 논쟁의 연결은 확인했지만,일상2~3시간/재판5시간의 체험 길이는 합격으로 인증하지 않아요.기존「전편 편집·검수본」은 원고의 작성·지정 연결 정리 범위이며 시간·문학 품질의 일괄 합격이 아니에요.

> 제작자용. 실제 대본과 분기 내용에는 전체 스포일러가 있어요. 게임 적용용 데이터가 아닌 집필 원고예요.
> 2026-10-29 전편 편집·검수본. 프롤로그~6장 두 결말과 지정한 자유시간 경로의 독서 순서예요.

프롤로그부터 아래 순서로 읽어요. 파일명의 문자순 정렬은 `13a10`을 `13a2`보다 앞에 놓으므로 장면 순서로 읽어야 해요. 본문에 **필수 연결**이 나오면 해당 파일의 지정 구간을 읽고 원래 위치로 돌아와요. 연결 파일을 처음부터 끝까지 미리 읽으면 뒤의 결과 구간이나 다른 선택이 앞당겨질 수 있어요.

선택에서는 실제 고른 한 갈래만 읽고 합류로 넘어가요. 재판의 정답/오답 구간은 정답 경로에서 전부 들은 대사가 아니에요. 오답은 실패했을 때만 읽고 지정된 논의·반박으로 돌아가 다시 선택해요. 자유시간도 한 시간창에 한 사람만 만나며, 기본 첫 만남과 같은 인물의 늦은 첫 만남을 함께 읽지 않아요. 모든 분기의 합계는 한 번의 플레이 분량이나 시간표가 아니에요.
