# 재판 입력·회차 재편집 검수 — 2026-10-29

주인님의 「왜 다 수가 같냐」 지적 뒤 실제 원고를 다시 고쳤어요.직전의 모든 장 논스톱12/반복 형식3은 장별 사건을 먼저 완성해서 나온 수가 아니라 같은 배분표를 적용한 결과였어요.그 수와 연결 검사 통과만으로 자연스러운 집필이라고 판단한 것은 잘못이에요.

이번 교정은 필요 없는 입력8개를 실제 대면으로 바꾸고,다른 반론이 생기는2곳을 논스톱으로 쓴 작업이에요.인물의 반문이나 비꼼을 거짓 믿음으로 취급했던 표적,자기 귀로 방금 들은 사실까지 무시하던 패닉4곳도 고쳤어요.분량을 늘리려고 같은 결론에 게임 이름만 바꾸어 덧붙이지 않아요.숫자 차이 자체도 품질의 합격 근거가 아니에요.

## 횟수 상한에 대한 최신 정정

주인님은 「한 번씩만 하라고 했던 건 따로 이유가 있다면 여러 번 해도 상관없다」고 정정했어요.스크럼·이론 무장·클라이맥스 추리·범인 투표에도 장당1회 상한을 두지 않아요.이전의 각1회 표와 검사 기록은 그때 작성된 배치에 대한 기록이며 이후 집필을 제한하지 않아요.

다시 사용할 때는 앞선 회차의 결론,새로 생긴 의문이나 반론,이번 회차에서 달라질 판단을 대본에서 확인해요.같은 질문을 같은 증거로 다시 풀게 하거나,시간·횟수를 채우기 위한 재사용은 별도 이유가 아니에요.상황에 따라 같은 형식을 여러 번 쓰거나 여러 장의 수가 같아지는 것도 허용해요.

- 스크럼:새 증언·반증 때문에 쟁점이나 편 구성이 달라졌다면 두 번째 공방을 맡길 수 있어요.앞선 팀 배치를 그대로 반복하거나 이미 끝낸 합을 새 회차로 세지 않아요.
- 이론 무장:다른 인물이 별개의 방어를 하거나 같은 인물의 방어 논리가 실제로 바뀌었다면 다시 사용할 수 있어요.한 무장 안의 파동과 마지막 일격은 여러 회차가 아니에요.
- 클라이맥스:중간의 한 사건 재구성과 이후 새 사실을 반영한 별도 범위의 재구성이 필요하다면 나눌 수 있어요.앞의 빈칸이 무엇이었고 다음 재구성이 무엇을 바꾸는지 남겨요.
- 투표:재실시할 실제 이유가 있다면 앞선 투표의 결과와 다음 투표가 열리는 조건·후과를 써요.중간 인물 지목·범인 지목을 정식 투표로 세지 않고,판정·처벌 조건은 대본의 교칙과 맞춰요.

이번 정정은 배치·검수 기준의 변경이에요.새 스크럼·무장·만화·투표 대본을 이미 추가했다고 세지 않아요.현재 아래 표의 각1회는 현황이며 상한이 아니에요.

## 논스톱을 추가한 두 이유

- [T3-NS-A11 시연하지 않은 사람의 승리](183_3장_재판_반복논의와_지목_연속대본.md#t3-ns-a11-시연하지-않은-사람의-승리--ns): 재시연 거절을 이용해 상대가 「자신의 신원 확인이 끝났다」고 판정을 가져가려는 반론이에요.현재 신원이나 첫 살해자를 다시 고르는 문제가 아니에요.시연 자체가 없었다는 사실로 그 결론만 막고,사람을 시험에 세우는 길에서 비공개 지식의 검증으로 옮겨 가요.소라의 신원을 이 입력으로 먼저 확정하지 않아요.
- [T5-NS-A11 골랐던 손을 지우는 말](185_5장_재판_반복논의와_지목_연속대본.md#t5-ns-a11-골랐던-손을-지우는-말--ns): 스크럼에서 음용과 독 인지를 구별한 뒤,아카리가 자기 선택 진술을 「시키는 잔을 옮겼을 뿐」으로 바꾸는 국소 모순을 물어요.코토가 죽고 싶었는지를 또 맞히지 않아요.나나의 미목격을 코토의 지정 증거로 쓰지 않으며,투입 인정과 살의는 기존 후속 대면까지 앞당기지 않아요.

2장과4장의 논스톱 수가 여전히 같은 이유는 이번 교정에서 해당 두 장의 남은 판정을 같은 수라는 이유만으로 지우거나 늘리지 않았기 때문이에요.주요 판단 축은2장의 닫힌 운반 경로·재생 음성과 신체의 위치·접촉 물증,4장의 사망 순간과 선행 가해·안팎 고정·피해자 인지로 달라요.장별 전체 문학 품질을 새로 전부 합격시켰다는 뜻은 아니에요.

## 억지 반박과 말투 교정

- 1장 PN-A03: 아카리의 비꼬는 질문을 거짓 약점으로 쏘던 배치를 없앴어요.실제로 자기 정상 보고를 방어하는 타이가의 주장에 왼쪽 표적을 두어요.고장 원인은 미정인 채로 남겨요.
- 4장 PN-A02: 쇼가 못 고른다고 한 직후 코토가 파일이 순서를 확정했다고 우기는 대사를 고쳤어요.코토는 선행 타격으로 논의를 좁히려 하고,사츠키는 눈에 보인 상처를 먼저 묻고,쇼는 사인과 발생 순서의 한계를 지켜요.
- 5장 PN-A02: 아카리가 함께 봤다고 방금 말했는데도 사츠키가 「아무도 같이 안 봤다」고 반복하지 않아요.대상이 겉상자 하나였는지 개별 여섯 용기였는지 묻게 하고 공동 확인 자료로 답해요.
- 6장 PN-A03: 설비 상태가 달랐다는 설명을 들은 뒤 사츠키가 정반대를 되풀이하지 않아요.현재 사용을 옛 안전 판정의 검증으로 옮기려는 주장부터 제시하고,정답 뒤 실제 상태 차이를 들어요.
- 5장 RS-A03: 쇼가 확인한 의료 사실을 잊어버린 사람처럼 보이지 않도록,못 쓴다는 말을 믿고 선택지를 줄였던 분노를 말하게 했어요.그 분노의 과도한 살해 판단은 미오가 시간 범위로 막아요.

## 입력·표현의 구별

새 논스톱은 한 바퀴 실제 발언/하나의 선택 언령/표적/구체적 오답/정답 귀환을 가져요.각 재판에 참인 말의 **동의** 입력도 있고,거짓 주장의 논파와 구별했어요.선택적 V포인트는 판정 표적의 특정 글자이며 보너스 정확도이지새 필수 회차나단서가 아니에요.소음 제거/집중/반복 청취는 정답 자동 선택이 아니에요.위증은 기존 A/B 후과를 그대로 보존하고 모든 회차에 억지로 추가하지 않아요.

인물 지목/범인 지목은16인 순환 선택,투표는 별도 표 확정·집계예요.영정 표시는 모든 지목에서 자동 선택 금지를 뜻하지 않아요.래피를 참가자16인 중 한 명으로 끼워 넣지 않아요.그림 지점은 문장 보기 번호 대신 실제 그림의 의미 영역이며최종 원화에 맞춘 픽셀 마스크 제작은 게임 통합 때 필요해요.대본 작성과 실제 마스크·히트 판정 구현을 혼동하지 않아요.

논스톱의 한 탄환 판정에 보조 근거 두 장을 동시에 발사하게 하지 않아요.개별 선택 언령을 지정하고 다른 관찰은 그 결론의 범위를 설명하는 근거로 남겼어요.참인 말은〔〕동의,틀린 단정은【】논파로 구분해요.거짓말 우회는 이전의 별도 분기와 비용/후과 계약을 따르고 이론 무장/스크럼/만화 속 소문제를 별도 게임으로 세지 않아요.
