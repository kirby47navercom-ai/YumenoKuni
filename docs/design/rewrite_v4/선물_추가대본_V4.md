# V4 선택 선물 추가 대본

> 신규 작성한 선택 장면이에요. 기존 자유시간 01~03 본문이나 과거 줄거리를 대체하지 않아요. 게임에 처음부터 있던 원고라고 주장하지 않아요.
> 독립된 다음 자유시간 창에서, 이미 한 번 실제로 만난 상대가 현재 본인으로 현장에 있고 먼저 대화에 응할 때만 열어요. 수사·재판·방송·발견·직접 작업·기존 자유시간 진행 중에는 열지 않아요. 본문에서 선물 없음을 명시한 끝 장면에 붙이지 않아요.
> 제안 → 소지 선물 보기 → 실제 품목 제시 → 상대 응답 → 최종 건네기 확정 순서예요. 수락 대사는 수량 검사를 다시 통과해 1개를 실제 건넨 뒤에만 재생해요. 거절·보류·취소·품절·부재는 소모하지 않아요. 영정이나 사라진 상대, 다른 정체가 사용하는 몸에 원래 사람 몫으로 전달하지 않아요.
> 허용 품목은 현재 새 선물 카탈로그의 정식 인벤토리 ID만이에요. 증거·차용품·공용품·이전 만남의 서사 소품을 목록에 섞지 않아요. 선택한 선물 그림/이름은 UI가 정확히 보여 주며 아래의 ‘이거’를 다른 물건으로 바꾸어 읽지 않아요.
> 수락 보상 +3은 기존 자체 시스템의 선호 선물 수치에 근거한 게임 수치예요. 화해·신뢰·용서·능력 공개·사건 증거·필수 서사 해금을 뜻하지 않아요. 거절/보류에는 관계 감점을 붙이지 않아요. 같은 사람에게 한 자유시간 창에서 수락 1회이며 반복 클릭·저장복귀는 중복 지급하지 않아요.
> 각 제안 뒤 공통 실제 선택: 「가진 선물을 보여 준다」 / 「오늘은 주지 않는다」. 품목을 본 뒤: 「이걸 건네도 될까」 / 「다시 고른다」 / 「그만둔다」. 수락 가능 응답 뒤 마지막 「건넨다」 / 「보류한다」를 확인해요. 정답 선물을 알려 주는 색·별·호감 힌트는 넣지 않아요.
