## 선택·정보·소지품

4장4-87a는사적부탁을공개당한사람이거듭정확한의도를해설하는대신,말을끊고상대얼굴을보게하고이미읽은자료부터다시읽게하는현재대면으로재집필했다.원래물리자료/친숙함/발언의첫공개/실제사과와남은불신을지킨다.1장I13a의15인실제이동과6장T39a의현재의식자기보존요구도부모에직접썼다.시간을정해강제로기다리게하거나새게임규칙을추가한분량이아니다.

## 최종 사후 대면과 선택 교정

1장1-C02 B의 객실 교환은 타이가가 직접 제안하고 카에데가 조건을 정하는 실제 대면으로 썼다.열쇠·표지는 기존 공통 구간에서 한 번만 바꾸고,이사 장면도 같은 상대를 따른다.I-C01 A는 미오/아카리가 확인 범위를 제한해 방 안에 들어갔다 빈손으로 나오는 경로,B는 들어가지 않고 보류를 일반 메모에 적는 경로다.둘 다 공용 자료로 필수 추리에 닿으며 개인 문서의 새 내용을 정답으로 주지 않는다.

2장R03/R05에는 서로 다른 공포·짜증과 운반한 사람의 원망을 썼다.소라의 틀린 표를 여기서 공개하지 않고,R04a의 거짓 부인과3장 본인 공개를 유지했다.3장R03/R07/R08은 얼굴과 이름,돌려받은 도구,살아 있을 때 싫었던 장난을 각 다른 대면으로 썼다.켄의 새 부탁을 뒤늦게 만들지 않고 R01에서 나나가 실제 말한 붕대 약속을 이었다.레이가 과거에 하지 않은 제지를 한 것처럼 회상하던 문장도 원래3-79~80의 침묵/작업 후 칭찬에 맞췄다.

4장R14는 부속을 다시 상자에 넣고 두 사람이 식사 뒤 이동할 준비를 하는 실제 행동이다.바로 문을 확인하고 돌아온 새 작업을 만들지 않아 R17~18의 같은 식탁/5-04의 작업 전 대면과 이어진다.R15의 사용 상태 공유는 새 맹세·일괄 합의가 아니다.5장R03~05/R07은 핀을 줍는 손,잘못된 표를 향한 분노,같은 승강기와 다른 거리,상처와 살해 책임의 구별을 실제 문답으로 썼다.핀은 사츠키 손→R13주머니 그대로이고,천을 먼저 고른 사람은5-135의 아카리다.5-C04 A의 미목격을 직접 본 기억으로 고치지 않았다.

지정한 새 구간을 저장 뒤 다시 읽고 기존 진입·귀환과 대조했다.기존 전편 전문 독해와 신규179/180 전문,이번 수정 구간의 재독을 구분해 누적 검수 기록에 남겼다.현재 지원 대본의 빈 필수 자리·끊긴 연결을 남겨 놓고 다음 집필을 예약한 상태가 아니다.미지원 날짜의 새 순열,게임 적용과 실제 목표시간 검증은 이 편집본의 검수 범위로 확대하지 않는다.
