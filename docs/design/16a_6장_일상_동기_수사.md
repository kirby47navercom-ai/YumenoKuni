# 6장 「드림 코어」 일상 · 동기 · 수사 전체 대사 (⚠ 최종 스포일러)

> 흑막 하나이 코토 / 엔딩 A(체포) · 엔딩 B(어두운 분기). 이 문서는 **재판 직전까지**(일상 · 동기 · 수사). 재판·엔딩은 `16b_6장_재판_엔딩.md`.
> 진행 : **스토리 → 동기 → 수사 → 재판**. **프리타임 없음**(대신 「대피소 마지막 대화」 고정 이벤트).
> 시간 : 일상 40 + 동기 15 + 수사 60 = 115분. (재판 180 + 엔딩 40 + 폭주 5 = 225분은 16b)
> 일정 : 13일차(코어 진입) / 14일차(재판).
> 개방 구역 : 드림 코어(지하) — 대피소 · 점검 통로 B · 코어 홀 · 제어실.
> 생존자 : 미오 · 코토 · 린 · 아이 · 카에데(5명).
> 분위기 : 최소한의 BGM, 래피 본래 목소리(장난기 0%).
> 마법(비공개 원칙) : 이 장의 핵심은 **맹세(코토)** 와 **기록 100%(미오)**. 코토의 맹세 이름·규칙은 재판 질의로 확정. 서약선은 1~5장에서 흩어진 **효과 목격**(레이 커프스, 아카리 손목, 나나 리본, 사츠키 토시, 침묵 패턴)을 모아 추리한다.
> 이 장에는 **새 살인 사건이 없다.** 5년 전 하루카를 죽인 사람을 찾는 재판이다.
> 형식 : `[화자] "대사" {표정}` / `(지문)` / `▶선택지` / `[UI]` / `[복선 회수]`.

## 6-S1 코어 진입 (13일차 / 10분)
**장소 : 드림 코어 입구 → 지하 엘리베이터**

```
(5장 재판 직후. 정오 시계탑 종이 울리고 5년 전 영상이 흩어진 뒤. 남은 5명이 엘리베이터 앞에 서 있다.)
[래피(방송)] "…여기가 마지막이에요. 아래로 내려가면 코어가 있어요." {장난기 0%}
[래피(방송)] "…래피의 목소리, 이상하죠? 이게 원래 목소리 같아요."
[린] "…래피, 오늘은 말투가 전혀 다르지롱." {낮은 목소리}
[코토] "점검 통로 B를 지나야 한다고 들었어요. 이쪽이에요." {온화}
[미오(독백)] "(…B? 수첩 지도에는 점검 통로가 A밖에 없다. 코토는 어떻게 B를 …)" ← **[복선 회수 : 5장 에필로그]**
(엘리베이터가 내려간다. 5명이 거울 같은 벽 앞에 선다.)
[UI] 엘리베이터 거울에 비친 미오의 키링. 귀의 실밥이 래피 귀와 겹쳐 보이는 연출.
[아이] "…내려가는 시간이 길어요." {작게}
[카에데] "…시간 낭비 없이 도착해 줘." {담백, 손이 떨림}
(미오가 문턱을 넘는 순간, 프롤로그 정문 장면과 같은 카메라 워크가 반복된다.)
```
* **[연출 회수]** 프롤로그의 "문턱을 넘는 순간" 카메라 워크 반복. 오르골 소리 한 음 어긋남.
* **E6-05 선행** : 수첩 지도에는 점검 통로 A만 표기. 코토의 발언만 B.

## 6-S2 대피소 마지막 대화 (15분 / 고정 이벤트)
**장소 : 대피소**

```
(대피소. 오래된 침상 열과 낡은 담요. 입구 쪽에 입소 단말기. 5명이 둥글게 앉는다.)
[아이] "…마지막 식사예요. …모두 먹어 줘요." {작게}
[카에데] "시간 낭비 없이 먹자. …근데 이상하게 천천히 먹고 싶네." {담백, 조금 떨림}
[린] "열쇠를 따는 건 내가 하지롱. 그런데 마음의 자물쇠는 못 따겠다…" {농담이지만 웃음 없음}
[미오] "…나는 여기까지 와서도 아무것도 모르는 것 같아." {고개를 숙임}
```
**▶ 분기 대사 (인연 Lv에 따라 추가)**
* **린 Lv3 이상** : [린] "…미오. 나, 아빠 열쇠고리를 아직 못 놓겠다지롱." {작게} / [미오] "…놓지 않아도 돼." / [린] "…그래?" {웃음}
* **아이 Lv3 이상** : [아이] "…하나, 둘, 셋…. 다 기억해요. 열여섯 명 이름." {작게} / [미오] "…나도 적었어." / [아이] "…둘이면 안 사라져요." 
* **카에데 Lv3 이상** : [카에데] "…미오. …나, 외로웠어. 그래도 이 마지막은 …혼자가 아니라서 다행이야." {시선 회피}
```
(코토가 조용히 일어난다. 소매를 정돈하고 미오 앞에 앉는다.)
[코토] "…미오 씨. 잠깐 얘기해도 될까요?" {온화}
[미오] "…응."
```
### 코토와 미오의 약속 (강제 이벤트 / 서약 형성 분기)
```
[코토] "내일 재판에서, 서로의 말을 먼저 믿고 의심은 나중에 하기로 약속해 줄래요?" {진지}
[코토] "…마지막 재판이니까요. 서로를 의심하기 시작하면 …끝이 날 것 같아서요." {낮게}
[미오] "…먼저 믿고, 의심은 나중에." {잠시 생각}
▶ 선택
  - A. "…약속할게." → 
  - B. "…약속은 못 해." →
```
```
(A 선택)
[미오] "…약속할게." {작게}
[코토] "…고마워요." {미소}
(미오의 오른 손목에 가는 검은 선이 한 줄 생긴다. 소매에 가려져 화면에는 짧은 번쩍임만.)
[UI] 손목에서 이상한 감각이 들었어요. (서약선 형성 / 6장 재판의 필수 루트)
(B 선택)
[코토] "…알겠어요." {잠깐 침묵}
[코토] "…그럼 제가 대신 믿을게요. 미오 씨 말을 먼저요." {미소}
[UI] 코토가 다른 방식으로 '먼저 믿기'를 청했어요. (서약선은 생기지 않지만 6장 재판에서 코토가 **동의 없는 일방 구속**을 시도한다 — 거부 의사가 있어 실패하는 연출이 추가)
```
* **[연출 분기 처리]** 두 선택 모두 재판에서 "맹세 발동" 장면은 발생한다. A는 성공(미오가 쓰러짐), B는 **시도→실패→코토가 놀람**(더 큰 반전)을 거쳐, 이후 미오가 의도적으로 "쓰러지는" 연기를 하거나(플레이어 선택), 노트 증거를 쓰는 대체 루트로 이어진다. (16b D-6/D-7 참조)
* **복선** : 코토의 말투가 완전히 존댓말로 고정. 평소의 "중간 말투"가 사라짐.

[래피] "…누가 날 죽였는지 알려 주세요." {목소리가 가늘게}

[래피] "…재판을 열어 주세요. 마지막 재판이에요. 지명이 틀리면…… 래피는 규칙대로 처리해야 해요."

```

```
