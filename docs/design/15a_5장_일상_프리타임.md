# 5장 「드림 캐슬」 일상 · 프리타임 · 동기 전체 대사 (⚠ 전체 스포일러)

> 피해자 유키무라 나나 / 범인 이노우에 사츠키. 이 문서는 **사건 직전까지**. 사건·수사·재판은 `15b_5장_수사_재판.md`.
> 진행 : **스토리 → 동기 → 스토리 → 프리타임(2) → 스토리 → 사건**. (프리타임 **1세션 / 2슬롯** — 후반 압축)
> 시간 : 일상 120 + 프리타임 14 + 동기 15 + 저녁 스토리 10 = 약 160분(에필 20분은 15b).
> 일정 : 11일차(개방 · 동기) / 12일차(일상 · 사건 21:00 · 발견 22:10).
> 개방 구역 : 드림 캐슬(대연회장 · 서고 · 시계탑 · 갑옷의 복도 · 왕좌의 방 · 수장고 · 지하 체험관 · 플로트 격납고).
> 생존자 7명 : 미오 · 코토 · 린 · 아이 · 카에데 · 나나 · 사츠키.
> 분위기 : 흑백에 가까운 색조, 래피 장난기 10%. 기억 복원 직후의 불안과 분노.
> 규칙 카드 추가 : **R-12 서고 규칙(입퇴실 장부에 서고 탁상시계의 시각을 적을 것)** / **R-13 상영회 입장은 입장 기록기에 카드를 찍을 것** / **R-14 시계탑 종은 정시에 울린다.**
> 마법(비공개 원칙) : 이 장의 마법은 **그림자(사츠키, 3장에서 M3-03 목격) · 망각(나나, 동기에서 래피가 공개)**. 사츠키의 그림자가 거울에 비치지 않는다는 사실, 나나의 소매 습관이 이 장의 맥락이 된다.
> 형식 : `[화자] "대사" {표정}` / `(지문)` / `▶선택지` / `★ +2` / `✕ −1` / `☆ 코인` / `[UI]` / `[복선]`.

# B. 프리타임 이벤트 (③ 중심 / 슬롯 2개)

## B-0 공통
```
[UI] 이벤트 ③ : 인연 Lv5 이상일 때 해금. 아직 Lv5가 아니라면 이벤트 ② 또는 ①이 대신 열려요.
```

### B-1 나나 ③ 「서고 독서석」 (서고)
```
(서고. 독서석. 나나가 책을 펴 놓고 앉아 있지만 읽지 않는다.)
[나나] "…미오 씨. 와 주셨군요." {작게}
[미오] "…책은?"
[나나] "…글자가 눈에 안 들어와요." {소매를 쥠}
```
▶ 선택지
  - ★ "…말하고 싶은 게 있으면 말해." →
```
[나나] "…말하고 싶은 게 있어요. …그런데 말이 안 나와요. 미안해요." {눈물}
[나나] "…5년 전 …그날 …제가 …" {손목을 움켜쥠}
(손목에서 리본 아래의 검은 선이 한 순간 번쩍인다. 나나가 숨을 몰아쉰다.)
[나나] "…!! …아, 안 돼요. 말할 수 없어요." {떨림}
[미오] "…괜찮아. 말 안 해도 돼." {손을 잡음}
[나나] "…미오 씨는 …왜 이렇게 친절해요?" {울음}
[미오] "…나나가 나를 걱정해 줬잖아."
```
  - ✕ "…누가 시킨 거야?" → [나나] "…!" {숨을 삼킴} / BP −1
```
[나나] "…미오 씨. 만약 제가 …무슨 일이 생기면 …이 쪽지를 …" {쪽지를 건넴}
[미오] "…쪽지?"
[나나] "…아직 열지 마세요. …필요할 때 열어 주세요." {작게}
```
* 획득 : **나나의 쪽지(미개봉)**. 유품 이벤트에서 개봉. 내용 : "미오 씨의 노트에 적어 주세요. 나는 괜찮았다고."
* ☆4 / 대표 대사 「말하고 싶은데 말이 안 나와요」. 선물 : 허브티 세트 [호] / 의학 소책자 [호].

### B-2 사츠키 ③ 「새벽 산책」 (산책로)
```
(새벽 산책로. 이른 시간의 안개. 사츠키가 걸음을 멈추고 서 있다.)
[사츠키] "…왔네." {짧게}
[미오] "…일찍 일어났네."
[사츠키] "…잠이 안 와." {낮게}
```
▶ 선택지
  - ★ "…같이 걷자." →
```
[사츠키] "…아카리가 있었어. …아니다. 아카리가 있었다고 해야지." {작게}
[사츠키] "…누가 알려줬어. 아카리가 죽은 이유를. …그건 …" {손목을 움켜쥠}
(말이 멈춘다. 사츠키가 호흡을 가다듬는다.)
[사츠키] "…이상하다. 말하려고 하면 …숨이 막혀." {낮게}
[미오] "…누가 알려 줬는지 …말하고 싶지 않은 거야?"
[사츠키] "…말하고 싶어도 못 해. …이유는 …모르겠어." {시선}
```
  - ✕ "…누가 알려 줬어?" → [사츠키] "…!" {숨이 막힘} / BP −1
```
[사츠키] "…미오. 만약 내가 …이상한 일을 하면 …말려 줘." {낮게}
[미오] "…이상한 일?"
[사츠키] "…아냐. 그냥 …해 본 말이야." {고개를 돌림}
```
* **[복선]** 서약선의 침묵. ☆4 / 대표 대사 「말하려고 하면 숨이 막혀」.
* 획득 : **사츠키의 매듭 한 줄**(풀면 쪽지가 나옴 — 유품 이벤트).
* 선물 : 말 모양 브로치 [호] / 고양이 간식 [호] / 매듭 끈 세트 [호].

### B-3 아이 ③ 「마지막 식사」 (대연회장 주방)
```
(대연회장 주방. 아이가 한 접시만 남겨 두고 앉아 있다.)
[아이] "…미오 씨. 마침 잘 오셨어요." {작게}
[미오] "…한 접시만?"
[아이] "…사람이 줄어서 …요리가 남아요. …그래도 …요리는 …사람이 먹어야 하니까요." {작게}
```
▶ 선택지
  - ★ "…같이 먹자." →
```
[아이] "…미오 씨. …음식은 사람을 살려요. 미오 씨도 살아 주세요." {눈물}
[아이] "…저는 …모든 걸 기억하는데 …그래서 …사라진 사람들의 …이름도 다 기억해요." {작게}
[아이] "…타이가 씨, 쇼 씨, 유우 씨, 아카리 씨, 리쿠 씨, 소라 씨, 켄 씨, 레이 씨, 하루카 씨…" {하나씩}
[미오] "…아이." {손을 잡음}
[아이] "…제가 기억하고 있을게요. …미오 씨가 노트에 적고, 제가 …기억하면 …사라지지 않아요." {미소}
```
  - "…나중에 먹을게." → [아이] "…네. …남겨 둘게요." {작게}
* ☆4 / 대표 대사 「제가 기억하고 있을게요」. 선물 : 요리 책 [호] / 허브티 세트 [호].
