# 6장 「드림 코어」 시나리오 (⚠ 전체 스포일러)

> 최종 장. 흑막 하나이 코토 / 엔딩 A(체포) · 엔딩 B(어두운 분기)
> 총 340분. 일상 40 + 동기 15 + 수사 60 + 재판 180 + 엔딩 40 + 처형/폭주 5. 자유시간 없음(대신 **마지막 대화 이벤트** 고정).
> 개방 구역 : 드림 코어(대피소, 점검 통로 B, 코어 홀, 제어실).
> 생존자 : 미오·코토·린·아이·카에데(5명).
> 분위기 : 최소한의 BGM, 래피 본래 목소리.
> 이 장은 **새 사건이 없다.** 5년 전 사건의 진범을 찾는 재판이다.

## A. 일상 파트 (40분)

### 6-D-01 코어 진입 (10분 / 드림 코어 입구)
```
[래피(방송)] "…여기가 마지막이에요. 아래로 내려가면 코어가 있어요."
[래피(방송)] "…래피의 목소리, 이상하죠? 이게 원래 목소리 같아요." {장난기 0%}
[린] "…래피, 오늘은 말투가 전혀 다르지롱." {낮은 목소리}
[코토] "점검 통로 B를 지나야 한다고 들었어요. 이쪽이에요." {온화}
[미오(독백)] "(…B? 수첩 지도에는 점검 통로가 A밖에 없다. 코토는 어떻게 B를 …)"
```
* **E6-05 선행 단서** : 수첩 지도에 점검 통로 B는 표기되어 있지 않음. 코토의 발언은 5장 에필로그에서 이미 한 번 등장(복선).
* 드림 코어 입구는 지하 엘리베이터. 내려가는 동안 미오가 키링을 만지작거림. 엘리베이터 거울에 비친 키링의 귀 실밥이 래피 귀와 겹쳐 보이는 연출.

### 6-D-02 대피소 마지막 대화 (15분 / 대피소)
* 5명이 둥글게 앉은 장면. **인연 Lv에 따라 대사 분기**(Lv3 이상이면 추가 대사).
```
[아이] "…마지막 식사예요. …모두 먹어 줘요." {작게}
[카에데] "시간 낭비 없이 먹자. …근데 이상하게 천천히 먹고 싶네." {담백, 조금 떨림}
[린] "열쇠를 따는 건 내가 하지롱. 그런데 마음의 자물쇠는 못 따겠다…" {농담이지만 웃음 없음}
[미오] "…나는 여기까지 와서도 아무것도 모르는 것 같아." {고개를 숙임}
[코토] "…미오 씨. 잠깐 얘기해도 될까요?" {온화}
```
* **코토와 미오의 대화 (핵심 복선 / 강제 이벤트)** :
```
[코토] "내일 재판에서, 서로의 말을 먼저 믿고 의심은 나중에 하기로 약속해 줄래요?" {진지}
[미오] "…먼저 믿고, 의심은 나중에." {잠시 생각}
(선택지 : 약속한다 / 거절한다)
```
* **선택지 처리 (엔딩 분기 아님 · 난이도 분기)** :
  - 약속한다 : 미오 손목에 가는 검은 선이 생김(서약선). 재판 중 맹세 발동 → 이벤트 진행(필수 루트).
  - 거절한다 : 코토가 "…알겠어요." 하며 다른 방법(연민 호소)으로 같은 이벤트를 유도. 서약선은 생기지 않지만 **코토의 대사 한 줄이 추가**("그럼 제가 대신 믿어요.").
* 미오의 서약선은 일상 장면에서는 소매에 가려져 보이지 않는다(플레이어 UI에서만 확인).
* **복선** : 코토의 말투가 완전히 존댓말로 고정. 평소의 "중간 말투"가 사라짐 → 플레이어가 어색함을 느끼도록.

### 6-D-03 점검 통로 B 둘러보기 (10분)
* 플레이어 자유 탐색 : 점검 통로 B(비공개 구역). 벽에 낙서와 그림. 5년 전 아이들이 그린 낙서.
```
[아이] "…이 낙서, 5년 전이에요. …여기 아이들이 많았어요."
[카에데] "'하루카와 미오'라고 쓰여 있어. …둘의 이름이."
[미오] "…내가 썼을까." {손으로 벽을 쓰다듬음}
```
* **E6-06 낙서** : "하루카 ♥ 미오 ♥ 코토" 라고 적힌 낙서. 하단에 작은 글씨 "점검 통로는 조심해서".

### 6-D-04 대피소 입소 단말 (5분)
* 대피소 입구의 단말기. 5년 전 입소 로그가 아직 남아 있음.
```
[아이] "…로그가 살아 있어요." {손이 빠르게 움직임}
[카에데] "…입소 명단. 14명은 19:55~20:05, 한 명은 20:50."
[미오] "…20:50?" {눈을 크게 뜸}
```
* **E6-02 대피소 입소 로그 획득**(자동 / 장면 진행).

## B. 동기 : 래피의 마지막 소원 (15분 / 코어 홀)

### 6-M-01 래피의 부탁
```
[래피(방송)] "…여러분, 여기까지 와 줘서 고마워요."
[래피(방송)] "래피는 이 공원의 주인이 아니에요. …이름도, 과거도 기억나지 않아요. 단지 한 가지 감정만 남았어요."
[래피(방송)] "…누가 날 죽였는지 알려 주세요." {목소리가 가늘게}
[린] "…죽였다고?" {숨을 삼킴}
[래피(방송)] "…재판을 열어 주세요. 마지막 재판이에요. 지명이 틀리면…… 래피는 규칙대로 처리해야 해요."
[래피(방송)] "…맞히면 …진짜 졸업이에요."
```
* 재판 직전 규칙 : **투표 대상은 코어 홀에 있는 모든 이(사망자 포함) + 5년 전 사고 당시 소환된 15명**. 
* 래피의 마지막 규칙 : 오답 시 전원 처형(나머지 전원).

## D. 재판 (180분)

### D-0 개정 · 래피의 정체 (10분)
```
[래피] "…재판을 시작할게요. 그 전에 하나만 말할게요."
[래피] "래피의 이름은 …하루카. 아사노 하루카."
[래피] "나는 이 인형 안에 있어요. 5년 전, 마지막 마법으로 마음 일부를 인형에 옮겼어요."
[미오] "…하루카?" {말이 안 나옴}
[래피] "미오가 만들어 준 인형이야. 귀를 꿰매 줬잖아. 붉은 실로." {부드러운 본래 목소리}
(미오의 키링과 래피 귀가 클로즈업으로 나란히)
[미오] "…내가…… 꿰맨 …" {울음}
[코토] "…하루카 씨." {조용히 눈을 감음}
```
* **[연출]** 래피의 목소리가 처음으로 '소녀'의 톤. 이전 장난기 음색이 전부 가면이었음을 암시.

### D-5 서약선 해체 (20분 / 특수 미니게임)
* 화면 : 미오의 손목, 코토의 완장.
* 규칙 : 노트 증거(N2/N4/N5)·유품 단서와 서약선의 위치를 대조하며 선을 하나씩 "지움". 5개 선이 대응.
* 중간 연출 :
```
[코토] "…이건 제 완장이에요. 풀 필요가 없어요." {미소}
[린] "풀어 보면 되지롱!" {손을 뻗음}
[아이] "…제가 도울게요." {반대 손으로 완장을 감쌈}
(두 사람이 코토의 완장을 푼다. 팔목에 여러 줄의 검은 서약선이 드러남)
[코토] "…" {미소 유지}
[카에데] "…줄이 여러 개야. 나나, 레이, 아카리, 사츠키…… 그리고 미오까지." {낮은 목소리}
```
* 이 미니게임을 클리어하면 서약선의 개수가 5개이며 코토가 5명과 맹세를 맺었음이 시각적으로 확인.

### D-6 코토의 최후 카드 : 맹세 발동 (10분)
```
[코토] "…맹세는 맹세야. 미오 씨, 먼저 믿기로 했죠? 제가 한 말을 먼저 믿어 주세요." {조용히}
[미오] "…코토. 네가…" {손목을 움켜쥠}
(미오의 손목에서 검은 선이 빛나고, 미오가 고통으로 쓰러짐)
[린] "미오!" {놀람}
[아이] "…맹세의 대가예요. 지금 의심하고 있으니까." {울음}
[코토] "…미안해요. 하지만 이대로 가면 제가 처형돼요." {목소리가 떨림}
```
* **플레이어 입력** : 미오가 쓰러진 상태에서 화면이 어두워지고 "미오의 노트"가 떠오름.

### D-7 미오의 100% 「기록」 해금 (15분)
```
[미오(독백)] "…내가 지금 하는 일은 노트에 적는 것뿐이야. 적은 건 지울 수 없으니까."
[미오(독백)] "…나는 코토를 의심한다. 하루카를 죽인 사람을 …용서할 수 없다."
(화면에 미오의 노트가 클로즈업 : 선택지 3개)
 A. "나는 코토를 믿는다." (취소) → 맹세 효과 유지, 재도전
 B. "나는 하루카를 죽인 사람을 증오한다." (살의 자각) → 100% 조건 충족, 다음 선택지
 C. "나는 지금 코토를 의심한다." (맹세와 모순) → 정답 / 100% 발동
```
* 정답 입력 시 :
```
[미오] "…나는 지금 코토를 의심해." {노트에 적는 손이 떨림}
(노트의 글자가 금빛으로 빛난다. 손목의 검은 선이 하나씩 끊어진다)
[래피] "…미오." {놀람}
[코토] "…!" {처음으로 미소가 사라짐}
```
* 100% 「기록」: 쓴 문장과 모순되는 마법 효과를 무효화. 맹세는 "의심하지 않기"와 모순되어 소멸.

### D-8 코어 폭주 · 래피(하루카)의 희생 (10분)
```
(미오의 살의가 코어에 감지되어 경고음이 울린다)
[래피] "…미오의 마음이 코어에 닿았어요. 폭주할 거예요." {소녀의 목소리}
[미오] "하루카…!" {손을 뻗음}
[래피] "미오. 나는 괜찮아. …이건 내가 할 일이야." {부드럽게}
(래피가 코어 앞에 서서 자신의 마음을 모두 쓴다. 인형이 빛으로 흩어짐)
[래피] "…고마워. 나를 꿰매 줘서. …안녕, 미오." {마지막}
(코어의 폭주가 가라앉는다. 래피의 장난기 음성이 완전히 사라짐. 인형이 바닥에 떨어짐)
```
* 미오의 키링이 흔들리는 연출.

### D-9 반론 쇼다운 : 코토의 최후 변론 (20분)
| # | 코토의 발언 | 대응 |
|---|---|---|

| 2 | "저는 하루카 씨와 점검 통로에 가지 않았어요!" | 칼질 → E6-01(일기) + E6-06(낙서) |

| 5 | "…" | (연출) 코토의 호흡이 끊긴다. |

### D-10 코토의 붕괴와 자백 (15분)
```
[코토] "…아빠가 …점검표를 위조했어요. …하루카 씨가 알아버렸어요."
[코토] "…하루카 씨는 '신고해야 한다'고 했어요. 저는 '아빠가 잡혀가요'라고 …"
[코토] "…난간에서 하루카 씨가 팔을 잡았어요. 놓으라고 하다가 …밀어 버렸어요." {울음}
[코토] "그 순간 코어가 …제 마음을 증폭했어요. …수백 명이…" {두 손으로 얼굴을 덮음}
[미오] "…그래서 5년 동안 사람들의 입을 막은 거야?"
[코토] "…하루카 씨를 죽인 걸 알면 …다들 저를 떠날 테니까요."

[린] "…코토. 나는 네가 좋았어. …반장이어서가 아니라 …네가." {눈물}
[코토] "…미안해요. 정말 …미안해요."
```
* **코토의 13세 공포** 서사 : 아버지를 지키려는 아이의 선택이 연쇄적 거짓을 낳음.

## E. 엔딩

### E-A 엔딩 A (기본) — 체포 (30분)
```
[코어(음성)] "…정답입니다. 범인은 하나이 코토."
(처형 장치가 작동하려 하지만 래피가 소멸한 후라 가동하지 않음)
[미오] "…처형은 안 돼. …나는 살의를 버릴래." {노트를 닫음}
[미오] "…법으로 심판받아. …살아서 갚아." {코토를 바라봄}
[코토] "…네." {미소와 눈물}
(코어 정지, 공원의 문이 열린다. 아침 햇살)
[린] "…문이 열렸지롱." {작게}
[아이] "…돌아갈 수 있어요." {눈물}
[카에데] "…시간이 많이 걸렸네." {미소}
```
* 후일담 : 사고의 진상 공표(점검표 위조 + 한 아이의 살의). 코토는 청소년 법원으로 이송. 5명의 생존자.
* 마지막 장면 : 미오가 새 노트에 쓴다.
```
[미오(독백)] "아사노 하루카는 거기에 있었다."
[미오(독백)] "…나는 적어 둘 거야. 잊지 않도록."
(키링이 햇빛에 반짝인다)
```
* 엔딩 크레딧 : 16명의 입상이 한 장씩 넘어가며 사망자는 흑백. 하루카(진짜)와 래피가 겹쳐 등장.

### E-B 엔딩 B (어두운 분기) — 처형
* 조건 : D-7에서 미오가 노트 A/B 선택 중 "살의를 인정하되 버리지 않음(B 이후 취소)"을 반복하거나, 엔딩 선택에서 "버리지 않는다"를 고름.
```
[미오] "…살의를 버릴 수 없어. …하루카를 죽인 사람을 …용서할 수 없어."
[코어(음성)] "…규칙을 집행합니다."
(래피의 소멸 후에도 코어가 최소한의 규칙을 집행)
[코토] "…미오 씨." {마지막 미소}
(코토가 빛으로 사라진다. 미오의 노트에 한 줄이 새겨진다)
[미오(독백)] "…나는 살의를 지우지 못했다."
```
* 후일담 : 문은 열리지만 미오의 눈빛은 무겁다. 린·아이·카에데가 미오를 부축. 엔딩 B 전용 아트 1장 + 짧은 크레딧.
