### A-2 장치 (마법이 아닌 것)
1. **샌드백 낙하 장치**(무대 장치실) : 레버 + 안전핀. 압좌 사인.
2. **음향실 자동 잠금 + 카드키 + 문받침** : 밀실 구조.
3. **비상 장비 보관함 개봉 기록** : 봉인 로그.
4. **좌석표·카드 반출 장부** : 알리바이 도구.
5. **영상 상영 시간표** : 21:00~22:30. 어두운 객석 + 큰 소리로 소음 가림.
