## A. 프롤로그·1장 생활

> 원고에 적힌 것만 옮겼다. Claude 제안은 [안], 주인님 판단은 [확인].
> 배경: 탐색은 3D(`explore_world.json`)다. 아래 배경 열은 대화(ADV) 장면에 2D 배경을 쓸 경우의 대응이다. 3D 화면을 그대로 배경으로 쓰면 "새로"는 필요 없다 [확인].
> 기존 CG 재사용은 파일 이름이 맞는 경우만 적었다. 그림 내용은 열어 보지 않았다 [확인].

### 공통 (여러 장면에 반복)

| 종류 | 내용 |
|---|---|
| 타이틀 카드 | `Prologue — 개장 전야` + `TIME UNKNOWN` (시작), `Prologue — 개장 전야` 끝, `Chapter 1 — 개장 / DAY 2`, DAY 3·DAY 4 [안: 원고엔 제목만, 카드 표기 없음] |
| 래피 방송 화면 | 천장 스피커 방송 연출(잡음·차임벨). P03 확성기, P09 10시, 1-01 아침, 1-05·1-11b·1-15d 폐장 방송(오르골), 1-13 아침, 1-19 시체 발견 방송 |
| 감시 카메라 | 검은 덮개 + 빨간 점 깜빡임 클로즈업 1종. P01·P02·P04·P08·P09·1-01·1-12·1-15d 반복 |
| 래피 등장/퇴장 | 분홍 조명 켜짐 → 등장, 조명 꺼짐 → 사라짐(P04·P06), 눈 깜빡하면 사라짐(1-08·1-13) |
| 미오 노트 인서트 | 노트 한 페이지 템플릿 1종 + 장면별 문구(아래 각 장면). 「지워지지 않음」 표현 포함 |
| 특수 스프라이트 — 타이가 | **P05 이후 타이가 전 스프라이트에 오른손 처치 버전 필요**: P05~P07 젖은 손수건 감은 손, P08 이후 붕대 손. 피 밴 붕대(1-03·1-06), 연고 배어 누런 붕대(1-15b) [확인: 기존 스프라이트 손 상태] |
| 래피 수첩 UI | 분홍 수첩. 이용 안내 9조(P06), 마법 페이지(P09) |
