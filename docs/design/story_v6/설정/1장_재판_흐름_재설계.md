## 0. V3에서 가져온 기준

### 0-1. 미니게임별 수치

| 항목 | V3 실측 | 이 재판에 적용 |
|---|---|---|
| 논스톱 발언 수 | 9~15구절(화자 턴 6~10), 구절 7~20자 | **11~15줄**, 한 줄 25자 안팎 |
| 약점 위치 | 뒤쪽 1/3, 결론 문장 근처 | 정답 약점은 **뒤쪽 1/3**. 앞쪽에는 미끼 약점 1~2개 |
| 미끼 약점 | 2~4개, 정답과 같은 모양 | 1~3개. 쏘면 그 화자의 전용 반박이 나온다 |
| 잡음(흰 글자) | 1장 초반 0줄, 후반 약 8줄, 2장 이후 10줄 이상 | ①~⑦ 0줄, ⑧~⑩ 3~4줄, ⑪~⑫ 6~8줄 |
| 패닉 | 스트림 3개 × 6~7구절, 약점은 한 스트림 뒤쪽 | 스트림 3개 × 6줄, 스트림마다 잡음 1~2줄 |
| 스크럼 | 5~6합, 합마다 상대 → 우리 → 키워드 | 6합. 첫 스크럼이므로 조작 독백 5줄 |
| 반론 쇼다운 | 1단계 5~7 → 주인공 반문 1줄 → 2단계 4~7(약점 뒤쪽) → 다시 시작 대사 | 1단계 6 → 반문 → 2단계 6 |
| 클라이맥스 추리 | 1장 11칸, 칸마다 질문과 조각(가짜 섞임), 완성 뒤 낭독, 마지막에 재능과 이름 호명 | **15칸, 4막** |
| 이론 무장 | 2장부터 등장. 결정적 증거 제시 직후 범인이 폭발하고 독백 2줄 뒤 시작. 끝은 「X의 정체는 Y야!」 | 1장에 넣는다(주인님 지시) |
| 사이코 택시 | 막다른 길에서 "하나씩 정리" 독백으로 시작, 질문 3~4개, 결론은 완결된 추론 문장 | **브레인 드라이브 = 롤러코스터 분기 레일**로 넣는다 |

### 0-2. 오답과 힌트 (두 바퀴 같은 단계형은 쓰지 않는다)

| 상황 | 나오는 것 |
|---|---|
| 논스톱·패닉에서 틀림 | 그 화자의 반박 1~2줄 → 공통 독백 `(…아니야. 다시 생각해 보자.)` → 발언력 −1 |
| 논스톱·패닉에서 한 바퀴가 끝남 | `[힌트: 한 바퀴]` 미오 독백 **2줄**. 첫 줄은 어느 쪽이 수상한지, 둘째 줄은 무엇으로 반박할지 |
| 선택지·인물 지목·증거 제시에서 틀림 | 그 선택지 **전용 반응** 1~2줄 → 고정 독백 `(…다들 시선이 차가워졌다.)` → 발언력 −1 |
| 선택지에서 아무것도 안 고름 | `……` → 누군가 재촉 1줄 → 고정 독백 |
| 반론 쇼다운에서 밀림 | 밀림 독백 2줄(1단계용, 2단계용 따로). 다시 시작 대사 `미오: …처음부터 다시 말해 봐.` |
| 스크럼 합에서 틀림 | `(…논점이 안 맞았어. 같은 말을 받아칠 사람을 골라야 해.)` |
| 스크럼 전체 실패 | `(…밀렸다. 처음부터 다시.)` |
| 애너그램·이매지네이션·롤러코스터·이론 무장 | 대사 없이 감점. 애너그램만 `[힌트: 시간 경과]` 1줄 |
| 발언력 0 | 게임 오버(§9) |

### 0-3. 단계 전환 규칙
* 미니게임이 끝나면 **누군가 새 의문을 한 줄로 던진다.** 그 의문이 다음 단계의 주제가 된다.
* 미니게임 직전에는 **미오 독백 2~4줄**로 들어간다. 종류마다 신호가 다르다.

| 다음 단계 | 직전 신호 |
|---|---|
| 논스톱 | 누군가 결론을 서두름 → 미오 `(…이대로 정해지면 안 돼.)` 계열 |
| 섬광 애너그램 | 개념을 묻는 미완성 독백 + `**독백**　생각해.` |
| 발굴 이매지네이션 | "현장의 무엇"을 가리키는 독백 1줄(짧게) |
| 롤러코스터 | "처음부터 하나씩 정리하자" |
| 이론 무장 | 범인 폭발 1~3줄 + 미오 독백 2줄 |
| 클라이맥스 | 누군가 마무리를 부탁 → 미오 "처음부터 전부 되짚을게." |

## 7. 반론 쇼다운 진타 — 후지타 타이가

3. 〔구하러 들어간 거다!〕

5. 【손에 힘이 없던 건 화상 때문이다!】

* 다시 시작 대사: `미오: …처음부터 다시 말해 봐.`
* `[힌트: 한 바퀴]` (…듣기만 하면 안 돼. 베어야 해.) / (…화상이 그대로면, 힘은 왜 빠졌지. 쇼의 메모가 있어.)

## 8. 롤러코스터 분기 레일 (브레인 드라이브) — 왜 카에데였나

> `spec/04` §8 브레인 드라이브의 놀이공원판이다. 진행 규칙은 같고, 탈것만 차에서 롤러코스터로 바뀐다. 1장부터 쓴다(이전 "4장 전용" 메모는 폐기).

**도입** 판이 막힌다. 아무도 이유를 말하지 못한다.
`**독백**　장비. 점검표. 보고서.`
`**독백**　따로따로 떨어진 것처럼 보이지만, 전부 한 줄로 이어져 있을 거다.`
`**독백**　…처음부터 하나씩 정리하자.`
`**독백**　가자.`

**1단계** 레일 위 글자를 모아 질문 4개를 완성한다.

**2단계** 질문마다 레일이 세 갈래로 갈라진다.

| # | 질문 | 레일(정답 굵게) |
|---|---|---|
| Q1 | 카에데가 그 밤 공개하려던 것은? | **17번 보고서** / 위치표 / 순찰표 |
| Q2 | 그 보고서에 적힌 것은? | **장비 고장과 '이상 없음'의 거짓** / 순찰 경로 변경 / 대표 투표 결과 |
| Q3 | 장비를 멈추고 '이상 없음'이라 적은 사람은? | **후지타** / 미사키 / 시노미야 |
| Q4 | 그걸 숨긴 이유는? | **들키면 순찰대장의 믿음이 끝나니까** / 래피의 명령이라서 / 탈출하려고 |

* 오답 레일: 감점, 대사 없음. 장애물 충돌: 감속.
* **종료(결론 문장)** 미오 "후지타는 자기가 멈춘 장비를 '이상 없음'으로 덮었어. 그걸 밝히려던 카에데의 보고서를 빼앗으려다… 카에데를 죽였어." → 타이가 폭발 "증거 있냐! 내가 그 장비를 만졌다는 증거가!" → 결정적 증거 제시

### 결정적 증거 제시
「후지타가 '이상 없음'이라 적었다는 걸 보여 주는 증거는?」
* 정답 E1-09 시노미야의 점검표 사본(확인자: 후지타 / → 실제: 작동 확인 불가 / 13:10 옮겨 적음)

* 힌트 1줄: (…카에데가 오후에 직접 옮겨 적은 종이.)
