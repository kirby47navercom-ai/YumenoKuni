# 탐색 대본 양식 — V3 조사 결과와 우리 견본 (2026-11-18)

> V3 한글 대본(1·2장 일상 c0N_0xx, 수사 c0N_1xx, 시간 보내기 c0N_7xx, 공통 999)을 조사해 정리했다. 원문은 옮기지 않았다.
> 이 양식으로 프롤로그 → 1장 → 2장 탐색 대본을 쓴다. 공간은 `공원_공간_설계서.md`를 따른다.

## 1. V3가 하는 것 (조사 결과)
1. **방 하나 = 조사할 물건 3~8개, 물건마다 1~2줄.** 이야기에 걸린 물건, 그 장 주제를 건드리는 물건만 3줄 이상이다.
2. **조사 문장 틀:** 관찰 한 줄 + 감상·농담 한 줄. 약 7할이 가벼운 관찰과 농담, 나머지가 세계관 의심과 복선이다. 복선은 1~2줄로 섞는다.
3. **모니터 한마디:** 모든 방에 있다. 문장은 장마다 하나로 고정한다.
4. **처음과 다시:** 처음 조사는 1~2줄, 다시 조사하면 줄인 1줄. 수사에서는 처음 조사가 동행자 대화 3~8줄, 다시 조사가 독백 2~4줄이다.
5. **같은 방도 날마다 바뀐다.** 계기는 넷이다.
   - 이야기 진행(숨은 문 발견 등)
   - 목적지가 정해진 구간: 모든 물건과 출구 문장이 재촉 한 줄로 바뀐다. 웃음 포인트는 하나만 남긴다
   - 주인공 교체
   - 사망 뒤: 고인과 관련된 물건에만 애도 2~3줄. 나머지는 그대로
6. **처음 들어가는 방:** 방 성격을 짚는 한 줄. 자기 방이나 특별한 방이면 3~6줄 감정.
7. **새 구역이 열릴 때:** 열쇠 물건 → 찾는 방향 안내 → 처음 들어가면 주인과 다른 1~2명의 짧은 장면(10~25줄) → 다음 날부터는 혼자 보는 1~2줄 문장으로만 남는다.
8. **문:** 잠긴 문 기본 문장은 장마다 하나. 이유가 있으면 2줄. 반쯤 열리는 문, 새로 열린 문("…어라?" 3줄), 수사 중 "사건과는 관계없으니".
9. **인물:** 날마다 새로 배치한다. 말을 걸면 5~20줄 장면이 나오고(선택지가 있으면 두 갈래 다 쓴다), 다시 말 걸면 마지막 대사를 다듬은 한 줄이 나온다.
10. **시간 보내기:** 인물마다 시간대별 첫마디 1~2줄 → 네/아니오 → "~랑 시간을 보낼까?" → 수락 반응 → "~하며 시간을 보냈다…" → "조금 사이가 좋아질 수 있었던 것 같다…". 1장은 시간대 4개, 2장은 5개. 아니오는 말 없이 탐색으로 돌아간다.
11. **선물:** 5단계 반응(아주 싫음 ~ 매우 좋음), 각 2줄.
12. **수사 막기:** 방침 안내 → 물건 조사 → "기억해 두자" 마무리 → 구역 완료 문장 → 남은 대상 안내("○○는 어디 있을 거야") → 다 모으면 재판 소집. 들어야 할 증언 명단을 미리 알려 주고, 겹치는 증언은 서술 한 줄로 줄인다.
13. **공통 문장 묶음(999):** 목적지 강제 문장, 출구 라벨마다 "어서 ○○로 가야 해…", 구역 완료, "아직 여기서 조사해야 할 게 있는 것 같다", "오늘은 그만 방으로 가자".
14. **분량(1장 / 2장 일상):** 서로 다른 조사 문장 약 130~200 / 220~300, 인물 말 걸기 약 300~500줄씩(추정).
15. **V3 텍스트에 없는 것:** 코토다마 획득 창 문구, 모노코인, 숨은 모노쿠마 위치 문장 → 우리가 UI 문구로 따로 정한다.

## 2. 우리 견본

```
### [방] room_id — 이름 (구역, 열리는 장)
area_label: 화면 이름표
exits: 출구 라벨 → 가는 곳 (문 상태: 열림/잠김/조금 열림, 바뀌는 시점)
enter_first: 1줄 (특별한 방은 3~6줄)
monitor: (장 공통 문장 사용)

objects:
- obj_id「이름표」
  first: 1~2줄 (관찰 + 감상)
  repeat: 1줄
  phase: { 시점 → 문장 }        # 예: DAY3 이후 / 시체 발견 뒤 / 재판 뒤 / 목적지 구간
  invest: { first: 동행자 대화 3~8줄 | repeat: 독백 2~4줄 | 증거면 `[증거 …]` + "기억해 두자" | 무관하면 "사건과는 관계없…" }

doors:
- 문 이름: 잠김 문장 / 이유 문장 / 새로 열림 문장

npcs (날·시간대마다):
- [DAY n 시간대] 인물: talk_first 5~20줄 / talk_repeat 1줄
```

```
### [인물] 이름 — 시간 보내기
slot_hook: { 시간대 → 첫마디 1~2줄 }
accept: 1~2줄
summary: "~하며 시간을 보냈다…"
gift: { 아주 싫음 / 싫음 / 보통 / 좋음 / 매우 좋음 → 각 2줄 }
```

```
### [장 공통]
monitor: 모니터 한마디 (장마다 하나)
locked_default: 잠긴 문 기본 문장
forced_nav: { 목적지 → 재촉 문장, 출구 라벨마다 }
area_done: { 구역 → 완료 문장 }
invest_block: 아직 조사할 게 남았을 때
day_end: "오늘은 그만 방으로 가자" 류
```

- 표기: 대사는 원고와 같은 `**이름**　대사`, 독백은 `**독백**`, 속마음 `(…)`.
- 이야기 원고(11~17)의 장면과 겹치는 물건은 원고 문장을 기준으로 맞추고, 새 단서를 만들지 않는다.
- 사건과 증거에 걸린 물건은 해당 장 설계 문서의 증거 번호를 적는다.
- 생성기(「개발」 세션)가 읽을 수 있게, 최종 형식은 그쪽과 맞춘다.
