## 1. 세계와 분위기

- **무엇인가:** 「유메노쿠니(夢の国)」. 아이들을 위한 동화 테마파크였다. 5년 전 개장 전야 사고 뒤 문을 닫았다. 지금은 래피가 관리하는 "살아 있는 폐장 공원"이다.
- **첫인상:** 깨끗하게 관리되는데 사람이 없다. 파스텔 색, 둥근 지붕, 토끼 장식. 그런데 운영 시간 칸은 지워져 있고, 가격표는 전부 「0」이고, 하늘은 회색이다.
- **그림체 방향(3D):** V3처럼 실내는 꽉 찬 소품과 강한 색, 바깥은 무대 세트 같은 과장된 형태. 실사 질감이 아니라 손으로 칠한 듯한 평평한 색과 굵은 윤곽선 느낌 [안, 그림체 기준 문서와 맞춘다].
- **래피 흔적:** 모든 구역에 래피 장식이 있다. 토끼 귀 모양 가로등 갓, 토끼 얼굴 스피커, 문손잡이 토끼 머리. 구역마다 하나씩 "래피 동상 또는 인형"이 서 있다.
- **하늘:** 늘 회색. 해는 보이지 않는데 낮과 밤의 밝기는 바뀐다. 경계 너머 풍경, 돔은 보이지 않는다(프롤로그 확정사항).
- **카메라:** 구역마다 몇 대. 가로등 꼭대기, 문 위, 천장 구석.
- **모니터:** 방마다 작은 래피 모니터가 하나씩 있다(V3 방식, 탐색 대본의 「모니터 한마디」).

## 2. 크기와 좌표

- **좌표:** 원점은 광장 분수 한가운데 (0, 0). x는 동쪽 +, y는 북쪽 +, z는 높이. 단위 m.
- **공원 전체:** x −210~310, y −150~330 (약 520 × 480m).
- **바깥 경계:** 높이 8m 벽. 안쪽에 철망. 벽 위는 회색 하늘과 닿아 흐릿하게 보인다.
- **이야기 속 걸음:** 분당 70m. 원고의 "5분, 2분 남짓, 열 걸음"은 이 잣대다.
- **게임 이동:** 초당 4m [안]. 이야기 5분 길 = 게임 약 90초.
- **문 기본 크기:** 실내 문 폭 0.9m 높이 2.1m, 양문 1.8m, 철문 4~6m.
- **층 높이:** 호텔 층고 3.5m(로비는 7m 트임).

## 7. 만드는 방식 (Claude 판단, 2026-11-18 주인님 위임)

**결론: 단간론파 V3식.** 공간은 진짜 3D로 만들되, 색칠은 2D 그림처럼 한다. 인물은 2D 입상을 3D 공간에 세운다.

| 항목 | 정한 것 | 이유 |
|---|---|---|
| 공간 | 낮은 폴리곤 3D 모델 + 손그림 느낌의 평평한 색 텍스처 + 굵은 외곽선(툰 셰이딩) | 3D라 걸어 다니며 조사할 수 있다. 그림처럼 보여야 2D 입상·CG와 어울린다. 1장 이미지 목록 §0 "3D 기본, 특별한 장면만 2D"와 같다 |
| 시점 | 1인칭으로 걸어 다닌다(기획서: 1인칭 탐색). 조사할 물건에 다가가면 표시가 뜬다 | 미오의 눈으로 보는 게임이다. 노트·기록 시스템과 맞는다 |
| 인물 | 2D 입상(스프라이트)을 그 자리에 세운다. 늘 카메라를 본다(빌보드) | 「개발」 세션이 만드는 입상 350장을 그대로 쓴다 |
| 대화 | 말을 걸면 V3처럼 화면이 대화 장면으로 바뀐다(배경은 그 자리 3D를 흐리게 + 입상) | |
| 특별 장면 | 2D CG(시체 발견, 23:14 로비, 처형 등) | 1장 이미지 목록 §0 |
| 조각 방식 | 구역마다 모듈 세트(벽·바닥·문·창·지붕 조각)와 공용 소품 모음. 방은 조각을 조합해 만든다 | 방이 많아도 빨리 만들고, 그림체가 맞는다 |
| 크기 | 이 명세의 미터를 그대로 쓴다. 문 폭 0.9m, 눈높이 1.55m(미오 키 기준) | 시야 표(누가 무엇을 보나)가 3D에서도 그대로 맞게 |
| 빛 | 낮·밤 두 벌을 미리 구워 둔다. 사건 밤처럼 특별한 상태는 따로 | 회색 하늘이라 해 방향 그림자는 약하게 |
| 충돌 | 단순한 상자로 | 걷기만 하면 된다 |
| 바깥 큰 공간 | 광장·축제의 거리는 실제 크기로 만들되, 멀리 보이는 관람차·캐슬은 낮은 폴리곤 배경 모델 | 1장부터 보여야 한다 |

- 3D 모델 제작은 블렌더로 한다(이 세션에 블렌더 연결 도구가 있다). 텍스처는 그림체 기준(`개발/07_그림체_기준.md`)을 따른다.
- 엔진(HBEngine) 설치본은 건드리지 않는다. 엔진 쪽 작업은 「개발」 세션이 한다.

## 8. 구역별 명세 쓰는 양식 (01~06 공통)

각 공간마다 아래를 쓴다. 3D 제작자와 탐색 대본 작가가 같이 본다.

```
### [id] 이름 (구역 / 열리는 장)
- 한 줄 콘셉트:
- 분위기: 낮 / 밤 / 사건 뒤
- 크기·모양: 바깥 W×D×H(m), 평면 모양, 공원 좌표(중심, 향)
- 바깥모습(건물이면): 실루엣, 지붕, 간판, 래피 장식
- 재질·색: 바닥 / 벽 / 천장(지붕)
- 빛: 광원 위치와 종류, 낮·밤 차이, 색
- 소리: 늘 들리는 소리, 옆 공간에서 새는 소리
- 문·창: 위치(벽/좌표), 크기, 여는 방향, 잠금 규칙, 바뀌는 시점
- 배치표: 이름 | 위치(방 좌표 또는 벽) | 크기 | 조사(탐색 대본 obj id) | 비고
- 시야·소리(추리): 어디서 무엇이 보이고 들리는지
- 장별 상태: 장·날마다 바뀌는 것
- 이야기 제약: 원고·설계 근거와 꼭 지킬 숫자
- 탐색 메모: 처음 들어갈 때 느낌, 모니터 자리, 숨김 요소 자리
```

- 방 좌표: 방 남서쪽 바닥 모서리를 (0,0)으로, x 동쪽, y 북쪽.
