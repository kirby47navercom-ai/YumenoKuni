# 1장 학급 재판 — V3 단계 구성판 (⚠ 전체 스포일러)

> 11b D 섹션의 추리 순서를 V3 구성(docs/spec/15 §5)으로 다시 자른 **게임용 재판 대본**. 이 파일이 11b D를 대체한다(수사까지는 11b 그대로).
> 피해자 타이가 / 범인 쇼. 마법 정보는 래피 질의 UI 대신 **인물이 래피에게 묻는 장면**으로 공개되고, 마법 카드(M)가 자동으로 언령이 된다.
> 단계 표기 규칙(tools/build_trial.py 가 읽는다) : `### T-번호 종류 : 제목`. 종류 = 개정 · 논스톱 논의 · 패닉 논의 · 객관식 · 언령 고르기 · 지점 고르기 · 인물 지목 · 인터럽트 · 반론 쇼다운 · 논의 스크럼 · 섬광 애너그램 · 발굴 이매지네이션 · 브레인 드라이브 · 이론 무장 · 클라이맥스 추리 · 투표 · 휴정 · 장면.
> 논의 표 : `| # | 화자 | 문장 | 판정 | 필요 |`. 약점 = 문장 안 【】. 판정 = 노란(논파) · 동의 · 잡담(소음) · 거짓(거짓 탄환 필수, 필요 칸에 `카드 → 거짓 : 뒤집힌 내용`) · 일반.
> 선택형 : `- 질문 :` `- 보기 :` (A) … | B) … | C) …) `- 정답 :`. 언령 고르기·인물 지목은 정답 칸에 카드 ID·인물 slug.
