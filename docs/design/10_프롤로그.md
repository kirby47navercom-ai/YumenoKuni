## P-01 눈뜨기 (4분 / 중앙 광장 — 벤치)
화면 암전. 먼 곳에서 풍선 소리, 어딘가의 회전목마 음악이 겹쳐 흐른다. 플레이어는 미오 시점.

(튜토리얼 : 마우스로 시점 돌리기 → 눈을 뜬다는 연출)

```
[미오(독백)] "…따뜻한 빛. 눈꺼풀 안쪽이 노랗다."
[미오(독백)] "아, 벤치. 뭔가 부드러운 소리. …음악?"
(시점 조작 안내 : 좌우 드래그로 주위를 둘러보세요)
[코토] "일어났어요? 다행이다. 괜찮아요? 어디 아픈 데는 없죠?" {걱정}
[미오] "…하나이? 여기는…" {놀람}
[코토] "저도 몰라요. 눈 뜨니까 광장이었어요. 주변 사람들 다 쓰러져 있어서, 하나씩 깨우는 중이에요."
[미오(독백)] "하나이 코토. 반장. 이런 상황에서도 목소리가 흔들리지 않는다."
(튜토리얼 : 이동 노드 클릭)
```
* 광장 풍경 : **이른 새벽(06:00), 푸른 안개**. 파스텔 간판, 분수대 중앙에 **래피 동상**(귀가 한쪽 짧음 — 디테일 복선), 불이 들어온 놀이기구, 사람 없음. 전날 밤(0일차)에 소환되어 광장에서 잠들어 있었다는 설정(수첩 지급 때 래피가 언급).
* 미오 소지품 확인(컷) : 낡은 **노트**, **토끼 키링**(귀에 붉은 실 꿰맨 자국). 미오 "…내 거네. 있어서 다행이다."
* **[복선]** 키링의 귀 실밥 → 래피 동상의 귀 → 래피 본체 귀. 플레이어에게 처음으로 보여 준다.

## P-02 광장 집합 (12분 / 중앙 광장)
15명이 차례로 깨어 모여든다. **대화 튜토리얼** : 한 명씩 말 걸기. 각자 핵심 대사 2~4줄. (`talk_tutorial` 플래그)

```
[소라] "으아, 목이야! …어, 다들 여기 있었네! 괜찮아, 맡겨! 내가 한 명씩 살필게!" {활기}
[타이가] "이상한 일이다. 하지만 내가 지킨다! 누구든 무슨 일이 있으면 나한테 말해!" {결의}
[켄] "오오, 이 무대는 어느 막의 어느 장면인가! …아니, 대본 없이 시작하다니 불친절하군." {장난}
[레이] "폐쇄된 놀이공원. 구조상 정문이 닫혀 있으면 외부 접근은 어렵습니다. 침착하게 확인하죠." {무표정}
[나나] "저, 저기… 다친 분 계세요? 소매 걷어 보세요… 아, 아니면 괜찮은데…" {불안}
[리쿠] "이거 마술 쇼의 오프닝이야? 카드가 없어서 곤란한데~." {장난}
[아카리] "인원 확인부터 하겠습니다. 한 명, 두 명… 열여섯 명. 전원 있습니다." {진지}
[유우] "우와, 조용한 건 싫은데! 누가 노래 좀 불러 줘!" {불안한 웃음}
[사츠키] "…소란." {짧은 한숨}
[쇼] "의식이 있는 사람부터 순서대로 체크하겠습니다. 눈을 움직여 보세요." {침착}
[린] "어, 이 열쇠 뭉치 내 거네~! 자물쇠 있으면 말해. 따 줄게지롱." {장난}
[아이] "…저는 괜찮아요. …여기, 밥은 있나요?" {소심}
[카에데] "시간 낭비야. 일단 정리부터 하자." {담백}
```

### 핵심 이벤트 : 하루카와 미오
```
[하루카] "미오~! 거기 있었구나! 어디 갔나 했잖아~!" {밝은 웃음}
[미오] "하루카! …괜찮아? 다친 데는?" {안도}
[하루카] "응! 오히려 미오가 더 창백한데? 걱정했지~!"
[미오(독백)] "아사노 하루카. 어릴 때부터 늘 곁에 있던 소꿉친구. …있었던 거 맞지."
[미오(독백)] "(왜 지금 '있었던 거 맞지'라고 생각했을까.)"
```
* **[복선]** 미오의 독백 말끝에 불안한 문장. 플레이어가 한 번 읽고 지나가도록 짧게. 하루카는 미오의 키링을 보고 "아직도 그거 들고 있네?"라고 말한다. 하루카의 표정은 "흥미 없음"에 가깝다(고양이가 지나가면 반응).

### 코토와 레이의 시선 (튜토리얼 외 짧은 컷)
```
(카메라가 레이를 비춘다. 레이는 코토를 한 번 본 뒤 시선을 피한다.)
(코토는 평소처럼 미소를 지으며 카디건 소매를 정돈한다.)
```
* **[복선]** 서약선을 가린 소품들 : 레이의 커프스, 나나의 리본, 코토의 완장. 이 장면에서는 명시하지 않음.

## P-03 래피 등장 (6분 / 분수대)
분수대에서 거품과 불꽃이 터지며 래피가 솟아오른다. 모자는 삐뚤어졌고, 귀 한쪽은 꿰매져 있다.

```

[소라] "우와, 토끼다! …근데 눈이 좀 빨갛지 않아?" {놀람}
[래피] "래피는 이 공원의 주인이자 진행자! 오늘부터 여러분이 이 공원의 첫 손님이에요!" {방방}
[타이가] "손님이라고? 우리를 여기에 데려온 건 너냐!" {적의}
[래피] "아야! 래피에게 그렇게 무섭게 하면 안 돼요. 규칙 위반으로 벌 받아요!"
```

* 하루카가 손을 흔들면 래피가 한 순간 움찔하고 "…어, 어어! 어서 오세요!"라고 말을 얼버무림. **[복선]** 플레이어에게 "래피가 하루카를 피한다"는 감각을 준다.

## P-04 규칙 설명 (8분 / 분수대)
래피가 수첩을 나눠 준다. **[핵심 UI 튜토리얼 : 수첩 열기]**

```
[래피] "그럼 규칙을 설명할게요! 첫째! 공원 밖으로는 나갈 수 없어요."
[래피] "둘째! 이 공원에서 '졸업'하는 방법은 오직 하나. …누군가를 죽이고, 들키지 않는 것!" {싱긋}
(전원 침묵. 유우의 숨이 흐트러지는 소리)
[켄] "…이거, 상당히 취향이 고약한 대본이군." {무표정}
[래피] "셋째! 시체가 발견되면 수사 시간. 그 뒤에 '학급 재판'을 열어요."
[래피] "넷째! 재판에서 범인을 맞히면 범인만 '특별 처형'! 틀리면 범인만 졸업하고, 나머지는 전부 처형!" {활짝}
```

* 수첩 7쪽 : 지도(인쇄본). **래피 : "수첩에는 오류가 없다."**

## P-05 마법 공개 시간 (10분 / 분수대 옆)

## P-06 탐색 튜토리얼 (20분 / 0구역)
래피가 퇴장하며 "0구역을 개방! 마음껏 놀아요!"라고 선언. 1인칭 탐색 시작.

### 튜토리얼 과제 (체크리스트)
1. 인포메이션 센터에서 **지도 수령** (조사 모드 설명)
2. **코인 수집** (광장 코인 3개 / 호텔 로비 2개)
3. **캡슐 머신 무료 2회** (선물 시스템 소개)
4. **호텔 열쇠함** 앞에서 방 배정 선택 (레이/린 근처 선택 가능)
5. **푸드코트**에서 린과 첫 자물쇠 이벤트(창고 열기)
6. **노트에 적기** 첫 체험 (프롤로그 슬롯 #1 : 호텔 안내 표지판 → 5층 VIP 플로어는 잠금)

### 장소별 핵심 텍스트
* **인포메이션 센터** : 분실물함에 낡은 **토끼 인형 시제품 사진**(귀 한쪽 짧음), 사진에 적힌 메모 "첫 번째 시제품 – 귀를 꿰맸음".
  [복선] 미오가 사진을 보고 "…이 인형, 본 적 있어."라고 중얼거림. 뒤 문장은 흐릿하게 처리.
* **호텔 로비** : 프런트에 열쇠함 16개. 4층 이상 객실은 잠금. 1층 라운지에 레이가 앉아 있음.
  `[레이] "구조는 지도대로입니다. 별관은 열려 있지 않군요."` {무표정}
* **푸드코트** : 아이와 카에데가 부엌에서 개장 케이크를 만든다. 린이 자물쇠 창고를 열어 준다.
  `[린] "여기 창고 열쇠 안 맞아서 못 열었는데, 내가 열어 줄게지롱! 열쇠 도둑이 아니라 열쇠 수리공이니까 오해 마라지롱♪"`
* **기념품샵 앞** : 잠금 상태. 쇼가 "의무실은 내일 개방이랍니다"라고 말한다.

## P-07 연습 사건 「사라진 개장 케이크」 (35분)

### 도입 (2분 / 푸드코트 앞)
```
[래피] "쨘~! 여러분, 큰일이에요! 개장 케이크가 없어졌어요!" {분노 연기}
[아이] "…제가 냉동 창고에 넣어 두었어요. 16시에." {당황}
[카에데] "17시 30분 현재 없음. 누군가 가져갔다는 뜻이야." {평온}
[래피] "래피의 케이크를 훔치다니! 이건 연습 재판감이에요! 범인을 찾으면 간지럼 퍼레이드♪"
[타이가] "…연습이라며 벌칙이 있냐!" {당황}
[래피] "연습이니까 처형은 없어요. 대신 간지럼 5분이요! 진짜 사건에서는… 처형이에요."
```
* 래피의 마지막 한 마디에서 BGM이 1.5초 끊긴다(분위기 전환).

### 연습 수사 (8분 / 푸드코트 · 광장)
**증거 카드(튜토리얼)**

| ID | 증거 | 획득 | 내용 |
|---|---|---|---|
| E0-01 | 냉동 창고 잠금 기록지 | 냉동 창고 문 앞 | 마지막 열림 16:48 |

| E0-03 | 크림 자국 | 푸드코트 뒷문 손잡이 | 위치 높이가 성인 어깨 높이 |
| E0-04 | 하루카의 사진 | 하루카에게서 받음 | 16:47 광장 분수대, 리쿠가 상자를 들고 있음 |
| E0-05 | 규칙 카드 R-05 「대역」 | 수첩 | 두 사람의 신원 인식을 10분간 맞바꿈. **거울·사진에는 안 통함** |

| T0-02 | 나나 | "16:30~17:00 소라 씨는 제 방에서 응급 처치 연습을 하셨어요." | 진실 |

### 연습 재판 (22분 / 푸드코트 임시 법정)
1. **시간표 맞추기 (3분)** : 카드 4장 — `16:00 케이크 보관` / `16:48 창고 열림` / `16:45 린의 목격(소라 모습)` / `16:47 하루카 사진` — 시간표에 놓기. 정답 순서 : 16:00 → 16:45 → 16:47 → 16:48.
2. **논파 스트림 1 (5분)** : 린의 증언을 흘려보냄.
   - S1 `[린] "내가 본 건 소라였어!"` ← **노란 마크: 소라의 알리바이(T0-02)**
   - S2 `[린] "소라가 케이크 상자를 들고 있었어."` ← 동의(파랑)
   - S3 `[소라] "나는 나나 방에 있었어!"` ← 동의
   - S4 `[켄] "그럼 린이 본 건 누구지?"` ← 동의 유도
   - S5 `[리쿠] "소라처럼 보이는 누군가가 있었다면…"` ← 힌트
   - 정답: 소라처럼 **보이는** 누군가 → 대역 가능성
3. **논파 스트림 2 (5분)** : "대역" 마법과 사진.
   - S1 `[아카리] "소라처럼 보였다면 변신을 쓴 사람이 있나요?"`
   - S2 `[린] "나는 변신을 안 썼어!"` ← 동의
   - S3 `[켄] "대역이라면 리쿠가 가능하겠지만…"`
   - S4 `[리쿠] "하하, 내가? 증거 있어?"` ← **노란 마크 : 사진(E0-04) + 규칙 R-05**
   - 정답 증거 : E0-04 + R-05. 설명 : 사진에는 대역이 통하지 않으므로, 린에게는 소라로 보였지만 사진에는 리쿠가 찍힘.
4. **래피 질의 (2분 / 최대 1회 사용 가능, 소모 없음)**
   - Q. "대역은 사진에도 통하나요?" → "아니요. 사진과 거울에는 통하지 않아요."
   - Q. "대역은 상대에게 어떻게 작용하나요?" → "두 사람을 아는 제3자의 '신원 인식'이 10분간 바뀌어요."
   - Q. "10분이 지나면?" → "원래대로 돌아와요."
5. **반론 쇼다운 (4분) : 리쿠**
   - `[리쿠] "증거는 사진 한 장이잖아!"`
   - `[리쿠] "누가 상자를 들고 있는지 모르잖아?"`
   - `[리쿠] "린이 본 건 소라라고!"`
   - `[리쿠] "…그리고 나는 간식이 싫어!" ← E0-02 젤리 포장지로 일격`
   - 결과 : 리쿠 "…참, 이건 연습이라 봐줄게?" 투표 → 리쿠.

### 처벌 (3분)

## P-08 개장 선물과 밤 (10분 / 호텔)
```
[래피] "연습 재판 참가 기념! 코인 10개와 캡슐 머신 개방! 내일부터 구역이 더 열려요♪"
[래피] "그럼 모두 호텔로 돌아가세요. 밤 10시 이후엔 외등이 꺼져요. 조심해서 다니세요?"
```
* **수첩 4쪽 규칙 카드(야간 규칙)** : 밤 10시 이후 외등 소등(3장부터 완전 소등. 1~2장은 광장 조명만 유지).
* 호텔 복귀 후 **방 배정 장면** : 미오 방 근처에 하루카, 코토, 레이. 각자 방 앞 인사 한 줄씩.

### 하루카와 미오의 밤 대화 (핵심 복선)
```
[하루카] "미오~ 아직 안 자?" {문틈에서 고개}
[미오] "응. 노트 정리하고. …하루카는 안 졸려?"
[하루카] "나는 혼자 있으면 이상하게 안 자게 돼서~. 조금만 같이 있어도 돼?"
[미오] "물론이지."
(하루카가 미오의 키링을 본다)
[하루카] "아직도 그 토끼 달고 있네. …솔직히 인형은 나 별로야. 이상하게 눈이 안 마주쳐."
[미오(독백)] "(어릴 때 하루카도 이 토끼 좋아했던 것 같은데…… 기억이 흐려졌나.)"
```
* **[복선]** 가짜 하루카의 "인형 무관심". 미오의 의문은 즉시 지워진다(마법적 인식 변경의 아주 약한 잔재).
* 노트 슬롯 (프롤로그 #2) : "하루카가 토끼 인형을 좋아하지 않는다." 이 항목을 적으면 4장 재판에서 **노트 증거 N0-02**로 사용 가능(숨은 보너스).

### 밤 방송 (에필로그)
```
[래피(방송)] "여러분, 오늘 수고했어요! 내일부터 정말 개장이에요. …잘 자요? …그리고 약속, 지켜 주세요♪"

[래피] "…누가 래피를 죽였을까요?"
```

* 래피의 마지막 한마디는 알림창 없이 음성만 들린다(스포일러 UI 방지). 암전, 타이틀 『유메노쿠니』.
