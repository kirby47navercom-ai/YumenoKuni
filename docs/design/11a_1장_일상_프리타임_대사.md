# 1장 일상 파트 · 프리타임 대사 확장본 (⚠ 스포일러 포함)

> `11_1장_개장.md`의 일상 파트(130분)와 프리타임(슬롯 4 + 프롤로그 슬롯 2)을 **대사 단위**로 푼 문서.
> 형식 : `[화자] "대사" {표정}` / `(지문)` / `▶선택지` / `★ 인연 +2` / `✕ 인연 −1` / `☆ 코인 +n`.
> 화면 전환 표시 : `── 전환 ──`.
> 시간 : 2일차(개방일) · 3일차(순찰 첫날·동기·사건).
> 스포일러 방침 : 사건 관련 복선은 `[복선]` 태그로 표시. 구현 시 태그는 제거.

---

## 0. 1장 프리타임 운영 규칙
* 슬롯 6개(프롤로그 2 + 1장 4) 사용처 : 프롤로그 슬롯은 ①을 열고, 1장 슬롯은 ①②를 연다.
* **타이가·쇼**는 이 장 밤에 퇴장 → ①②만 존재, ③ 대신 **유품 이벤트**(11-4절).
* 한 슬롯에서 캐릭터 선택 → 장소 이동 컷 → 이벤트(약 8~10분) → 보상 정산.
* 인연 포인트(이하 BP) : 이벤트 기본 +2, ★ 선택지 +2, ✕ −1, 선물 +3/+1/−1.
* **레벨업 연출** : Lv2 도달 시 대표 대사 카드 획득 알림 + 해당 인물이 "이름을 부르는 방식"이 바뀐다.
