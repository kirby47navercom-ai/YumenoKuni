### A-2 장치 (마법이 아닌 것)
1. **대피소 입소 단말** : 입소 시각 기록(14명 19:55~20:05 / 코토 20:50).
2. **점검표 사본** : 서명(아카리 아버지)과 본문(코토 아버지 필체)의 불일치.
3. **난간 손바닥 자국** : 어린 아이의 손.
4. **래피의 기억 복원 로그** : 추락 직전의 음성.
5. **노트·일기** : 미오의 변조 불가 기록.

### B-5 서약선 해체 (20분 / 특수 미니게임)
**[UI]** 노트 증거(N2/N4/N5)·유품 단서와 서약선의 위치를 대조하며 선을 하나씩 "지우세요". 5개 선이 대응합니다.
```
(화면 : 미오의 손목, 코토의 완장, 회상 컷)
[코토] "…이건 제 완장이에요. 풀 필요가 없어요." {미소}

[아이] "…제가 도울게요." {반대 손으로 완장을 감쌈}
(두 사람이 코토의 완장을 푼다. 팔목에 여러 줄의 검은 서약선이 드러난다.)
[코토] "…" {미소 유지}
[카에데] "…줄이 여러 개야. 나나, 레이, 아카리, 사츠키…… 그리고 미오까지." {낮은 목소리}
```
* **미니게임 규칙** : 선 5개를 각 인물 증거와 연결(나나=E5-09, 레이=커프스 컷, 아카리=손목 컷, 사츠키=E5-08, 미오=6-S2 형성). 클리어 시 연출 : 선이 하나씩 이름으로 변해 화면 한가운데에 "하나이 코토"로 수렴.
* **미오 B 선택(약속 거절)** 루트 : 서약선 4개(미오 제외)가 확인되며, 코토의 "미오 씨와는 맹세를 맺지 않았어요"가 부각.

## C. 엔딩

### C-A 엔딩 A (기본) — 체포 (30분)
```
[코어(음성)] "…정답입니다. 범인은 하나이 코토."
(처형 장치가 작동하려 하지만 래피가 소멸한 후라 가동하지 않는다.)
[코어(음성)] "…처형 절차를 시작합니다. …오류. 처형 장치와의 연결이 끊어졌습니다."
[린] "…처형이 안 돼." {놀람}
[미오] "…처형은 안 돼. …나는 살의를 버릴래." {노트를 닫음}
[미오] "…법으로 심판받아. …살아서 갚아." {코토를 바라봄}
[코토] "…네." {미소와 눈물}
(코어 정지, 공원의 문이 열린다. 아침 햇살.)
[린] "…문이 열렸지롱." {작게}
[아이] "…돌아갈 수 있어요." {눈물}
[카에데] "…시간이 많이 걸렸네." {미소}
```
* 후일담 : 사고의 진상 공표(점검표 위조 + 한 아이의 살의). 코토는 소년 법원으로 이송. 5명의 생존자.
* 마지막 장면 : 미오가 새 노트에 쓴다.
```
[미오(독백)] "아사노 하루카는 거기에 있었다."
[미오(독백)] "…나는 적어 둘 거야. 잊지 않도록."
(키링이 햇빛에 반짝인다)
```
* 엔딩 크레딧 : 16명의 입상이 한 장씩 넘어가며 사망자는 흑백. 하루카(진짜)와 래피가 겹쳐 등장.

### C-B 엔딩 B (어두운 분기) — 처형

* 후일담 : 문은 열리지만 미오의 눈빛은 무겁다. 린·아이·카에데가 미오를 부축. 엔딩 B 전용 아트 1장 + 짧은 크레딧.
