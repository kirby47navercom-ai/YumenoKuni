# 6장 최종 학급 재판 — V3 단계 구성판 (⚠ 최종 스포일러)

> 16b B 섹션을 V3 구성으로 다시 자른 게임용 재판 대본. 16b B를 대체한다(엔딩 C는 16b 그대로). 형식 규칙은 11c 머리말과 같다.
> 사건 : 5년 전 하루카 살해 / 진범 코토. V3 최종 재판처럼 **패닉 논의 연속**과 **이론 무장 연속**으로 끝을 맺는다. 폐지한 「서약선 해체」 미니게임은 논의 스크럼 2연속 + 지점 고르기로 옮겼다.
> 분기 A(서약선 형성 루트)·B(약속 거절 루트)는 T-14만 다르다.

### T-14 장면 : 코토의 마지막 카드
```
[코토] "…좋아요. 저는 졌어요." {미소}
[코토] "…하지만 미오 씨. 맹세는 맹세예요. 먼저 믿기로 했죠? 제가 한 말을 먼저 믿어 주세요."
```
* **분기 A (서약선 형성 루트)** : 미오의 손목에서 선이 빛나고 미오가 쓰러진다. [아이] "…맹세의 대가예요. 지금 의심하고 있으니까." → T-15로.
* **분기 B (약속 거절 루트)** : 선이 미오의 손목에서 튕겨 나간다. [래피] "맹세의 100%는 합의 없이도 묶을 수 있어요. 하지만 상대가 거부하면 실패해요." [미오] "난 약속 안 했어." → T-15로(쓰러지지 않음).
