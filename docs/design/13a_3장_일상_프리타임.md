# 3장 「거울의 밤」 일상 · 프리타임 · 동기 전체 대사 (⚠ 전체 스포일러)

> 피해자 타치바나 리쿠 · 카미야 소라(본체) / 범인 카미야 소라(의식, 시라누이 켄의 몸). 이 문서는 **사건 직전까지**. 사건·수사·재판은 `13b_3장_수사_재판.md`.
> 진행 : **스토리 → 프리타임(2) → 스토리 → 프리타임(2) → 스토리 → 동기 → 사건**. (프리타임 2세션 / 4슬롯 — 후반이라 줄어듦)
> 시간 : 일상 110 + 프리타임 28 + 동기 15 + 에필 15 = 약 168분(에필 15분은 13b).
> 일정 : 7일차(개방) / 8일차(연극 준비·상영회·사건 밤).
> 개방 구역 : 거울 미로 「미러 라비린스」, 대관람차, 드림 시어터.
> 규칙 카드 추가 : **R-08 야간 외등 완전 소등(22:00)** / **R-09 극장 규칙 : 상영 중 입·퇴장 자유, 음향실·장치실은 카드키(#1 장치실·#2 음향실·#3 분장실) 사용.**
> 분위기 : 야간색(남색), 저음 BGM, 래피 장난기 50%. 식당 공석 7자리.
> 마법(비공개 원칙) : 이 장의 마법은 **빙의(소라) · 최면(켄)**. 일상에서 공개되는 것 — 켄의 최면은 **켄 본인이 자랑하며 조건까지 밝힘**(M3-02), 소라의 빙의는 **대관람차에서 리쿠의 질문에 소라가 시인**(M3-01, 리쿠·미오만 앎). 그 외 : 사츠키의 그림자가 거울에 비치지 않음(M3-03).

### B-3 리쿠 ③ 「밤 광장」 (중앙 광장 벤치)
```
(중앙 광장. 오후의 햇살이 길게 늘어진다. 리쿠가 동전을 굴리지 않고 가만히 앉아 있다.)
[리쿠] "…미오. 와 줬네. 앉아." {평소와 다른 목소리}
[미오] "…리쿠, 오늘 뭔가 달라."
[리쿠] "…그래? 마술사는 가끔 진지해지면 안 되는데." {웃음}
```
▶ 선택지
  - ★ "진지해도 돼." → 
```
[리쿠] "…미오. 가끔 이상한 생각이 들어." {작게}
[리쿠] "…우리 중에 이미 다른 사람이 되어 있는 사람이 …있을 수도 있다고." {시선}
[미오] "…다른 사람?" 
[리쿠] "…아냐. 카드 한 장 뽑아 봐." {웃음으로 덮음}
```
  - ✕ "마술사는 거짓말쟁이잖아." → [리쿠] "…그렇지. 거짓말쟁이니까 진실을 알아." {짧게}
```
[리쿠] "…미오. 만약 내가 오늘 밤 …무슨 일이 생기면, 이 카드를 …" {카드 한 장을 건넴}
[미오] "…무슨 일이?"
[리쿠] "…아무것도 아냐~. 마술사의 마지막 장난이야." {윙크}
```
* **[복선]** 리쿠가 소라의 의도를 눈치채기 시작.
* 획득 : **리쿠의 카드 1장(스페이드 에이스)**. 이후 재판 장면에서 이 카드가 클로즈업.
* ☆4 / 대표 대사 「마술사의 마지막 장난」.
* 선물 : 마술 카드 [호] / 젤리 파우치 [호].

### B-4 코토 ③ 「점검 일정」 (호텔 라운지)
```
(라운지의 창가 자리. 코토의 가방에서 접힌 종이가 삐져나와 있다.)
[코토] "…미오 씨. 마침 잘 오셨어요." {온화}
[미오] "…그 종이는?"
[코토] "…아빠의 일정표예요. 아직 가방에 있어요. 버려야 하는데." {종이를 쥠}
[코토] "…아빠는 …공원 점검 기술자였어요. 사고 날 …마지막 일정이 이거예요." {낮게}
```
▶ 선택지
  - ★ "나도 엄마 물건을 못 버려." → 
```
[코토] "…미오 씨도요?" {놀람}
[미오] "…엄마가 만든 인형. 키링으로 갖고 다녀."
[코토] "…좋은 습관이에요. …저는 …버려야 하는데 …" {작게}
[코토] "…미오 씨, 제가 이 일정표를 없애면 …어떻게 될까요?" {시선}
[미오] "…?"
[코토] "…아니에요. 이야기만 해 봤어요." {미소}
```
  - "…버려도 돼." → [코토] "…그렇죠." {종이를 접음}
* **[복선]** 코토의 점검 일정표(6장 증거 E6-10 연결).
* ☆4 / 대표 대사 「버려야 하는데」.
* 선물 : 노트 세트 [호] / 시계 케이스 [호].
