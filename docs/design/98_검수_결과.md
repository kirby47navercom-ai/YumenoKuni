## 3. 규칙 일관성 점검 결과
| 규칙 | 결과 |
|---|---|
| **마법 비공개** : 시작 시 본인 마법만 안다 | 프롤로그에서 마법 공개·연습 재판 제거 완료. 각 장의 "필수 효과 목격(M카드)"이 일상에 존재(1장 M1-01 / 2장 M2-01·02 / 3장 M3-01·02·03). 4~6장은 효과가 아닌 **기록(N4-01)·증거**로 공정성 확보 |
| **래피 질의 한도 5회** | 1~6장 모두 5회 이내. 3장 Q4(사망자 지명)는 6장에서 재참조 |
| **재판에 새 물증 없음** | 모든 증거는 수사·일상에서 획득 가능. 4장 일기장(E4-14)은 수사 중 선택 열람 + 재판에서 필수 열람(획득 경로 존재) |
| **마법만으로 살인 불가** | 1장 하강 장치 / 2장 약병·앰플 / 3장 샌드백·도끼·밀실 / 4장 걸쇠·환기 부재 / 5장 시한 석궁 장치 — 모두 물리 장치가 사인 |
| **프리타임 구조** | 1·2장 3세션 / 3·4장 2세션 / 5장 1세션 / 6장 0 — 일상 문서와 일치 |
