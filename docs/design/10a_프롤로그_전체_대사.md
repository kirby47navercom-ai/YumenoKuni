# 프롤로그 「개장 전야」 전체 대사 확장본 (⚠ 스포일러 포함)

> `10_프롤로그.md`(구조·복선표)를 **대사 단위**로 푼 문서. 총 120분.
> 구성 : 오프닝 시퀀스 → P-01 눈뜨기 → P-02 광장 집합 → P-03 래피 등장 → P-04 규칙 설명 → P-05 마법 공개 → P-06 탐색 튜토리얼 + 프리타임 2 → P-07 연습 사건 → P-08 밤.
> 형식 : `[화자] "대사" {표정}` / `(지문)` / `▶선택지` / `★ 인연 +2` / `☆ 코인 +n` / `[UI]` 튜토리얼 안내 / `[복선]`(구현 시 제거).
> 단간론파식 **오프닝 연출**을 반영 : 타이틀 → 초대장 회상 → 문을 넘는 순간 어지럼 → 눈뜨기.
