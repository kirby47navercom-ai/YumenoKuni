### B-9 사츠키 ② 「동물 이야기」 (호텔 마당)

▶ 선택지

### B-10 린 ② 「공원 구석구석 탐험」 (워터파크 기계실 · 펌프실)

### C-1 유우 유품 (인연 Lv3 이상)
```
(유우의 방. 침대 위에 기타 피크 한 개와 이름 없는 악보가 놓여 있다. 나나가 서 있다.)

[미오] "…내가 이 악보를 갖고 있을게." {노트에 끼워 넣음}
```
* 획득 : **유우의 기타 피크**. 스킬 「공감」 유지. **Lv4 이상** : 악보 뒷면에 "미오 코러스 파트 : 낮게 라라라" 라는 메모.

### C-2 아카리 유품 (인연 Lv3 이상)
```
(아카리의 방. 책상 위에 정리된 약초 노트. 마지막 페이지는 비어 있다. 사츠키가 문 앞에 서 있다.)
[사츠키] "…이거, 아카리 거야." {짧게}
[미오] "…정리 노트네. …완벽해."
[사츠키] "…마지막 장은 …비어 있어. 아카리가 …끝내지 못했어." {낮게}
[미오] "…내가 이어서 적을게. …아카리의 정리 방식으로." {노트를 건네받음}
```
* 획득 : **아카리의 약초 노트**. 스킬 「정리 정돈」 유지. **Lv4 이상** : 마지막 장에 "미오 씨의 노트와 같은 방식으로 정리하고 싶었다" 라는 메모.
