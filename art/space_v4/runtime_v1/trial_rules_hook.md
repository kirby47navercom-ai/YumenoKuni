# Pure trial rules integration

`Game/Source/TrialRulesV4.hpp` is header-only, namespace `trialv4`, and independent of HBEngine. Add its include to Yumeno.h and keep a Mine, Scrum, Anagram, Arming state where the existing stage state lives. The parent owns TrialRunner/Yumeno.h and scene UI edits.

- Mine.reset(w,h,colorCount,board): retains externally set hp/damage/skill options. `click(cell)` removes only a four-connected group of >=2, with deduplicated one-time boundary rotation. A singleton needs three consecutive clicks and costs600 internal ticks. `undoEnabled=true; undo()` restores board/colors only. It never refunds time or HP. Board seed construction is not supplied by this pure module.
- `Mine.setImages({MineImage{id,cells,correct,collectible,active}})`: cells are the **actual** mask footprint, not a guessed rectangle. `submitAt(cell,inverseTransformedPixelAlpha)` checks uncovered footprint and alpha>127. Collection feedback holds the clock60ticks; wrong image damage is throttled30ticks. `tick(frames)` is integer nominal update count; pause/focus state remains the caller's owner. Do not make focus half-speed for this mode. `permanentCollectionEligible()` only after Complete.
- Scrum.reset(1): normal difficulty, requirements4/5/6/7/15 and failure thresholds6/6/6/6/9, limits180/180/180/180/300. `tick(direction)` accepts one logical0..3 or -1 per update, then tests success before time/miss failure. `direction()` is the current prompt. A failed later phase returns PhaseBack; phase0 returns Failed. The supplied pattern0/0/2/2/0/0/2/2/0/0 is the verified representative; other authored stages can set `directions` and `patternPeriod`. RNG is our deterministic selection, not the original RNG.
- Anagram.reset(u16answer,u16choices):20 active slots, recursive long-side split of [-1024,-416,2048,832]. Midpoints are deterministic testable placements, not claims of original random coordinates. UI maps these authored units into its own viewport. `pick(slot,tx,ty)` starts a flight and never judges immediately. `advance(allowedMovementDelta)` returns Correct/Wrong/Complete only at arrival, using t+=2delta and Q=P+Vt+At²/2 projected byQz. `position(slot)` returns x/y/scale, including2x at midpoint. Repeated glyphs respawn and next required code unit cannot disappear. Parent still owns normal orb motion, mask hit test, focus/spotlight/time/feedback and any special stage6000damage metadata. Glyph0 collection has no wrong-answer damage.
- Arming raw HP is10000-scale. `apply(Rating)` implements per-difficulty critical/hit/miss/mash gains and enemy10/5damage. Normal tension+4/+2/-2/+4/-8, clamped0..20; only empty tension triggers the HP hit and restores10. Caller must not call existing hurt() for every MISS. `press(Note,button0..3,d)` / `release(...durationDelta)` distinguish tap/hold/mash; UI/audio scheduler owns the `d` counter and physical mapping. No claim of completing all native hold-note scoring subpaths or fever resource timing. `finalOrder({0,1,2,3})` is order-sensitive; finalWrong applies1500normal raw damage and restores opponent total/10 for an internal rhythm retry (not whole trial retry). Caller owns phase/visual waits and all final-battle-specific differences.
