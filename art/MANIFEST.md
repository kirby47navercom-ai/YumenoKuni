## 완료: 기준 입상

`ai`, `akari`, `haruka`, `kaede`, `ken`, `koto`, `lappy`, `mio`, `nana`, `rei`, `riku`, `rin`, `satsuki`, `sho`, `sora`, `taiga`, `yuu` — 각 `art/standing_hd/{slug}.png`.

- 전부 PNG, 3328×4864, 입력 832×1216의 정확히 4배.
- Real-ESRGAN NCNN Vulkan 20220424 / `realesrgan-x4plus-anime`, scale 4, tile 128.
- [공식 배포 및 모델](https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.5.0).
- 원본 `art/standing/` 수정 없음. 17쌍 비교 검수: 얼굴·머리·복장·소품·색 유지 확인.
- 일괄 입력 폴더의 TXT는 디코딩 대상에서 제외되었으며 출력 PNG 17장만 규격 검사함.

## 진행: 스프라이트

- 내장 이미지 생성 도구 사용. 매 포즈의 기준은 `art/standing_hd/{slug}.png`.
- 미오 6포즈 생성 및 검수 진행 중. 생성 원본은 최종 정렬·알파 검수 전이므로 완료에 포함하지 않음.
- 스프라이트 규격: 투명 PNG, 2048×2048, 정면 허벅지 위, 머리 y≈120 / 몸 중심 x=1024.
- `sheet.png`는 인물별 6열 검수 미리보기이며 본편 스프라이트 개수에 포함하지 않음.
